# 题库数据管理页面:需求说明

状态:第三稿,待确认。确认前不开始实现。

## 1. 背景

### 1.1 题库现状

| 项目 | 数量 |
|---|---|
| 考试 | 9709、9231、9618(CAIE A Level);TMUA、TSA、BMAT(入学考试) |
| 题目 | 5937 道,每道一条记录。题目 ID 形如 `9709_s23_12_q05`、`TMUA-2023-P1-q1` |
| 题图 | 每题一张紧凑题图;2885 道 CAIE 题另有带答题区的题图 |
| 评分细则 | 5936 道有,按小问切开 |
| 详解 | 874 道(9618 卷 1–3) |
| 原卷与细则 PDF | 现在只在本机 `raw/pdf/`、`raw/ms/`,共 688 MB;将放进 `data/papers/` |

### 1.2 使用方式

- 作答在纸上或 iPad 上进行。纸上作答时打印题目卷;iPad 上作答时,在本页面内用白板直接在题目卷上书写。
- 判分与讲解交给模型。交给模型的资料一次交齐,不来回补充。
- 题库数据由 Claude 用 pipeline 维护,包括数据质量的检查与修正。

### 1.3 要做什么

一个在 Mac 上运行、iPad 通过局域网访问的本地服务,提供以下功能:

1. 查询题库中任何一道题的任何数据;
2. 把选中的题组成题组;
3. 由题组生成题目卷 PDF,用于下载打印或在 iPad 上书写;
4. 由题组、作答与模板生成交给模型的资料包。

导出(第 3、4 项)是需要反复打磨的重点。

## 2. 范围

### 2.1 本期实现

| 编号 | 功能 |
|---|---|
| F1 | 查询:全部题目的表格、筛选、搜索、排序 |
| F2 | 单题详情:一道题的全部数据 |
| F3 | 题组:创建、排序、命名、保存;导入与导出题组 JSON |
| F4 | 题目卷 PDF:由题组生成,可下载打印 |
| F5 | iPad 书写:在页面内用白板在题目卷上书写,导出带笔迹的 PDF |
| F6 | 参考文档:评分细则与详解的排版文档,供阅读,不进题目卷 |
| F7 | 资料包:由题组、作答与模板生成 ZIP |
| F8 | 模板:定义资料包的内容、结构、命名与说明文字;在页面内编辑与预览 |

### 2.2 不实现

- 修改题库。页面对 `data/caie.db` 只读。
- 数据质量检查。由 Claude 用 pipeline 完成。
- 作答与成绩记录。成绩随资料包交给模型。
- 网页判分。
- 打印评分细则。评分细则只以参考文档的形式提供(F6)。

## 3. 使用流程

### 3.1 刷整卷

1. 在查询中找到一份试卷,例如 `9709/12/M/J/23`,把整卷加入一个新题组。
2. 生成题目卷。整卷题组直接使用原卷 PDF。
3. 作答,二选一:
   - 下载 PDF,打印,纸上作答,拍照;
   - 在 iPad 上打开页面,用白板在题目卷上书写,导出带笔迹的 PDF。
4. 选择模板(例如"判分"),生成资料包,交给模型。

### 3.2 刷专题

1. 按条件查询,例如"9709 卷 3,主题 3.8,2021 年及以后"。
2. 勾选题目,组成题组并命名。
3. 生成题目卷(版式见第 6 节)。
4. 后续同 3.1 的第 3、4 步。

### 3.3 由模型出题组

1. 模型按要求选题,返回题组 JSON(格式 `alevel-question-set/v1`)。
2. 在页面导入,成为一个题组。题库中不存在的题目 ID 单独列出。
3. 后续同 3.2 的第 3 步起。

### 3.4 查看参考文档

1. 打开题组的评分细则文档或详解文档(F6),在页面内阅读,或下载为 Markdown 文件。

## 4. 数据对象

| 对象 | 内容 | 存放位置 |
|---|---|---|
| 题目 | 题库中的一条记录 | `data/caie.db`,只读 |
| 查询 | 一组已命名的筛选条件 | `paths.WORK` |
| 题组 | 名称;有序的题目 ID 列表;来源(查询、手选或导入);创建时间;备注 | `paths.WORK` |
| 题目卷 | 由题组生成的 PDF;题组内容变化后重新生成 | `paths.WORK` |
| 书写板 | 一份题目卷对应一块白板;笔迹以矢量保存,与题目卷 PDF 分开存放 | `paths.WORK` |
| 模板 | 一个模板文件(第 7 节) | 内置模板在仓库 `app/templates/`;用户模板在 `paths.WORK/templates/` |

`paths.WORK` 中的内容不进 `data/`,不随 `sync.py` 推送。

## 5. 功能需求

每项附验收标准。

### F1 查询

- 表格,每行一道题。可选列:试卷代码、题号、小问数、分值、主题、子主题、题型、有无图形、有无详解。
- 筛选条件:考试、卷别、变体、年份范围、考季、主题(多选)、分值范围、题型、有无详解。多个条件同时满足才列出。
- 搜索:全文搜索题干;按试卷代码定位,例如输入 `s23 12 q5`。
- 点击列头排序。
- 显示结果条数与分值合计。
- 当前筛选条件可以命名保存为查询。

验收:对全部 5937 道题,筛选与排序在 0.1 秒内完成;结果与在 `caie.db` 上执行等价 SQL 的结果一致。

### F2 单题详情

显示以下内容:

- 紧凑题图与带答题区题图,两者可切换;
- 题干文本与 LaTeX,可复制;
- 按小问的评分细则;
- 详解;
- 主题;
- 来源试卷与页码。可以打开原卷的对应页。

可以在详情中把这道题加入或移出当前题组。

验收:任意一道题的每个非空字段都能在详情中看到。

### F3 题组

- 创建方式有三种:从查询结果中勾选;把整个查询结果加入;导入题组 JSON。
- 在题组内可以调整顺序、移除题目、修改名称与备注。
- 题组列表显示名称、题数、总分、来源、创建时间。
- 题组可以导出为 JSON(`alevel-question-set/v1`)。

验收:导入一份 JSON 再导出,题目 ID 与顺序不变;刷新页面后题组仍在。

### F4 题目卷 PDF

- 由题组生成,版式见第 6 节。
- 题组恰好是一整份试卷时,使用原卷 PDF(来自 `data/papers/`)。
- 可下载。

验收:打印效果与原卷同等清晰;CIE 题的答题区与原卷一致。

### F5 iPad 书写

- 白板直接使用 white-board 仓库中文档板的实现,把代码复制进本项目:
  - 服务端:`whiteboard/docs.py`(PDF 页面渲染与导出)、`whiteboard/inkpdf.py`(笔迹写入 PDF)、`whiteboard/freehand.py`(笔迹轮廓);
  - 前端:文档板的显示与书写、工具栏、iPad 笔具盘。
- 在页面内打开一份题目卷即进入书写。笔迹实时保存,iPad 与 Mac 同步。
- 写完导出带笔迹的 PDF:笔迹作为矢量追加到原页面,原页面内容不重新编码。
- 一个题组的书写板列在题组页面中,显示最后修改时间,可以重新打开或导出。

验收:导出的 PDF 包含全部笔迹,位置与书写时一致;页面顺序与题组顺序一致。

### F6 参考文档

- 评分细则文档:题组中每道题按小问列出评分细则,公式正常显示。
- 详解文档:题组中有详解的题,按小问列出详解。
- 两种文档都可以在页面内阅读,也可以下载为 Markdown 文件。
- 两种文档都可以由模板选择放入资料包(F8 中的 `documents` 字段)。

验收:文档中每道题的评分细则与 F2 显示的内容一致。

### F7 资料包

- 输入:一个题组、一个模板,以及可选的作答文件(F5 导出的带笔迹 PDF,或拖入页面的照片)。
- 输出:一个 ZIP。其中的文件、目录结构、文件名与说明文字由模板决定(第 7 节)。
- 下载前显示预览:文件列表、清单内容、说明文字全文。
- 可以只复制说明文字,不下载 ZIP。

验收:模型只拿到资料包,就能完成模板说明文字中规定的任务,不需要询问题目内容、评分细则或文件对应关系。

### F8 模板

- 内置四套模板:判分、讲解、提问、整卷判分。
- 用户可以复制内置模板后修改,也可以新建。内置模板不可修改。
- 在页面内编辑模板。编辑器旁显示用当前题组生成的预览,修改后立即更新。
- 编辑器旁列出全部字段与占位符(第 7.2、7.3 节)。

验收:修改模板后预览立即更新;同一题组、同一模板、同一作答文件,重复生成的 ZIP 内容完全相同。

## 6. 题目卷版式

| 项目 | 规则 |
|---|---|
| CIE 题 | 使用带答题区的题图,只保留原卷的答题区,不另加空白。没有带答题区题图的题,答题区已经在紧凑题图中,使用紧凑题图 |
| 入学考选择题 | 使用紧凑题图,每题下方留半页空白作为作答区,一页两题 |
| 分页 | 每道 CIE 题从新的一页开始;一道题内部按原卷分页 |
| 页脚 | 题组名称、试卷代码与题号、页码 |
| 纸张 | A4;题图 150 dpi,按页宽排版 |
| 评分细则与详解 | 不放入题目卷 |

## 7. 模板格式

### 7.1 文件结构

一个模板是一个 UTF-8 文本文件,扩展名 `.md`,由两部分组成:

1. 设置区:文件开头,以单独一行 `---` 开始和结束,内容为 YAML;
2. 说明文字:设置区之后的全部文字,即放入资料包、交给模型的说明。说明文字中可以使用占位符(第 7.3 节)。

### 7.2 设置字段

| 字段 | 类型 | 取值 | 默认值 | 含义 |
|---|---|---|---|---|
| `name` | 文本 | 任意 | 必填 | 模板名称 |
| `per_question` | 列表 | `image`、`image_with_space`、`text`、`mark_scheme`、`explanation` | `[image]` | 每道题放入资料包的内容,按列出顺序排列。`image` 为紧凑题图;`image_with_space` 为带答题区题图,没有时用紧凑题图;`text` 为题干文本;`mark_scheme` 为该题评分细则(Markdown);`explanation` 为该题详解(Markdown) |
| `documents` | 列表 | `mark_scheme`、`explanation`、`question_paper` | `[]` | 放入资料包的整份文档:评分细则文档、详解文档(F6)、题目卷 PDF(F4) |
| `answers` | 文本 | `none`、`written_pdf`、`photos` | `none` | 作答文件来源:不附;F5 导出的带笔迹 PDF;拖入页面的照片 |
| `layout` | 文本 | `folder_per_question`、`flat` | `folder_per_question` | 每道题一个文件夹,或全部文件放在同一层 |
| `filename` | 文本 | 含占位符的文件名 | `{index:02}_{paper_code}_Q{q}` | 每道题的文件夹名(`folder_per_question`)或文件名前缀(`flat`) |
| `answer_filename` | 文本 | 含占位符的文件名 | `answers` | 作答文件的文件名;照片按 `{page:02}` 依次编号 |
| `manifest` | 布尔 | `true`、`false` | `true` | 是否附 `manifest.json`:题组名称、每题的 ID、试卷代码、分值、小问、主题、对应文件 |
| `summary` | 布尔 | `true`、`false` | `true` | 是否附 `summary.md`:题组的题目一览表 |
| `prompt_file` | 文本 | 文件名 | `README.md` | 说明文字在资料包中的文件名 |

### 7.3 占位符

| 占位符 | 含义 | 示例 |
|---|---|---|
| `{title}` | 题组名称 | `9709 P3 微分方程` |
| `{count}` | 题数 | `8` |
| `{total_marks}` | 总分 | `64` |
| `{papers}` | 涉及的试卷,以顿号分隔 | `9709/32/M/J/23、9709/31/O/N/22` |
| `{date}` | 生成日期 | `2026-10-02` |
| `{question_table}` | 题目一览表(Markdown 表格):序号、试卷代码、题号、分值、小问、主题、文件 | |
| `{file_tree}` | 资料包的目录结构 | |
| `{index}` | 题目序号,从 1 开始;`{index:02}` 补足两位 | `03` |
| `{paper_code}` | 试卷代码,斜线换成连字符 | `9709-12-MJ-23` |
| `{q}` | 题号 | `5` |
| `{id}` | 题目 ID | `9709_s23_12_q05` |
| `{page}` | 作答照片的页序号 | `01` |

`{index}`、`{paper_code}`、`{q}`、`{id}` 只用于 `filename`;`{page}` 只用于 `answer_filename`;其余用于说明文字。

### 7.4 示例:判分模板

```
---
name: 判分
per_question: [image_with_space, mark_scheme]
documents: []
answers: written_pdf
layout: folder_per_question
filename: "{index:02}_{paper_code}_Q{q}"
answer_filename: answers
manifest: true
summary: true
prompt_file: README.md
---
# {title}

本资料包包含 {count} 道题,满分合计 {total_marks} 分,题目来自 {papers}。

## 文件

{file_tree}

- 每个题目文件夹包含该题的题图与评分细则。
- answers.pdf 是全部作答,页面顺序与题目顺序相同。

## 题目

{question_table}

## 任务

按评分细则对每道题的每个小问逐个分码判分。

## 输出格式

1. 每道题一个表格,列为:小问、分码、是否给分、依据。依据写明作答中的对应步骤。
2. 每个表格之后写该题得分。
3. 全部题目之后写总分与失分最多的三个小问。
```

## 8. 设计

- 使用设计系统 ENDFIELD React(`https://claude.ai/artifact/Y7GzkWZhPQVDPaAWQf1Due`):
  - 组件从 `window.Endfield` 取用,包括 Table、Tabs、TopBar、Sidebar、List、Dialog、TextField、TextArea、Select、Checkbox、Tag、Toast、EmptyState、Pagination;
  - 样式来自它的 `bundle.css` 与 `tokens.css`;
  - 本页面属于设计系统中的"工作页",间距按工作页的规定。
- F5 的书写界面使用 white-board 的界面与工具栏,与设计系统分开。
- React、组件包与字体文件复制进项目,页面不依赖外网。
- 页面结构:
  - 顶栏:考试切换、搜索;
  - 侧边导航:查询、题组、模板;
  - 主区:表格,或题组内容;
  - 右栏:当前题的详情。
- 本文件确认后,单独给出设计稿。
