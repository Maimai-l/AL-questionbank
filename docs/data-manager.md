# 题库数据管理页面:需求说明

状态:第二稿,待确认。确认前不开始实现。

## 1. 背景

### 1.1 题库现状

| 项目 | 数量 |
|---|---|
| 考试 | 9709、9231、9618(CAIE A Level),TMUA、TSA、BMAT(入学考试) |
| 题目 | 5937 道,每道一条记录。ID 形如 `9709_s23_12_q05`、`TMUA-2023-P1-q1` |
| 题图 | 每题一张紧凑题图;2885 道 CAIE 题另有带答题区的题图 |
| 评分细则 | 5936 道有,按小问切开 |
| 详解 | 874 道(9618 卷 1–3) |
| 原卷与细则 PDF | 现在只在本机 `raw/pdf/`、`raw/ms/`(共 688 MB);将放进 `data/papers/` |

### 1.2 使用方式

- 刷整卷:打印原卷,纸上作答。
- 刷专题:按主题选题,打印出来作答。以后可能改为放进 white-board 作答,本期不做。
- 判分与讲解:交给模型。交给模型的资料要一次交齐,不来回补充。
- 题库数据:由 Claude 用 pipeline 维护,包括数据质量检查与修正。你只使用数据,不维护数据。

### 1.3 要做什么

做一个只读的数据管理页面,让你能做三件事:

- 查到任何一道题的任何数据;
- 把需要的题组成题组;
- 由题组导出符合要求的文件。

其中最需要花时间打磨的是导出:导出的内容、版式和打包方式,每次都要正好符合当次的用途。

## 2. 范围

### 2.1 做

| 编号 | 内容 |
|---|---|
| F1 | 查询:全部题目的表格、筛选、搜索、排序 |
| F2 | 单题详情:一道题的全部数据 |
| F3 | 题组:由查询或手选组成,有名字,会保存;也能导入模型给出的题组 JSON |
| F4 | 打印 PDF:题目卷、整卷、评分细则 |
| F5 | 模型资料包:按模板打包成 ZIP,附给模型的说明 |
| F6 | 导出模板:由你设计和修改,决定资料包的内容、命名与说明文字 |

### 2.2 不做

- 不修改题库。页面对 `data/caie.db` 只读。
- 不检查数据质量。这项工作由 Claude 用 pipeline 完成,不放进页面,也不需要你处理。
- 不记录作答与成绩。成绩随资料包交给模型,由模型记录。
- 不做网页作答与判分。
- 白板作答本期不做。之前的练习页(`app/web/`)暂停使用。

## 3. 使用流程

### 3.1 刷整卷

1. 查询找到一份试卷,例如 `9709/12/M/J/23`。
2. 打印原卷 PDF(F4 整卷)。
3. 纸上作答,拍照。
4. 用"判分"模板导出这份试卷的资料包(F5),连同照片交给模型。

### 3.2 刷专题

1. 按条件查询,例如"9709 卷 3,主题 3.8,2021 年以后"。
2. 勾选题目,组成题组并命名。
3. 打印题目卷(F4 题目卷)。
4. 纸上作答,拍照。
5. 用"判分"模板导出题组的资料包,连同照片交给模型。

### 3.3 由模型出题组

1. 模型按你的要求选题,返回题组 JSON(格式 `alevel-question-set/v1`)。
2. 页面导入 JSON,成为一个题组。题库中找不到的 ID 会单独列出。
3. 后续同 3.2 的第 3 步起。

### 3.4 问几道题

1. 选几道题组成临时题组。
2. 用"讲解"或"提问"模板导出资料包,或者直接复制资料包里的说明文字和题目文本。

## 4. 核心对象

| 对象 | 内容 | 存放 |
|---|---|---|
| 题目 | 题库中的一条记录 | `data/caie.db`,只读 |
| 查询 | 一组筛选条件,可以命名保存 | `paths.WORK` |
| 题组 | 名称、有序的题目 ID 列表、来源(查询、手选或导入)、创建时间、备注 | `paths.WORK` |
| 模板 | 一个导出模板文件(第 7 节) | 内置模板在仓库,你的模板在 `paths.WORK` |

查询、题组和你的模板属于个人数据,不进 `data/`,也不随 `sync.py` 推送。

## 5. 功能需求

每项后面附验收标准。

### F1 查询

- 表格,每行一道题。可选的列:试卷代码、题号、小问数、分值、主题、子主题、题型、有无图形、有无详解。
- 筛选条件:考试、卷别、变体、年份范围、考季、主题(多选)、分值范围、题型、有无详解,条件之间取"并且"。
- 搜索:全文搜索题干;输入试卷代码直接跳到题,例如 `s23 12 q5`。
- 点列头排序。
- 实时显示结果条数与分值合计。
- 当前查询可以命名保存。

验收:对全部 5937 道题,筛选与排序在 0.1 秒内完成;结果与在 `caie.db` 上执行等价 SQL 的结果一致。

### F2 单题详情

显示一道题的全部字段:

- 紧凑题图与带答题区题图,可切换;
- 题干文本与 LaTeX,可复制;
- 按小问的评分细则;
- 详解;
- 主题;
- 来源原卷与页码,可打开原卷对应页。

在详情中可以直接把题加入或移出当前题组。

验收:任意一道题的每个非空字段都能在详情中看到。

### F3 题组

- 三种创建方式:从查询结果勾选;把整个查询结果加入;导入题组 JSON。
- 在题组内调整顺序、移除题目、改名、写备注。
- 题组列表显示名称、题数、总分、来源、创建时间。
- 导出题组 JSON(`alevel-question-set/v1`)。

验收:导入一份 JSON 再导出,题目 ID 和顺序不变;刷新页面后题组仍在。

### F4 打印 PDF

题目卷:由题组生成。版式见第 6 节。

整卷:

- 题组正好是一整份试卷时,可以直接输出原卷 PDF(来自 `data/papers/`)。
- 可以另外输出该卷评分细则的原件 PDF。

评分细则:

- 题目卷之外,单独生成一份对应的评分细则,方便打印后对照。

验收:打印效果与原卷同等清晰;CIE 题的答题区与原卷一致。

### F5 模型资料包

- 由一个题组和一个模板生成 ZIP。
- 资料包里有什么、文件怎样命名、说明文字写什么,全部由模板决定(第 7 节)。
- 下载之前可以预览:文件列表、清单内容、说明文字。
- 可以只复制说明文字或题目文本,不下载 ZIP(第 3.4 节的用法)。
- 可以把作答照片拖进页面,与资料包打在一起,并按模板规定的名字重命名(见第 9 节问题 A)。

验收:模型只拿到资料包,就能按题号和小问逐项判分或讲解,不需要追问题目内容、评分细则或文件对应关系。

### F6 导出模板

- 内置几套模板:判分、讲解、提问、整卷判分。
- 你可以复制一套内置模板,改成自己的,也可以新建。
- 页面上提供编辑器:一边改模板,一边用当前题组实时预览生成的结果。
- 模板就是文件。也可以用任意文本编辑器修改,页面会读到最新内容。

验收:修改模板后,预览立即反映;用同一题组和同一模板重复导出,结果完全相同。

## 6. 题目卷版式

| 情况 | 版式 |
|---|---|
| CIE 题 | 使用带答题区的题图,只保留原卷的答题区,不另外加空白;没有带答题区题图的题(原卷答题区已在紧凑题图里)用紧凑题图 |
| 入学考选择题 | 使用紧凑题图,每题下方留出固定高度的空白作答区(高度见第 9 节问题 C) |
| 分页 | 每道 CIE 题从新的一页开始;一道题内部的页面按原卷的分页 |
| 页眉页脚 | 页脚印题组名、试卷代码与题号、页码 |
| 尺寸 | A4;题图 150 dpi,按页宽排版 |

## 7. 导出模板

### 7.1 模板决定的内容

| 项目 | 例子 |
|---|---|
| 每题包含哪些内容 | 题图(紧凑或带答题区)、题干文本、评分细则、详解 |
| 文件组织 | 每题一个文件夹,或全部平铺 |
| 文件命名 | `{序号}_{试卷代码}_Q{题号}`,例如 `03_9709-12-MJ23_Q5.png` |
| 清单 | 是否附 `manifest.json`,以及包含哪些字段 |
| 题组汇总 | 是否附一份汇总文本:每题的试卷代码、分值、小问、主题 |
| 说明文字 | 给模型的话,写明任务(判分、讲解、出题)、文件对应关系和输出要求 |
| 作答文件 | 是否要求附作答照片,以及照片的命名规则 |

### 7.2 模板的样子

一个模板就是一个文件:开头是设置,后面是说明文字的正文。正文中可以引用题组的信息。示例:

```
---
名称: 判分
每题内容: [带答题区题图, 评分细则]
文件组织: 每题一个文件夹
命名: "{序号:02}_{试卷代码}_Q{题号}"
附清单: 是
附作答: 是,命名为 "{序号:02}_作答_{页}"
---
以下是 {题数} 道题,共 {总分} 分,来自 {试卷列表}。
每个文件夹是一道题:题图、评分细则,以及我的作答照片。
请按评分细则逐个小问判分,写出每个分码给或不给的理由,最后给出总分。
{题目列表}
```

- `{题数}`、`{总分}`、`{题目列表}` 等占位符由页面在导出时填入。
- 可用的占位符在编辑器旁边列出。

## 8. 设计

- 采用你新做的设计系统 ENDFIELD React(`https://claude.ai/artifact/Y7GzkWZhPQVDPaAWQf1Due`):
  - 组件从 `window.Endfield` 取用(Table、Tabs、TopBar、Sidebar、List、Dialog、TextField、Select、Checkbox、Tag、Toast、EmptyState、Pagination 等);
  - 样式全部来自它的 `bundle.css` 与 `tokens.css`;
  - 页面属于设计系统中的"工作页",间距按工作页一栏的规定。
- 设计系统的 React、组件包和字体文件复制进项目,页面不依赖外网。
- 页面结构草案:
  - 顶栏:考试切换、搜索;
  - 侧边导航:查询、题组、模板;
  - 主区:表格或题组内容;
  - 右侧:当前题的详情。
- 设计稿在本文件确认后单独给出。

## 10. 分期

| 阶段 | 内容 |
|---|---|
| 1 | F1 查询、F2 详情、F3 题组 |

每个阶段完成后给你预览,确认后再进入下一阶段。
