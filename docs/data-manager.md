# 题库数据管理页面:需求说明

状态:第三稿,待确认。确认前不开始实现。

## 1. 背景

### 1.1 题库现状

| 项目 | 数量 |
|---|---|
| 考试 | 9709、9231、9618(CAIE A Level);TMUA、TSA、BMAT(入学考试) |
| 题目 | 5937 道,每道一条记录。题目 ID 形如 `9709_s23_12_q05`、`TMUA-2023-P1-q1` |
| 题图 | 每题一张紧凑题图;2885 道 CAIE 题另有带答题区的题图 |
| 评分细则 | 5936 道有,按小问切开 |
| 详解 | 874 道(9618 卷 1–3) |
| 原卷与细则 PDF | 现在只在本机 `raw/pdf/`、`raw/ms/`,共 688 MB;将放进 `data/papers/` |

### 1.2 使用方式

- 作答在纸上或 iPad 上进行。纸上作答时打印题目卷;iPad 上作答时,在本页面内用白板直接在题目卷上书写。
- 批改与讲解交给模型。交给模型的资料一次交齐,不来回补充。
- 题库数据由 Claude 用 pipeline 维护,包括数据质量的检查与修正。

### 1.3 要做什么

一个在 Mac 上运行、iPad 通过局域网访问的本地服务,提供以下功能:

1. 查询题库中任何一道题的任何数据;
2. 把选中的题组成题组;
3. 由题组生成题目卷 PDF,用于下载打印或在 iPad 上书写;
4. 按导出选项把题组、作答与说明打包为 ZIP;按节点图批量生成。

导出(第 3、4 项)是需要反复打磨的重点。

## 3. 使用流程

### 3.1 刷整卷

1. 在查询中找到一份试卷,例如 `9709/12/M/J/23`,把整卷加入一个新题组。
2. 生成题目卷。整卷题组直接使用原卷 PDF。
3. 作答,二选一:
   - 下载 PDF,打印,纸上作答,拍照;
   - 在 iPad 上打开页面,用白板在题目卷上书写,导出带笔迹的 PDF。
4. 下载压缩包,交给模型。

### 3.2 刷专题

1. 按条件查询,例如"9709 卷 3,主题 3.8,2021 年及以后"。
2. 勾选题目,组成题组并命名。
3. 生成题目卷(版式见第 6 节)。
4. 后续同 3.1 的第 3、4 步。

### 3.3 由模型出题组

1. 模型按要求选题,返回题组 JSON(格式 `alevel-question-set/v1`)。
2. 在页面导入,成为一个题组。题库中不存在的题目 ID 单独列出。
3. 后续同 3.2 的第 3 步起。

### 3.4 查看评分细则与详解

1. 打开题组的评分细则文档或详解文档(F6),在页面内阅读,或下载为 HTML 文件。

## 4. 数据对象

| 对象 | 内容 | 存放位置 |
|---|---|---|
| 题目 | 题库中的一条记录 | `data/caie.db`,只读 |
| 题组 | 名称;有序的题目 ID 列表;来源(查询、手选或导入);创建时间 | `paths.WORK` |
| 题目卷 | 由题组生成的 PDF;题组内容变化后重新生成 | `paths.WORK` |
| 书写板 | 一份题目卷对应一块白板;笔迹以矢量保存,与题目卷 PDF 分开存放 | `paths.WORK` |
| 模板 | 一个模板文件(第 7 节) | 内置模板在仓库 `manager/templates/`;用户模板在 `paths.WORK/templates/` |

`paths.WORK` 中的内容不进 `data/`,不随 `sync.py` 推送。

## 5. 功能需求

每项附验收标准。

### F1 查询

- 表格,每行一道题。默认列:年份、考季、卷号、题号、小问数、分值;考季写作"3 月""6 月""11 月"。可加列:主题、子主题、有无图形、有无详解。筛选后所有行取值相同的列不显示。
- 筛选条件:考试、试卷、变体、年份范围、考季、主题(多选)、分值范围、小问类型(求解、证明、解释等,取自评分细则的任务类型,按 `docs/ui-text.md` 第 3.1 节显示)、有无详解。多个条件同时满足才列出。
- 搜索:搜索框在表格上方的工具栏左侧(右侧为已选题数与「加入题组」)。输入时即搜索(停顿 0.25 秒),Esc 或框旁的清除按钮清空。
  - 试卷代码(`s23 12 q5`、`9709/12/M/J/23 Q5`)直接列出该卷或该题,不受左侧条件限制,只有一题时在右侧显示详情。
  - 其他输入是关键词,在当前考试的题干、评分细则与主题名中查找,结果再按左侧条件筛选。每个词都须出现(可为词首,`integr`、`integrat` 都匹配 integration:索引按 porter 词干存储,词首短于词干时,查询同时找以该词首开头的原词的词干);
    `"geometric progression"` 按短语查;两个词之间写 OR 表示任一;带标点的词(`x-axis`、`10.5`)按其各部分相连查找。
  - 左侧试卷与主题的计数随搜索与年份范围变化,显示各项中符合搜索的题数。
- 点击列头排序。
- 显示结果条数与分值合计。
- 选中:点击选中该行(取代原有选中),Cmd/Ctrl 点击加选或取消,Shift 点击选中到上次点击的行,按住拖过多行选中一段。
  方向键移动,Shift+方向键扩展,空格切换,Cmd/Ctrl+A 全选,Esc 清除。最后点击的行在右侧显示详情。
  表头左侧的方块全选当前结果。显示已选题数与分值合计。

验收:对全部 5937 道题,筛选与排序在 0.1 秒内完成;结果与在 `caie.db` 上执行等价 SQL 的结果一致。

### F2 单题详情

显示以下内容:

- 紧凑题图与带答题区题图,两者可切换;
- 题干文本与 LaTeX,可复制;
- 按小问的评分细则,公式按 LaTeX 渲染;
- 详解;
- 主题;
- 来源试卷与页码。可以打开原卷的对应页。

可以在详情中把这道题加入或移出当前题组。

验收:任意一道题的每个非空字段都能在详情中看到。

### F3 题组

- 创建方式有三种:从查询结果中勾选;把整个查询结果加入;导入题组 JSON。
- 在题组内可以调整顺序、移除题目、修改名称。名称在标题处直接编辑:点铅笔图标或双击标题,Enter 或移开焦点保存,Esc 放弃。
  新建题组后标题直接进入编辑状态。
- 题组列表显示名称、题数、总分、来源、创建时间。
- 题组可以导出为 JSON(`alevel-question-set/v1`)。
- 题组页(2026-10-02 改版):
  - 左栏为题组列表,列表顶部为「新建题组」「导入 JSON」。
  - 详情区顶部为标题栏:左侧是题组名称、题数与分值、作答状态(未作答,或已作答与最后书写时间);
    右侧是「打开白板」「输出」与「更多」(打开评分细则、打开详解、导出 JSON、删除题组)。
    白板上还没有笔迹时「打开白板」是主要按钮,有笔迹后「输出」是主要按钮。
  - 标题栏下方左侧是练习卷的全部页面,右侧是题目列表;「编辑」切换为表格,可选中题目上移、下移、移出。
  - 「输出」打开对话框:选择预设(即导出模板),需要时「调整格式与内容」(只用于这一次,不改模板),
    对话框列出将要下载的文件,下载 PDF 或 ZIP。没有笔迹时默认预设为「练习卷 PDF」,有笔迹时为「交给模型」。
- 练习卷、评分细则与详解随题组内容自动更新,没有单独的生成步骤。

验收:导入一份 JSON 再导出,题目 ID 与顺序不变;刷新页面后题组仍在。

### F4 题目卷 PDF

- 由题组生成,版式见第 6 节。
- 题组恰好是一整份试卷时,使用原卷 PDF(来自 `data/papers/`)。
- 可下载。

验收:打印效果与原卷同等清晰;CIE 题的答题区与原卷一致。

### F5 iPad 书写

- 白板直接使用 white-board 仓库中文档板的实现,把代码复制进本项目:
  - 服务端:`whiteboard/docs.py`(PDF 页面渲染与导出)、`whiteboard/inkpdf.py`(笔迹写入 PDF)、`whiteboard/freehand.py`(笔迹轮廓);
  - 前端:文档板的显示与书写、工具栏、iPad 笔具盘。
- 在页面内打开一份题目卷即进入书写。笔迹实时保存,iPad 与 Mac 同步。
- 写完导出带笔迹的 PDF:笔迹作为矢量追加到原页面,原页面内容不重新编码。导出全部页面。
- 导出时可以勾选同时导出评分细则文档与详解文档(F6)。导出的文件自动列入题组的输出。
- 一个题组的书写板列在题组页面中,显示最后修改时间,可以重新打开或导出。

验收:导出的 PDF 包含全部笔迹,位置与书写时一致;页面顺序与题组顺序一致。

实现(2026-10-02):

- 同步与保存用 white-board 的 inksync(复制在 `manager/vendor/inksync/`),挂在数据管理页的服务上(`/ws`、`/inksync/`);
  白板存在 `paths.BOARDS`(`paths.WORK/boards/`,与刷题服务 `app/` 的 `paths.INK` 分开)。iPad 外壳的「来源」填 `@qb-manage`(刷题服务 `app/` 是 `@qb`)。
- 每一版题目卷一块白板,ID 为题目卷的缓存名(`<题组 ID>-<键>`);新建时把题目卷 PDF 复制到 `paths.BOARDS` 下的 `papers/`,
  题组之后修改不影响已有白板。页面排布与 white-board 的文档板相同(页距 24 pt,按最宽一页居中)。
- 书写页 `/write/<白板 ID>`:白板应用的工具栏与 iPad 笔具盘(`manager/web/board/`)。
  Mac 上从题组页「打开白板」进入 `#/sets/<题组 ID>/board/<白板 ID>`:数据管理页的侧边导航与顶栏不变,顶栏为路径、
  当前页的题号与页码、「完成」(回到题组页);白板以 `/write/<白板 ID>?embed=1` 嵌入内容区的圆角框,框内保持白板应用原样。
  直接打开 `/write/<白板 ID>` 时仍是独立页面,顶栏为返回、题组名、题号与页码、导出 PDF。
  iPad 上没有顶栏,也没有任何导出入口,只显示画布与笔具盘;在 iPad 外壳中右上角保留「白板设置」,其中的「换一台 Mac」用于选择服务器。
- 数据管理页只在电脑的浏览器上使用,窗口宽度低于 1280 时整页横向滚动,不为触屏或窄屏另作排版。iPad 只作为白板的书写终端。
- iPad 外壳打开 `/ipad`:只显示书写页,跟随 Mac。Mac 上点「打开白板」后,该白板成为当前白板(记在 `paths.BOARDS` 下的 `current.json`),
  iPad 随即切换到它;没有当前白板时显示等待页。跟随模式的书写页不显示返回按钮。页面标签按题目卷实际排布生成:
  整卷原样拼接时按原卷页码标注,重新排版时按排版结果标注。
- 导出把笔迹作为新的内容流追加到页面上,原有内容流不改(`manager/whiteboard/docs.py`,用 PyMuPDF 实现 white-board
  中 pypdf 的做法)。最近一次导出存为 `paths.WORK/answers/<题组 ID>.pdf`,即导出压缩包中的批注版。

### F6 评分细则与详解

- 评分细则文档:题组中每道题按小问列出评分细则,公式正常显示。
- 详解文档:题组中有详解的题,按小问列出详解。
- 两种文档都可以在页面内阅读,也可以下载为 HTML 文件;公式按 LaTeX 渲染。
- 两种文档都可以由模板选择放入压缩包(F8 中的 `documents` 字段)。

验收:文档中每道题的评分细则与 F2 显示的内容一致。

### F7 导出

- 题组页的「输出」打开输出对话框:选择导出模板(F8),需要时调整格式与内容,对话框列出将生成的文件,确认后下载 PDF 或 ZIP。
  没有单独的导出页与练习卷页。
- 导出选项(`docs/ui-text.md` 第 2.3 节):
  - 格式:PDF / ZIP / 图片 ZIP;PDF 时选择练习卷或批注版;
  - 每道题包含:题目截图、截图保留原卷答题区、题干文字、评分细则、详解;
  - 压缩包包含:练习卷、批注版、README.md;
  - 文件结构:按题分文件夹 / 不分文件夹。
- 一组选项加一份 README 文字保存为一个导出模板,在模板页编辑与预览。

验收:同一题组、同一组选项、同一作答文件,重复导出的 ZIP 内容完全相同。

### F8 导出模板

- 一个导出模板是一组 F7 选项加一份 README 文字(第 7 节)。
- 只内置"默认":题图(含答题区)、评分细则、作答 PDF、每题一个文件夹、附 README;README 只列文件和题目,不写任务说明。
- 用户在模板页新建、复制、修改导出模板;README 编辑器可以插入占位符,并用一个题组预览。

验收:修改模板后预览立即更新。

### F9 批量生成

用节点图描述一次批量生成,界面参照 Grasshopper:左侧是节点列表,中间是画布,右侧是选中节点的参数与运行结果。

数据只有两种形状:

- 列表:一串记录。端口为圆形,连线为细线。
- 分组:若干个有名称的列表。端口为方形,连线为粗线。

记录有两类:题目(字段:考试、试卷、卷号、年份、考季、题号、卷内位置、分值、小问数、主题、子主题、含图、有详解)与章节(字段:教材、章号、标题、主题、PDF)。卷内位置等于题号除以该卷最大题号,取值 0 到 1。

节点:

| 类别 | 节点 | 输入 | 输出 | 参数 |
|---|---|---|---|---|
| 来源 | 题库 | | 题目列表 | 考试(一门或全部) |
| 来源 | 教材 | | 章节列表、章节 PDF | 教材 |
| 来源 | 题组 | | 题目列表 | 题组 |
| 处理 | 筛选 | 列表 | 列表 | 若干条件,全部满足才保留。条件的写法由字段决定:数值字段(年份、题号、卷内位置、分值、小问数、章号)填最小与最大,可只填一端;取值固定的字段(考试、试卷、卷号、考季、主题、子主题、教材)选「是」或「不是」,再从输入数据中出现的值里选一个;文字字段(标题、文件名)填「包含」的文字;是否字段在两个选项中选一个(含图 / 不含图,有详解 / 无详解) |
| 处理 | 排序 | 列表 | 列表 | 依据字段(升序或降序),或随机(种子) |
| 处理 | 限制数量 | 列表 | 列表 | 条数 |
| 处理 | 分组 | 列表 | 分组 | 字段 |
| 处理 | 合并 | 分组 | 列表 | |
| 处理 | 连接 | 左列表、右列表 | 分组 | 左侧字段、右侧字段;左侧每条记录一组,组内为字段值相等的右侧记录 |
| 输出 | 导出 | 列表或分组、附件 | ZIP | 导出模板;分组时每组一个文件夹 |
| 输出 | 新建题组 | 列表或分组 | 题组 | 题组名称为流程名称;分组时每组一个题组,名称后加组名 |
| 输出 | 练习卷 | 列表或分组 | PDF | 版式(第 6 节);分组时每组一份 |
| 输出 | 章节包 | 题目列表(分组时合并) | 每章一个 ZIP | 教材(一本或全部教材)。逐章遍历所选教材,每章收入输入题目中属于该章主题的题(只有部分小问属于该主题的题也收入),与 `pipeline/export/export_all_chapters.py` 同一格式(章节正文与插图、配套真题、题图、评分细则),写入 `exports/chapters/<考试>/<教材>_<两位章号>_<标题>.zip`(9231、9618、9709 三个文件夹,9709 的四本教材同在 `9709/`)并替换同名文件,旧版按教材分散的同一章文件一并删除 |

规则:

- 处理列表的节点接到分组上时,对每组分别处理,输出仍是分组。例如"分组 → 排序(随机) → 限制数量 2"是每组随机取 2 题;要对全部题目处理,先接"合并"。
- 端口只能连接记录类型相同的端口;类型不符时不能连线。
- 随机排序使用种子,同一种子、同一份题库得到相同结果;改种子得到另一种顺序。
- 每个输出端口旁显示条数,分组显示组数;选中节点后右侧显示其输出的明细。
- 点击"运行流程"执行整张图。画布下方的"输出"区列出每个输出节点的结果:文件可以直接下载,题组可以直接打开。输出节点没有输出端口。
- 一张图保存为一个批量生成模板,存放在 `paths.WORK/flows/`。

## 6. 练习卷版式

所有考试的练习卷用同一套版式（`docs/ui-text.md` 第 4.8 节），没有切换选项。

| 项目 | 规则 |
|---|---|
| 排列 | 题目按题组顺序从上到下连续排列，题与题之间 24 pt。剩余高度放不下下一题时换页，一道题不拆到两页；只有一题高于整页时，才在页底附近最空白的一行切开 |
| CIE 题 | 使用带答题区的题图。原卷没有答题区的题（另附答题册的试卷），题图下方 8 pt 处补加答题线，每分两行，行距 24 pt |
| 入学考试的题 | 使用紧凑题图，与 CIE 题按同一间距排列 |
| 页边距 | 左右与上 40 pt，下 56 pt（含页脚） |
| 页脚 | 8 pt，基线距纸张下缘 24 pt。题组名称、试卷代码与题号、页码三项，各自可以在设置页关闭 |
| 纸张 | 固定为 A4;题图 150 dpi,按页宽排版 |
| 评分细则与详解 | 不放入练习卷 |

设置页左侧为「页脚显示」与「配色」，右侧为第一个有题目的题组的练习卷预览，随页脚选项更新。设置页的入口在侧边导航底部的工具区。

## 7. 模板格式

### 7.1 文件结构

一个模板是一个 UTF-8 文本文件,扩展名 `.md`,由两部分组成:

1. 设置区:文件开头,以单独一行 `---` 开始和结束,内容为 YAML;
2. 说明文字:设置区之后的全部文字,即放入压缩包、交给模型的说明。说明文字中可以使用占位符(第 7.3 节)。

### 7.2 设置字段

| 字段 | 类型 | 取值 | 默认值 | 含义 |
|---|---|---|---|---|
| `name` | 文本 | 按第 7.5 节的规则 | 必填 | 模板名称 |
| `per_question` | 列表 | `image`、`image_with_space`、`text`、`mark_scheme`、`explanation` | `[image]` | 每道题放入压缩包的内容,按列出顺序排列。`image` 为紧凑题图;`image_with_space` 为带答题区题图,没有时用紧凑题图;`text` 为题干文本;`mark_scheme` 为该题评分细则(Markdown);`explanation` 为该题详解(Markdown) |
| `documents` | 列表 | `mark_scheme`、`explanation`、`question_paper` | `[]` | 放入压缩包的整份文档:评分细则文档、详解文档(F6)、题目卷 PDF(F4) |
| `answers` | 文本 | `none`、`written_pdf` | `none` | 是否放入批注版 |
| `format` | 文本 | `pdf`、`zip`、`images` | `zip` | `pdf`:一个 PDF(有笔迹且选了批注版时为批注版,否则为练习卷);`zip`:压缩包;`images`:压缩包,其中的 PDF(练习卷、批注版)按页拆成灰度 JPEG,每张不超过 100 KB,文件夹名为原文件名。界面上「格式」只有 PDF 与 ZIP 两项,`images` 是 ZIP 下勾选「PDF 按页拆成图片」 |
| `layout` | 文本 | `folder_per_question`、`flat` | `folder_per_question` | 每道题一个文件夹,或全部文件放在同一层 |
| `filename` | 文本 | 含占位符的文件名 | `{index:02}_{paper_code}_Q{q}` | 每道题的文件夹名(`folder_per_question`)或文件名前缀(`flat`) |
| `answer_filename` | 文本 | 文件名 | `批注版` | 批注版在压缩包中的文件名 |
| `manifest` | 布尔 | `true`、`false` | `true` | 是否附 `manifest.json`:题组名称、每题的 ID、试卷代码、分值、小问、主题、对应文件 |
| `summary` | 布尔 | `true`、`false` | `true` | 是否附 `summary.md`:题组的题目一览表 |
| `prompt_file` | 文本 | 文件名 | `README.md` | 说明文字在压缩包中的文件名 |

压缩包中每道题的文件名固定:`question.png`(题图)、`question.md`(题干文字)、`mark_scheme.md`
(评分细则,CIE 为 Answer | Mark | Guidance 三列表格)、`explanation.md`(详解)。`layout: flat` 时以
`filename` 的结果加下划线作前缀。没有评分细则或详解的题不生成对应文件。批注版取自
`paths.WORK/answers/<题组 ID>.pdf`(F5 写入),不存在时不放入。`manifest.json` 的格式为 `alevel-export/v1`。

### 7.3 占位符

| 占位符 | 含义 | 示例 |
|---|---|---|
| `{title}` | 题组名称 | `9709 Paper 3 Differential equations 2021-2026` |
| `{count}` | 题数 | `8` |
| `{total_marks}` | 总分 | `64` |
| `{papers}` | 涉及的试卷,以顿号分隔 | `9709/32/M/J/23、9709/31/O/N/22` |
| `{date}` | 题组的创建日期(使重复导出的结果相同) | `2026-10-02` |
| `{question_table}` | 题目一览表(Markdown 表格):序号、试卷代码、题号、分值、主题 | |
| `{file_tree}` | 压缩包的目录结构 | |
| `{index}` | 题目序号,从 1 开始;`{index:02}` 补足两位 | `03` |
| `{paper_code}` | 试卷代码,斜线换成连字符 | `9709-12-M-J-23` |
| `{q}` | 题号 | `5` |
| `{id}` | 题目 ID | `9709_s23_12_q05` |

`{index}`、`{paper_code}`、`{q}`、`{id}` 只用于 `filename`;其余用于说明文字。

### 7.4 默认模板

```
---
name: 题目与评分细则
per_question: [image_with_space, mark_scheme]
documents: []
answers: none
layout: folder_per_question
filename: "{index:02}_{paper_code}_Q{q}"
answer_filename: 批注版
manifest: true
summary: false
prompt_file: README.md
---
# {title}

{count} 题,满分 {total_marks} 分,来自 {papers}。

## 文件

{file_tree}

## 题目

{question_table}
```

### 7.5 命名规则

页面中的名称一律按以下格式书写,不使用空格以外的分隔符号,不使用全角空格。

| 对象 | 格式 | 示例 |
|---|---|---|
| 题组:整卷 | 试卷代码 | `9709/12/M/J/23` |
| 题组:来自查询 | 考试、主题(大纲编号与名称)、起止年份,以空格分隔;多个主题以顿号分隔,没有主题条件时用试卷代替主题 | `9709 1.8 Integration 2025-2026` |
| 题组:导入 | "导入"加导入日期;同一天多次导入时依次加 2、3 | `导入 2026-10-01` |
| 日期与时间 | `YYYY-MM-DD HH:MM` | `2026-10-02 09:12` |

题组名称由来源自动生成,可以修改;修改后的名称仍按上表格式校验。
