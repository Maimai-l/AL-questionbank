# 数据管理页 1.0.0

发布日期：2026-10-03。`stable` 分支与标签 `v1.0.0` 指向这一版本。需求与设计见 `docs/data-manager.md`，界面文字规范见 `docs/ui-text.md`。

## 安装与启动

```bash
pip install -r manager/requirements.txt     # 可选依赖见该文件
python3 sync.py pull                        # 取回 data/(题库、题图、原卷)
python3 manage.py                           # 在浏览器中打开,端口 8910
python3 manage.py window                    # 在独立窗口中打开(需要 pywebview);macOS 可双击 manage.command
python3 manage.py auto                      # 题库更新后运行自动流程
```

iPad 只通过白板外壳访问，来源填 `@qb-manage`。

## 功能

| 页面 | 内容 |
|---|---|
| 查询 | 按考试列出全部题目，按试卷、年份、主题、小问类型筛选，表格上方搜索；选中题目加入题组；右侧为题目详情 |
| 搜索 | 一次搜全部考试；左栏为高级搜索(考试、试卷、主题、年份、关键词四种写法、查找位置、小问类型、详解);命中处标出关键词；最近搜索 |
| 题组 | 新建、改名、排序、移出、复制、删除；导入与导出 JSON;练习卷预览；评分细则与详解阅读文档；输出(PDF、ZIP、PDF 拆页图片);白板 |
| 白板 | 在练习卷上书写(Mac 与 iPad 同步),导出带笔迹的 PDF;批注版可放进 ZIP |
| 模板 | 导出模板的新建、修改(随改随存)、复制、删除；README 预览；内置模板只读 |
| 批量生成 | 节点图：题库、教材、题组 → 筛选、排序、限制数量、分组、合并、连接 → 导出、新建题组、练习卷、章节包；运行、上次输出；内置流程只读；「全部 章节包」在题库更新后自动运行 |
| 设置 | 版面默认档、页脚三项、配色；右侧为练习卷预览 |

练习卷的作答空间由「版面」调节，四档，两端标「紧凑」「宽松」:只排题目；原卷答题区的四分之一；一半；原卷答题区。小问之间的答题线同样按档缩减，题干不切开。

## 自 0.1.0 以来的变化

**运行方式**
- 数据管理页改为独立脚本 `manage.py`(原 `qb.py manage` 已去掉);`manage.py window` 在 pywebview 窗口中打开，macOS 可双击 `manage.command`。
- macOS 窗口：页面延伸到标题栏，顶栏与背景一体；窗口显示前即放入网页视图，打开时不再黑屏；标题栏高度内(窗口按钮除外)按住可拖动，非活动窗口第一次按下也能拖动，双击按系统设置缩放或最小化。
- 载入动画按固定节奏上升(约 1.3 秒),主线程繁忙时暂停而不跳跃；查询页的表格在动画结束后绘制。
- `sync.py pull` 在题库更新后运行自动流程(`--no-auto` 跳过)。

**查询与搜索**
- 新增搜索页(`#/search`)。查询页的搜索框移到表格上方工具栏；词首短于词干时也能搜到。
- 页面上不再显示分值与分值合计。

**练习卷**
- 「版面」四档取代固定的版式；设置页定默认，输出时可另选。
- 小问之间的答题线按像素识别，随版面缩减。
- 生成提速：题图解码一次后直接写入压缩的灰度图像，字体全文共用一份。
- 设置页预览只排前 6 题，预先生成各页脚组合与相邻档位，切换选项不再等待。

**题组与白板**
- 超过约 115 页的练习卷也能建白板(上限 1000 页,超过时给出提示而不是报错)。
- 题组页的练习卷预览只加载可见附近的页面，「打开白板」不再排队等待。
- 白板顶栏的题号按当前版面计算。

**批量生成**
- 新增「章节包」输出节点，按考试写入 `exports/chapters/{9231,9618,9709}/`;题库可选全部考试。
- 筛选条件按字段类型设计(数值为范围，枚举为是/不是，文字为包含，是非字段为两个选项);旧格式的条件读取时自动转换。
- 编辑页工具栏：保存状态、更多操作(重命名、复制、下载 JSON、删除)、「运行流程」「完成」;可复制流程 JSON。
- 内置流程按「范围 内容」命名:`9709 P1 主题抽题`、`9709 P3 高分题`、`全部 章节包`。

**修复**
- 设置保存时检查版面范围。

## 升级说明

- 设置中保存过的旧第五档(原「宽松」,4)读取时按新的「宽松」(3,原卷)处理，无需操作。
- 练习卷缓存与搜索索引的版本已提升，首次打开时自动重建(搜索索引约 4 秒)。
- 已有的白板与笔迹保留不变；按旧版练习卷建的白板仍显示建板时的页面。
- 内置流程改名后，用旧名称建出的题组按旧名称找回，再次运行时更新同一题组，此后按流程 ID 关联。

## 已知限制

- 白板最多 1000 页。
- 搜索页不填关键词时不列出题目(浏览全部题目用查询页);中文只能整段匹配。
- 不装 `zeroconf` 时不在局域网广播服务，iPad 白板外壳需手动填写地址。
- Windows 与 Linux 上的窗口使用系统标题栏，没有延伸到标题栏的效果。

## macOS 验收清单

以下只能在 Mac 上确认，测试中以替身代替:

1. 双击 `manage.command`:窗口打开时直接显示载入动画(深色背景上读数从 0 匀速升到 100),没有黑屏停顿。
2. 窗口顶部与页面顶栏颜色一致，红黄绿按钮可用。
3. 按住顶部任意空白处可拖动窗口；切到其他应用后，第一次按下即可拖动。
4. 双击顶部空白处缩放窗口(系统设置为「最小化」时改为最小化)。
5. 进入全屏后，顶部的点击正常传给页面。
6. 「打开原卷」用系统浏览器打开；「复制 JSON」写入剪贴板；输出文件弹出保存对话框。
7. 终端中不再出现 `NSWindow warning: adding an unknown subview`。
