# 数据管理页 1.0.1

修复 1.0.0 在 macOS 上双击 `manage.command` 打开窗口时，页面内容点击无反应(窗口仍可拖动)的问题。在终端中运行 `python3 manage.py window` 不受影响。

## 修改

- `manage.command` 改为经登录交互 shell(`$SHELL -lic`)运行，与在终端中输入时使用同一个 `python3`。原来用 `/bin/sh` 运行，读不到 `~/.zshrc` 中的 conda、pyenv 等设置，可能换成另一个 Python。
- 窗口显示后，程序主动设为常规前台应用并激活，窗口成为主窗口。按下鼠标时程序若仍未激活，先激活再把这次按下交给页面。
- 启动时在终端打印所用 Python 的路径。

## 测试

`tests/test_window.py` 新增一项(未激活时的按下)，并检查窗口显示后会激活程序。全部 38 项通过(Linux,替身代替 AppKit 与 pywebview)。
