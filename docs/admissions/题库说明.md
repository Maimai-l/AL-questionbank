# TMUA / TARA 题库

122 个 PDF,2118 页,全部来自 **UAT-UK 官方文件库**
(uat-wp.s3.eu-west-2.amazonaws.com,即 esat-tmua.ac.uk 背后的存储)。
没有用任何培训机构的转载,所以答案键是官方的。

你的推断被官方证实:UAT-UK 的 TARA 备考页明文写着,TARA 的 Critical Thinking
和 Problem Solving 板块 "share a common history with BMAT Section 1 and the
TSA",并把这两个前代考试的真题直接挂在 TARA 备考页上。TMUA 那边,官方说法是
2024 年改机考后 "content specification and question style are unchanged"——
纸质时代的真题就是现行考试的题库。

## 考试对应关系(2026 年状态)

**TMUA**(Cambridge / Imperial / LSE / Warwick 等数学向专业)
- 2016–2023:纸质,Cambridge Assessment 主办 —— 本库的 papers 就是这些
- 2024 起:UAT-UK / Pearson 机考,**内容规范和题风不变**(官方原话)
- 机考时代的真题不公开;官方另有 2 套线上模拟(在 Pearson VUE 上,非 PDF,
  要自己登录做)

**TARA**(Oxford 多数文社科专业 + UCL 部分专业)
- 2025 年 10 月首考,**不存在真题**
- 官方指定的备考材料 = TSA S1 + BMAT S1 真题(本库已含)+ docs/ 里的
  Question Guide 和 Content Specification
- Pearson VUE 上另有官方线上练习卷,非 PDF

## 用的时候要知道的

1. **TMUA 2016 = 官方 Practice Paper。** 卷面上印的就是 "Practice paper",
   后来 CAAT 把 2016 首考卷重新发布为练习卷。别处看到的 "Practice Paper"
   和本库的 2016 是同一套,不要当成两套刷。
2. **Specimen 是 2017 年发的样卷**,难度标定略低于真题,适合当第一套热身。
3. **TSA 只收了 Section 1。** Section 2 是写作,TARA 没有写作部分,收了没用。
   同理 BMAT 只收 Section 1(S2 是理科、S3 是写作,都与 TARA 无关)。
4. **TSA 2016 年答案键官方缺失过一段时间**,本库里的是官方后补的版本,已核对。
5. **32 个 PDF 的文本层是乱码**(TMUA 2016/2017/2021/2022/2023 的题卷 +
   大部分答案键)。这是 UCLES 字体嵌入的老毛病,**人打开阅读完全正常**,
   只影响机器抽取文本 —— 以后如果要把这批题入 caie.db 那样的结构化库,
   这些文件要走 OCR(和 9709 mark scheme 当年一模一样的情况)。
6. 版权归 UCLES / UAT-UK。自用可以,别公开分发。

## OCR(已做)

122 个 PDF 已全部 OCR(`bank_ocr/`,目录结构与 `bank/` 一一对应):

```
bank_ocr/TMUA/papers/TMUA-2021-paper-1/page_0004.md   一页一个 markdown
bank_ocr/.../imgs/                                    图形题的插图
bank_ocr/.../_raw.jsonl                               API 原始返回,别删
```

验证结果:122/122 页数与 PDF 逐一相符;正文引用的 1175 张插图零缺失、
零空文件、零裁坏(最小 49x40,无细条);抽样人工过目图形题裁切完整。
原先文本层乱码的 32 个文件(含 TMUA 2021 全卷)现在是干净的 LaTeX。

(标 `<!-- 选项自页面图像转录 -->` 之类的注释),重跑上述脚本可复现。
