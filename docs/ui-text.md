# 数据管理页界面用语

数据管理页（`manager/`）、iPad 白板、设计稿与生成的阅读文档统一按本文件书写。新增文字先查术语表，再按句式规则写。

## 1. 术语表

一个概念只用一个名称。

| 概念 | 名称 | 不再使用 |
|---|---|---|
| 一道题 | 题目；计量用"题" | 试题 |
| 题目的图片形式 | 题目图片；在"题目"分组下简称"图片" | 题图 |
| 题目的文字形式 | 题目文字；在"题目"分组下简称"文字" | 题干、题干文字 |
| 题目下的 (a)(b) | 小问 | 子题 |
| 原卷上的作答位置 | 答题区 | 答题空间 |

| 本项目生成的逐小问讲解 | 详解 | 解析 |

## 2. 句式规则

1. **按钮、菜单项、图标按钮的名称**：动词加宾语，宾语用术语表中的名称。同一对象在全站只有一个宾语写法。
   - 例：新建题组、重命名题组、删除题组；新建模板、复制模板；新建流程、运行流程；下载 PDF、下载 ZIP；导入 JSON、导出 JSON。
   - 文件格式直接写格式名：PDF、ZIP、JSON。
2. **动词的分工**：
   - 新建：建立空白对象；
   - 复制：以现有对象为底建立新对象；
   - 下载：把已生成的文件存到本机；
   - 导出：把可编辑的内容转成文件（白板转 PDF，题组转 JSON）；
   - 打开：进入另一页面查看；
   - 移出：从题组中去掉题目，题目本身保留；
   - 删除：永久删除对象。
3. **区块标题、字段名、表头、分组标题**：名词短语，不含动词。
4. **同一组选项**：结构相同，同为名词短语，长度相近。
   - 例：图片 / 文字；仅题目 / 含答题区；每题一个文件夹 / 不分文件夹；跟随系统 / 浅色 / 深色。
5. **进行中的状态**："正在"加动词加宾语。
   - 例：正在载入、正在读取题目、正在生成题目卷。
6. **操作结果提示**：对象加"已"加动词；失败为对象加"无法"加动词，原因放在全角括号内。
   - 例：16 题已加入 9709 Paper 1 Integration；README 已复制；文件无法读取；白板无法打开（连接中断）。
7. **空状态**：数据不存在写"没有"加名词；用户尚未操作写"未"加动词加名词。不加说明句。
   - 例：没有题组；题组中没有题目；未选择题目。
8. **校验与错误**：主语加"不存在""须为""未连接"等谓语，不用祈使句与口语。
   - 例：考试不存在；条数须为整数；分组节点的输入须为列表；右侧输入未连接。
9. **计量**：数字、空格、量词。量词固定为：题、分、页、组、条、个文件、项输出。
10. **默认名称**："未命名"加对象，例如未命名题组、未命名模板、未命名流程；复制得到的对象为"原名 副本"。
11. **标点**：中文句子用全角逗号、冒号、括号。不用 unicode 箭头或符号充当图标或分隔。
12. **措辞**：不用口语词，例如"还""这个""这块""几次""即可""打不开""抢走"。
