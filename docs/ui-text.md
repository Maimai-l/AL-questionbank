# 数据管理页界面用语

数据管理页（`manager/`）、iPad 白板、设计稿与生成的阅读文档统一按本文件书写。新增文字先查术语表，再按句式规则写。

## 1. 术语表

一个概念只用一个名称。「简称」列为该名称在所属分组内可用的短写，没有简称的留空。

| 概念 | 名称 | 简称 | 不再使用 |
|---|---|---|---|
| 一道题 | 题目 | 计量写「题」 | 试题 |
| 题目的图片形式 | 题目图片 | 「题目」分组内写「图片」 | 题图 |
| 题目的文字形式 | 题目文字 | 「题目」分组内写「文字」 | 题干、题干文字 |

## 2. 句式规则

### 2.1 按钮与菜单项

动词加宾语。宾语用术语表中的名称，同一对象在全站只有一种写法。文件格式直接写格式名：PDF、ZIP、JSON。

示例：

- 新建题组、重命名题组、删除题组
- 新建模板、复制模板、删除模板
- 新建流程、运行流程
- 下载 PDF、下载 ZIP、下载批注版
- 导入 JSON、导出 JSON

### 2.2 动词的分工

| 动词 | 用于 |
|---|---|
| 新建 | 建立空白对象 |
| 复制 | 以现有对象为底建立新对象 |
| 下载 | 把已生成的文件存到本机 |
| 导出 | 把可编辑的内容转成文件，例如白板转批注版、题组转 JSON |
| 导入 | 从文件建立对象 |
| 打开 | 进入另一页面查看 |
| 移出 | 从题组中去掉题目，题目本身保留 |
| 删除 | 永久删除对象 |

### 2.3 各类文字的句式

| 类别 | 句式 | 示例 |
|---|---|---|
| 区块标题、字段名、表头、分组标题 | 名词短语，不含动词 | 图片范围 |
| 同一组选项 | 结构相同，同为名词短语，长度相近 | 仅题目 / 含答题区 |
| 进行中的状态 | 正在 + 动词 + 宾语 | 正在生成练习卷 |
| 操作成功 | 对象 + 已 + 动词 | README 已复制 |
| 操作失败 | 对象 + 无法 + 动词，原因放在全角括号内 | 白板无法打开（连接中断） |
| 空状态：数据不存在 | 没有 + 名词 | 没有题组 |
| 空状态：用户尚未操作 | 未 + 动词 + 名词 | 未选择题目 |
| 校验与错误 | 主语 + 不存在、须为、未连接等谓语 | 条数须为整数 |
| 计量 | 数字 + 空格 + 量词 | 16 题 |
| 默认名称 | 未命名 + 对象 | 未命名题组 |
| 复制得到的对象 | 原名 + 空格 + 副本 | 默认 副本 |

### 2.4 其他要求

- 量词固定为：题、分、页、组、条、个文件、项输出。
- 中文句子用全角逗号、冒号、括号。
- 引用界面上的名称用直角引号「」。
- 不用 unicode 箭头或符号充当图标或分隔。
- 空状态只写状态本身，不加说明句。
- 不用口语词，例如「还」「这个」「这块」「几次」「即可」「打不开」「抢走」。
