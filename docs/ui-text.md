# 数据管理页界面规范

数据管理页（`manager/`）、白板书写页、设计稿与生成的文档统一按本文件书写和排版。数据管理页只面向电脑的浏览器；iPad 只作为白板的书写终端，书写页在 iPad 上不显示顶栏与导出入口。

- 新增文字先查第 1 节的术语表，再按第 2 节的句式写。
- 显示数据时按第 3 节的格式写。
- 排版与交互按第 4 节。
- 第 5 节列出现有界面需要改动的地方，每行一处。

## 2. 句式

### 2.1 按钮与菜单项

按钮与菜单项写成动词加宾语。宾语用术语表中的名称，同一对象在全站只有一种写法。文件格式直接写格式名：PDF、ZIP、JSON。

示例：

- 新建题组、重命名题组、删除题组
- 新建模板、复制模板、删除模板
- 新建流程、运行流程、编辑流程
- 下载 PDF、下载 ZIP、下载批注版
- 导入 JSON、导出 JSON

### 2.2 动词的分工

| 动词 | 用于 |
|---|---|
| 新建 | 建立空白对象 |
| 复制 | 以现有对象为底建立新对象 |
| 下载 | 把已生成的文件存到本机 |
| 导出 | 把可编辑的内容转成文件，例如白板转批注版、题组转 JSON |
| 导入 | 从文件建立对象 |
| 打开 | 进入另一页面查看 |
| 编辑 | 进入对象的编辑页 |
| 移出 | 从题组中去掉题目，题目本身保留 |
| 删除 | 永久删除对象 |

### 2.3 各类文字

| 类别 | 句式 | 示例 |
|---|---|---|
| 区块标题、字段名、表头 | 名词短语，不含动词 | 评分细则与详解 |
| 选项的分组标题 | 写明选项作用的对象与动作，与下面的选项连起来读是一句完整的话 | 「每道题包含」+「评分细则」 |
| 有或无的选择 | 复选框，标签紧跟在复选框右侧，写勾选后的结果 | 截图保留原卷答题区 |
| 多个取值的参数 | 分段控件或数字输入，列出全部取值，不压缩成开关 | 每页题数：1 / 2 / 3 |
| 两种都有意义的方式 | 分段控件，两项都写出，结构相同 | 按题分文件夹 / 不分文件夹 |
| 三种以上的方式 | 分段控件，各项结构相同、字数相同 | 自动 / 浅色 / 深色 |
| 同一组选项 | 结构相同，长度相近 | 评分细则、详解、批注版 |
| 进行中的状态 | 正在 + 动词 + 宾语 | 正在生成压缩包 |
| 操作成功 | 对象 + 已 + 动词 | README 已复制 |
| 操作失败 | 对象 + 无法 + 动词，原因放在全角括号内 | 白板无法打开（连接中断） |
| 空状态：数据不存在 | 没有 + 名词 | 没有符合条件的题目 |
| 空状态：用户尚未操作 | 未 + 动词 + 名词 | 未选择题目 |
| 校验与错误 | 主语 + 不存在、须为、未连接等谓语 | 条数须为整数 |
| 节点摘要：参数 | 名称：值 | 模板：只有题目 |
| 节点摘要：条件 | 字段 运算符 值 | 分值 ≥ 8 |
| 默认名称 | 未命名 + 对象 | 未命名题组 |
| 复制得到的对象 | 原名 + 空格 + 副本 | 只有题目 副本 |

### 2.4 其他要求

- 数字字体（Novecento）用于加载页的进度读数与表格的数值列；表格中的编号（年份、考季、卷号、题号、序号）用科技字体（Space Grotesk），与设计系统 Table 一致。表格所有单元格同为 13 号。界面其他位置的数字一律用正文字体。
- 量词固定为：题、分、页、组、条、个文件、个文件夹、项输出。界面与生成的文件都写「8 题」，不写「8 道题」。
- 中文句子用全角逗号、冒号、括号。
- 引用界面上的名称用直角引号「」。
- 不用 unicode 箭头或符号充当图标或分隔。
- 空状态只写状态本身，不加说明句。
- 不用口语词，例如「还」「这个」「这块」「几次」「即可」「打不开」「抢走」。
- 名称按用户看到的内容起，不按实现起。例如截取的图片叫「题目截图」，不叫「图片」。
- 模板和流程的示例名称写出依据，例如「Paper 3 后段高分题」。流程列表的第二行写出条件。

## 3. 数据的书写格式

同一项数据在表格、详情、页脚、文件名和生成的名称中只有一种写法。官方编号与专有名称（考试代码、试卷名称、主题名称、教材标题、编程语言）保留官方写法，其余用中文。

| 数据 | 格式 | 示例 |
|---|---|---|
| 考试代码 | 官方代码 | 9709、TMUA |
| 考试类别 | 剑桥考试、入学考试 | 剑桥考试 |
| 试卷 | 官方写法 | Paper 1 |
| 卷号 | 两位数字 | 12 |
| 考季 | 官方考季代码 | F/M、M/J、O/N |
| 年份 | 四位数字 | 2023 |
| 试卷代码 | 官方代码，其中的考季与两位年份属于代码本身 | 9709/12/M/J/23、TMUA/1/2016 |
| 文件名中的试卷代码 | 把试卷代码中的「/」换成「-」，其余不变 | 9709-12-M-J-23 |
| 题号 | Q 加数字，跟在试卷代码后，中间空一格 | 9709/12/M/J/23 Q5 |
| 主题 | 大纲编号、空格、官方名称 | 1.8 Integration |
| 教材章节 | 第 n 章、空格、章节标题 | 第 9 章 Integration |
| 小问类型 | 两个汉字，编程语言名称保留原文 | 求解、证明、SQL |
| 日期与时间 | YYYY-MM-DD HH:MM | 2026-10-02 09:12 |

## 4. 排版与交互

### 4.1 页面标题

- 顶栏左侧只放页面名称，所有页面位置相同。
- 列表加详情的页面（题组、模板、批量生成），详情区第一行是所选对象的名称。
- 从属页面（练习卷、导出、流程编辑）在顶栏显示位置路径，内容区不再重复对象名称。

### 4.2 操作

- 页面级操作（新建、导入）放在顶栏右侧。
- 单个对象的操作（重命名、复制、删除）放在列表项右侧的「更多」菜单，删除与其他项用分隔线隔开。
- 一行最多放一个图标按钮。
- 只有图标、没有文字的按钮，只用于含义通用的操作：新建（加号）、下载、上移、下移、删除、更多、关闭，标题旁的改名笔，以及有文字标签的行末用于打开的箭头。
- 本应用特有的操作，例如打开白板、编辑流程，必须带文字，不能只放图标。
- 按钮的样式由操作的分量决定：页面上分量相同的几个主要操作用同一种主要按钮，并排、等高。例如练习卷页的「下载 PDF」与「打开白板」，流程概览的「编辑流程」与「运行流程」。无边框按钮只用于次要操作。
- 同一操作在一个页面上只出现一次。
- 菜单从按钮向列表外侧弹出，顶边与所属列表项的顶边对齐，不遮挡相邻的列表项。

### 4.3 表格

- 筛选后所有行取值相同的列不显示。
- 可变宽度的列放有信息量的内容，例如题干开头。
- 数值列右对齐。
- 表格不加四角标记。

### 4.4 选中态

按设计系统的 `color-checked`：

- 列表项与分段控件的选中项：浅色为墨底黄字，深色为黄底墨字
- 侧边导航的当前项：浅色为墨色竖条，深色为黄色竖条
- 列表统一用双行：第一行为名称，第二行为摘要（题组写题数与分值，导出模板写每道题包含的内容，流程写条件）

### 4.5 状态

每个页面设计四种状态。设计稿的「状态」一行各画一例。

| 状态 | 设计稿中的例子 |
|---|---|
| 有数据 | 各页面的主画板 |
| 没有数据 | 查询无结果、空题组 |
| 进行中 | 生成压缩包时显示进度 |
| 失败 | 流程运行失败：出错的节点标红，工具栏写出原因 |

### 4.6 选项与设置

- 选项用复选框或分段控件，不用开关。复选框的标签紧跟在框的右侧，不把标签和控件分到一行的两端。
- 同一项设置对所有对象都适用。只适用于部分对象的设置，要么在界面上说明原因，要么取消。
- 分组标题到第一个选项 12，选项行高 32、之间不另加间距，分组与分组之间 16。分组标题离自己的选项比离上一组近。
- 内置的模板与流程不可修改，选项区上方写明「内置模板不可修改，复制模板后可修改副本」。
- 设计稿中的复选框同时画出勾选和未勾选两种状态。

### 4.7 界面间距

界面的所有间距按设计系统工作页的取值（`showcase.html#spacing` 的「样例：工作页」），按层级使用，内层小于外层。同一层级在全站只用一个值。数据管理页只在电脑上使用，窗口最小宽度 1280，低于 1280 时整页横向滚动。

| 层级 | 值 | 例子 |
|---|---|---|
| 页边距 | 32 | 顶栏标题、各栏内容、表格外缘对齐的那条线 |
| 区块之间 | 32（有分隔线时线的两侧各 16） | 题组页右侧面板的练习卷、评分细则与详解、导出三个区块 |
| 标题区到工具栏或内容 | 24 | 查询页的结果数到已选栏，题组名称到表格 |
| 同级组件之间 | 16 | 筛选条件的各个分组、导出选项的各个分组、工具栏到表格 |
| 小标题到内容 | 12 | 选项分组标题到第一个选项，右侧面板区块标题到第一行 |
| 元素内部 | 8 | 图标与文字之间、并排的按钮之间 |
| 文字组 | 4 | 标题与下方的题数分数行 |

单位为 px。代码中只能引用这七个值（`style.css` 中的 `--pad`、`--block`、`--head`、`--sib`、`--sub`、`--el`、`--txt`），不写其他数值。

### 4.8 练习卷版式

所有考试的练习卷用同一套版式和同一套间距，不按考试区分排法，也不提供切换。

| 项目 | 值 |
|---|---|
| 纸张 | A4（595 × 842 pt） |
| 左右页边距 | 40 pt |
| 上页边距 | 40 pt |
| 下页边距（含页脚） | 56 pt |
| 题与题之间 | 24 pt |
| 题目与补加的答题线之间 | 8 pt |
| 答题线行距 | 24 pt |
| 页脚文字 | 8 pt，基线距纸张下缘 24 pt |

排法：

- 题目按题组顺序从上到下连续排列。剩余高度放不下下一题时换页，一道题不拆到两页。
- 只有一题高于整页时，才在页底附近最空白的一行切开，余下部分接到下一页。
- 剑桥考试的题目使用带原卷答题区的截图。原卷没有答题区的题目（另附答题册的试卷），在题目下方补加答题线，每分两行。
- 入学考试的题目使用题目截图，与剑桥考试的题目按同一间距排列。
