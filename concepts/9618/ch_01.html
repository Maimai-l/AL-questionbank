1.1进制

二进制每 4 位一组,一组写成 1 位十六进制;负数用补码,补码只有最高位是负的。

十六进制hexadecimal以 16 为基数(base 16),用 0–9 和 A–F,一位正好对应四位二进制(one hex digit = 4 bits)。补码two's complement表示有符号整数(signed integers),最高位的位权是负数(the MSB has a negative place value),8 位补码能表示 −128 到 +127。BCDbinary-coded decimal把每一位十进制数字单独用四位二进制表示(each denary digit is represented by its own 4-bit code)。

说存储容量时,十进制前缀denary prefix按 10 的幂(powers of 10)每级乘 1000,二进制前缀binary prefix按 2 的幂(powers of 2)每级乘 1024。

必考十进制换二进制:一步一步减

从最大的位权开始,能减就减,减得动的那一位写 1,减不动写 0:

182−128 →54−32 →22−16 →6−4 →2−2 →0

用到的位权是 128、32、16、4、2,所以二进制是 1011 0110。二进制换十六进制:从右往左每 4 位一组,每组单独换算(1011 = 11 = B,0110 = 6)。

了解十六进制和 BCD 用在哪里

十六进制比一长串二进制短、好读,也不容易抄错,所以用于内存转储(memory dump: memory contents output to a screen or printer)和网页颜色代码(如 #FF0000)。

BCD 每位数字单独编码,便于在计算器、时钟上逐位显示(digital displays);金额用 BCD 可以精确存储十进制小数,避免二进制小数带来的误差(exact representation of monetary values)。

1.1二进制加减

减法就是加上对方的补码;结果超出位数能表示的范围,就是溢出。

溢出overflow是计算结果太大,超出了给定位数能表示的范围(the result is too large for the number of bits allocated)。补码加法中,两个正数相加得到负数,或两个负数相加得到正数,就说明溢出了。

1.1文字怎么存

每个字符对应一个唯一的二进制编码;位数越多,能表示的字符越多。

编码每个字符占几位能表示多少字符
ASCII7 位128 个:英文键盘字符和控制码
扩展 ASCII8 位256 个:多出一些其他语言字符和制表符号
Unicode16 或 32 位世界上各种语言的字符;前 128 个与 ASCII 相同

字符集character set是计算机能使用的全部字符(all the characters a computer can use),每个字符有唯一的二进制编码(a unique binary code)。ASCII每个字符占 7 位,表示键盘字符和控制码(keyboard characters and control codes);扩展 ASCIIextended ASCII用 8 位;Unicode给多种语言的字符分配唯一编码(characters of many languages),能表示的字符远多于 ASCII,代价是每个字符占的位更多。

了解ASCII 大写和小写只差一位

A = 65 = 100 0001,a = 97 = 110 0001:两者只差位权为 32 的那一位,所以大小写转换只需改这一位。字母和数字在码表中按顺序连续排列。

1.2位图

位图是一格一格的像素;格子越多越清晰,每格的位数越多颜色越多,两样都会让文件变大。

位图bitmap image由像素pixel组成(made up of a grid of pixels),像素是图像中最小的可寻址单位(the smallest addressable element of an image)。每个像素用来表示颜色的位数(number of bits per pixel)叫颜色深度colour depth。图像分辨率image resolution是图像宽和高各有多少像素(pixels wide × pixels high);屏幕分辨率screen resolution是屏幕宽和高各能显示多少像素(that a screen can display)。

必考算文件大小

文件大小 = 宽 × 高 × 颜色深度1024 × 768 × 24 位 ÷ 8 = 2 359 296 字节 = 2.25 MiB

常考调高会怎样

调高好处代价
图像分辨率像素更多,图像更清晰(more pixels, more detail)文件变大
颜色深度颜色更多,更接近真实(more colours can be represented)文件变大

了解文件头

文件头
宽 · 高 · 颜色深度 …像素数据
0101 1100 1110 …

文件头file header放在位图文件开头,记录这个文件的信息(data about the file),软件靠它才知道怎么读后面的像素数据。

了解文件头里有什么

文件类型(file type, e.g. .bmp)、文件大小(file size)、图像分辨率(image resolution)、颜色深度(bit depth: 1, 8, 16, 24 or 32),以及用了哪种压缩(compression used)。

了解位图放大为什么会模糊

放大位图时像素的个数不变,每个像素覆盖的面积变大,像素密度(pixel density: pixels per square inch)下降,边缘出现锯齿,图像变得模糊(pixelated)。

1.2矢量图

矢量图不存像素,存的是一张绘图列表:画哪些对象,每个对象有哪些属性。所以放大不会模糊。

矢量图vector graphic由数学定义的绘图对象构成(drawing objects defined mathematically)。绘图列表drawing list是矢量图中全部绘图对象的列表(a list of all the drawing objects in the image),每个对象写明绘制它的命令(command)和属性。属性attribute / property是一个绘图对象的一项数据(data about one drawing object),例如线条颜色(line colour)、线宽(line width)、填充颜色(fill colour)、坐标和半径。放大时按属性重新计算再画,所以不失真(can be scaled without loss of quality)。

了解位图还是矢量图
选适合原因
矢量图标志、示意图、需要缩放或按比例绘制的图放大不失真,文件通常更小
位图照片逐个像素记录颜色,看起来更真实

打印矢量图时,通常要先把它转换成位图(converted to a bitmap before printing)。

1.2声音

声音是模拟信号,要采样才能存成数字:横向看采得多密,纵向看每个点分得多细。

模拟声波analogue sound wave
→
按固定时间间隔测振幅amplitude measured at set time intervals
→
取最接近的量化值approximate value stored
→
编码成二进制encoded as binary

采样率sampling rate是每秒采样的次数(number of samples taken per second);采样分辨率sampling resolution是每个样本的振幅用多少位表示(number of bits used to represent each amplitude)。

必考算文件大小

文件大小 = 采样率 × 采样分辨率 × 秒数44 100 × 16 位 × 60 秒 ÷ 8 = 5 292 000 字节;立体声再 ×2

常考调高会怎样

调高好处代价
采样率样本之间的时间间隔更短,数字波形更接近原声波(smaller time gaps between samples; closer to the analogue wave)文件变大
采样分辨率每个样本的位数更多,振幅更精确(more bits per sample; wider range of amplitudes)文件变大

1.3压缩

压缩让文件变小,省存储、传得快;无损能完全还原,有损永久丢掉一部分数据。

无损压缩lossless compression解压后能完全还原原文件(the original file can be restored exactly);有损压缩lossy compression永久删去部分数据(permanently removes some data),无法完全还原。游程编码run-length encoding属于无损压缩,把一串连续相同的数据记成"重复次数 + 数据的编码"(replaces a run of identical data with the number of repeats and the data value);重复越长,压缩效果越好。

常考选有损还是无损

选适合的文件原因
无损文本、程序、表格少一位数据,文件就出错或不能用
有损照片、音乐、视频丢掉的细节人几乎察觉不到,文件小得多,传输占用带宽更少(uses less bandwidth)
常考游程编码怎么存:编码与标志位

文字 aaaaabbbbccddddd 共 16 个字符,占 16 字节。用 ASCII 码写成"次数 编码"对:

05 9704 9802 9905 100

只需 8 字节,是原来的一半。像 cdcdcd 这样没有重复的数据,每个字符前都写 01 反而更长,所以加一个标志位(flag):只有跟在标志值(如 255)后面的两个数表示"次数 编码",其余字节按原值读。

255 05 97= 5 个 a99= 1 个 c
了解有损压缩怎么做:感知音乐整形与 JPEG

MP3 用感知音乐整形(perceptual music shaping,一种 perceptual coding)去掉人听不到的声音:

去掉人耳听不到的频率frequencies outside the human hearing range removed
+
两个声音同时响,去掉较轻的那个the quieter of two simultaneous sounds removed
→
文件约缩小 90%original file cannot be restored

MP3 的音质还取决于比特率(bit rate: bits per second used when creating the file),常见 80 到 320 kbps,越高越接近 CD 音质。

JPEG 去掉人眼察觉不出的颜色和色调变化(colour changes and hues the eye cannot detect),一般把位图缩小到原来的 1/5 到 1/15。
