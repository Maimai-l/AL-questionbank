10.1数据类型

每个数据项都有数据类型,它决定能取什么值、能怎样使用;用之前先用 DECLARE 声明。

类型存什么
BOOLEANTRUE 或 FALSE(logical values)
CHAR单个字符(single alphanumerical character)
DATE日期(value to represent a date)
INTEGER正或负的整数(whole number, positive or negative)
REAL带小数点的数(number with a decimal point)
STRING一串字符(sequence of alphanumerical characters)

数据类型data type是对数据项的分类(a classification attributed to an item of data),决定它能取哪些值、能怎样使用(determines the types of value it can take and how it can be used)。每个数据项有一个唯一的名字,叫标识符(identifier: a unique name applied to an item of data);使用前要先声明它的数据类型(declare the data type)。

必考声明变量:选对类型

DECLARE <标识符> : <数据类型>DECLARE Index, LineNum : INTEGER 同一类型的变量可以写在一行

计数和数组下标用 INTEGER(whole numbers used for counting and indexing),测量值用 REAL(accurate measurements)。评分细则给分看每个 DECLARE 是否带了正确的类型(DECLARE included with correct data types)。

了解各语言里的叫法

同一个类型在不同语言里名字不同:INTEGER 在 Python 里是 int,REAL 是 float,STRING 是 str,BOOLEAN 是 bool,DATE 是 datetime;Python 里不用 CHAR(char: not used in Python)。

10.1记录

记录把几项相关、类型可以不同的数据装在一个名字下:先用 TYPE 定义,再声明变量,用点号取字段。

记录类型record把几个相关的数据项装在一起(a composite data type comprising several related items that may be of different data types),用同一个标识符引用(held under a single identifier),字段数是固定的(a record contains a fixed number of items)。它是一种复合数据类型composite data type(a data type constructed using several basic data types)。语言里没有的类型必须先定义才能使用(must be defined before it can be used),这样就能用已有类型造出新类型(to create a new data type from existing data types)。取字段写成 记录名.字段名,如 Book.author。

10.2一维数组

数组是同一类型的一排元素,共用一个名字,靠下标找到每一个元素。

数组array是装着同一类型的若干元素的数据结构(a data structure containing several elements of the same data type),共用一个标识符,用数组下标index区分每个元素(a numerical value that identifies the position of an element in an array)。第一个元素的下标是下界lower bound,最后一个元素的下标是上界upper bound(the index of the first / last element in an array),下界通常是 0 或 1。声明时要写出下界、上界和数据类型(lower bound, upper bound and data type);问「声明数组还差哪一项信息」,答案是元素的数据类型(the data type of the item to be stored)。一维数组也叫列表(a 1D array can be referred to as a list)。

必考声明数组,用 FOR 循环逐个处理

DECLARE Marks : ARRAY[1:5] OF INTEGER
DECLARE Index, Total : INTEGER

Total ← 0
FOR Index ← 1 TO 5
    OUTPUT "Enter mark"
    INPUT Marks[Index]
    Total ← Total + Marks[Index]
NEXT Index
OUTPUT "Total is ", Total

累加用的变量要在循环前声明并赋初值(declared and initialised);整个数组用一个计数循环从下界走到上界。输入 80、65、90、72、88,输出 Total is 395。

了解记录数组
DECLARE Item : ARRAY[1:2000] OF Component
Item[1].Stage ← 'B'

存所有顾客、所有零件的记录,用一个一维记录数组(a (1D) array of records)。好处:能用循环逐条访问(allows iteration / can use a loop to access the records);用下标直接取到一条记录,用点号取字段(use of index to directly access a record; dot notation Item[1].Stage);代码更简单,更易读、易改、易调试(simplifies the code; easier to write / understand / maintain / test / debug)。

10.2二维数组

二维数组像一张表:第一个下标选行,第二个下标选列,遍历要用嵌套循环。

二维数组two-dimensional array可以看成有行和列的表(a table with rows and columns),元素用两个下标定位,先行后列。声明时要写出行的下界、上界,列的下界、上界,以及数据类型(lower and upper bound for rows and for columns, and data type)。同一个二维数组的所有元素类型相同。

常考嵌套循环:外层走行,内层走列

DECLARE myArray : ARRAY[0:8, 0:2] OF INTEGER
DECLARE Row, Col, Total : INTEGER

FOR Row ← 0 TO 8
    Total ← 0
    FOR Col ← 0 TO 2
        Total ← Total + myArray[Row, Col]
    NEXT Col
    OUTPUT "Row ", Row, " total ", Total
NEXT Row

内层循环用的累加变量,要在内层循环之前赋初值(declaration and initialisation before inner loop of Count and Total)。按图中的数据,第 0 行输出 75,第 1 行输出 134,第 2 行输出 163。

10.2线性查找

从下界走到上界,一个一个比较,找到就停;走完都没有,就是没找到。

线性查找linear search依次检查数组的每个元素(each element of the array is checked in order, from the lower bound to the upper bound, until the item is found or the upper bound is reached)。用一个标志变量记录有没有找到(flag to show when item has been found);循环条件写成「找到」或「越过上界」两个,找到就立刻停,效率更高。

了解线性查找模板

DECLARE myList : ARRAY[0:8] OF INTEGER
DECLARE Index, Item : INTEGER
DECLARE Found : BOOLEAN

INPUT Item
Found ← FALSE
Index ← 0
WHILE Index <= 8 AND Found = FALSE
    IF myList[Index] = Item
      THEN
        Found ← TRUE
      ELSE
        Index ← Index + 1
    ENDIF
ENDWHILE
IF Found = TRUE
  THEN
    OUTPUT "Found at ", Index
  ELSE
    OUTPUT "Not found"
ENDIF

027≠FALSE
119≠FALSE
236≠FALSE
342≠FALSE
416≠FALSE
589=TRUE

找 89:下标 5 时 Found 变成 TRUE,循环停止,输出 Found at 5。找 77:下标一直加到 9,越过上界,输出 Not found。

10.2冒泡排序

每一轮比较相邻两项,顺序不对就交换;一轮下来,最大的数落到最后。

冒泡排序bubble sort比较相邻的元素,顺序不对就交换(comparing adjacent items and swapping them if they are in the wrong order)。每一轮结束,本轮范围里最大的元素已经在正确的位置,下一轮就少比一个;一直重复,直到只剩一个元素,或者某一轮没有发生交换(until there is only one element left or no swaps are made)。

了解冒泡排序模板

DECLARE myList : ARRAY[0:8] OF INTEGER
DECLARE Index, Top, Temp : INTEGER
DECLARE Swap : BOOLEAN

Top ← 8
REPEAT
    Swap ← FALSE
    FOR Index ← 0 TO Top - 1
        IF myList[Index] > myList[Index + 1]
          THEN
            Temp ← myList[Index]
            myList[Index] ← myList[Index + 1]
            myList[Index + 1] ← Temp
            Swap ← TRUE
        ENDIF
    NEXT Index
    Top ← Top - 1
UNTIL Swap = FALSE OR Top = 0
下标比较交换?
027 和 19交换
127 和 36不换
236 和 42不换
342 和 16交换
442 和 89不换
589 和 21交换
689 和 16交换
789 和 55交换

上表是第 1 轮的 8 次比较;交换需要一个临时变量 Temp(temporary storage location during swap)。

10.3文本文件

文本文件把数据存成一行一行的字符,程序结束后数据还在;读写前要打开,读到文件结尾为止,用完要关闭。

文本文件text file把数据存成一行行的字符(a sequence of characters, with an end-of-line character so it can be read and written as lines),能存的数据量不固定(the amount of values stored is not fixed / not limited)。文件里的数据在程序结束或关机后仍然保留,这叫非易失性存储non-volatile storage(the data is retained when the program is terminated / after the computer is switched off // data is stored permanently)。文件结尾end of file (EOF)是「没有更多数据可读」的标记(a marker showing that there is no more data to be read);函数 EOF(文件名) 到了文件结尾返回 TRUE,否则返回 FALSE(returns TRUE if the end of the file has been reached)。读和写用的变量必须是 STRING 类型(the variable must be of data type STRING)。

必考打开文件:三种模式

OPENFILE <文件> FOR <模式>READFILE <文件>, <变量> 读一行 · WRITEFILE <文件>, <变量> 写一行 · CLOSEFILE <文件> 关闭

模式作用
READ从文件读数据(reads data from the file)
WRITE向文件写数据,原有数据被覆盖(any existing data stored in the file will be overwritten)
APPEND把数据加到文件末尾(adds data to the end of the file)
了解OPEN 与 OPENFILE

教材写成 OPEN <文件> FOR <模式>,真题评分细则里多数写成 OPENFILE;两种写法都出现过。本页统一用 OPENFILE。读完要关闭(open the file in read mode and subsequently close)。

10.3逐行读写文件

读文件的固定写法:打开,在「直到 EOF」的循环里一行行读,关闭;写文件换成 WRITEFILE。

读文件时,先用 READ 模式打开,然后写一个条件循环,一直循环到文件结尾(conditional loop until EOF(file)),每次读一行并处理(read a line from the file in a loop),最后关闭文件。需要计数时,计数变量要先声明并赋初值(both counts must have been declared and initialised),统计结果在循环结束后输出(final output after a loop)。写文件时先用 WRITE 打开,逐行 WRITEFILE,最后关闭;想保留原来的内容,就改用 APPEND 打开。

10.4抽象数据类型:栈、队列、链表

抽象数据类型 = 数据 + 能对数据做的操作;栈、队列、链表都是,它们靠指针管理数据。

抽象数据类型abstract data type (ADT)是数据加上能对这些数据执行的一组操作(a collection of data together with a set of operations that can be performed on that data)。本章有三个:栈、队列、链表。它们都用指针pointer来管理数据:指针是存放另一个数据项的地址或下标的变量(a variable that stores the address or index of another data item);用数组实现时,指针就是数组的下标(used as pointers / indexes to the arrays)。

必考比较栈、队列、链表

结构规则与操作指针
栈后进先出(last in first out / LIFO)。只在顶部加入(push)、移出(pop)基指针(base pointer)指第一项,顶指针(top pointer)指最后一项;两者相等时只有一项(when they are equal there is only one item)
队列先进先出(first in first out / FIFO)。队尾加入(enqueue)、队头移出(dequeue)队头指针(front pointer)指第一项,队尾指针(rear pointer)指最后一项;两者相等时只有一项
链表每个节点存数据和指向下一个节点的指针;增删只改指针起始指针(start pointer)指第一个节点;最后一个节点是空指针(null pointer)

栈和队列的区别:队列按收到的顺序移出,栈按相反的顺序移出(data is removed from a queue in the order it is received and removed from a stack in the reverse order)。问「说出另一种 ADT 并描述特征」,答队列或链表,各写 1 分的特征(one mark for identifying an ADT; one mark per feature)。

常考用数组实现三种结构
结构用数组怎样实现
栈一个一维数组,加一个整型的栈顶指针和栈的大小;push 前查满,pop 前查空(check for full or empty conditions)
队列一个一维数组,加队头、队尾两个整型指针和队列长度;满、空检查,指针走到末尾要绕回
链表两个一维数组(数据、指针),或一个记录数组;加起始指针和空闲链表指针(an array to store the data and a second array to store the pointers)
了解它们用在哪里

栈:内存管理、表达式求值、递归回溯(memory management; expression evaluation; backtracking in recursion)。队列:打印队列、键盘缓冲、进程调度(management of files sent to a printer; buffers used with keyboards; scheduling)。

10.4栈

栈后进先出:只在顶部 push 入栈、pop 出栈,顶指针指向最后放进去的那一项。

栈stack后进先出(last in first out / LIFO):最先放进去的最后才取出。入栈与出栈push / pop只在栈顶进行:push 把数据加到栈顶,pop 把栈顶的数据取走。栈放在固定大小的数组里,会满:对已满的栈再 push,就是栈溢出stack overflow(an item pushed onto a stack that is already full)。所以 push 和 pop 都要先检查栈是满还是空(push and pop routines need to check for full or empty conditions)。顶指针指向最后放进去的值(TopOfStack indicates the last value added)。

常考push 和 pop 的写法

DECLARE Stack : ARRAY[1:10] OF INTEGER
DECLARE BasePointer, TopPointer : INTEGER
DECLARE StackFull : INTEGER

BasePointer ← 1
TopPointer ← 0
StackFull ← 10

// push:把 Item 放进栈
IF TopPointer < StackFull
  THEN
    TopPointer ← TopPointer + 1
    Stack[TopPointer] ← Item
  ELSE
    OUTPUT "Stack is full, cannot push"
ENDIF

// pop:把栈顶取到 Item
IF TopPointer = BasePointer - 1
  THEN
    OUTPUT "Stack is empty, cannot pop"
  ELSE
    Item ← Stack[TopPointer]
    TopPointer ← TopPointer - 1
ENDIF

10.4队列

队列先进先出:队尾 enqueue 入队,队头 dequeue 出队,队头指针和队尾指针各管一头。

队列queue先进先出(first in first out / FIFO):先加入的先被移出。入队与出队enqueue / dequeue:入队在队尾加一项,出队从队头取走一项。队头指针指向第一项,队尾指针指向最后一项,两者相等时队列里只有一项(when they are equal there is only one item in the queue)。

进出方式Data is added at back / end and removed from front / start // works on a FIFO basis
可以循环May be circular

10.4循环队列

数组大小固定:指针走到最后一格就绕回第一格,出队空出来的位置可以再用,不用搬数据。

用固定大小的数组存队列时,按循环队列circular queue管理:队头、队尾指针指向数组最后一格之后,都改回指向第一格(the front and rear pointers wrap around to the start of the array)。这样每次出队都不用搬动数组里的数据(avoid moving the position of the items in the array every time an item is removed)。队列长度不能超过数组大小(providing the length does not exceed the size of the array),所以用 QueueLength 判断满和空;另一种做法是队尾加一后等于队头就说明满了(if incremented EoQ = FoQ then error condition: queue is full)。

常考入队和出队的写法(数组大小为 4)

DECLARE Queue : ARRAY[1:4] OF STRING
DECLARE FrontPointer, RearPointer : INTEGER
DECLARE QueueLength, QueueFull, UpperBound : INTEGER

FrontPointer ← 1
RearPointer ← 0
QueueLength ← 0
QueueFull ← 4
UpperBound ← 4

// enqueue:把 Item 加到队尾
IF QueueLength < QueueFull
  THEN
    IF RearPointer < UpperBound
      THEN
        RearPointer ← RearPointer + 1
      ELSE
        RearPointer ← 1
    ENDIF
    QueueLength ← QueueLength + 1
    Queue[RearPointer] ← Item
  ELSE
    OUTPUT "Queue is full, cannot enqueue"
ENDIF

// dequeue:把队头取到 Item
IF QueueLength = 0
  THEN
    OUTPUT "Queue is empty, cannot dequeue"
  ELSE
    Item ← Queue[FrontPointer]
    IF FrontPointer = UpperBound
      THEN
        FrontPointer ← 1
      ELSE
        FrontPointer ← FrontPointer + 1
    ENDIF
    QueueLength ← QueueLength - 1
ENDIF

10.4链表

链表的每个节点存数据和指向下一个节点的指针;增删只改指针、不搬数据;最后一个节点的指针是空指针。

链表linked list是一种动态数据结构,大小不受限制(a dynamic data structure / not restricted in size)。每个节点node含一项数据和指向下一个节点的指针(each node contains data and a pointer to the next node)。起始指针指向第一个节点(a pointer to the start of the list);最后一个节点的指针是空指针null pointer(last node in the list has a null pointer; there are no further nodes in the list),教材用 −1,真题也接受 0 或超出下标范围的值。数据靠改指针来增删,不用搬动数据(data may be added / removed by manipulating pointers (not moving data)),所以比数组更容易编辑(allows more efficient editing using pointers)。用数组实现时,没用的位置串成一条空闲链表free list(unused nodes are stored on a free list)(教材叫 heap),加新节点就从它那里取。代价是除了数据还要存指针,实现更复杂(need to store pointers as well as data; more complex to set up / implement)。

常考在有序链表中插入节点 B

检查有空闲节点check for a free node
→
找到正确的插入位置search for correct insertion point
→
数据 B 放进空闲链表的第一个节点assign data value B to first node in free list
→
A 的指针改指向 B,B 的指针指向 Cpointer from A changed to point to B; pointer from B points to C
→
空闲链表的起始指针移到下一个空闲节点start pointer in free list moved to next free node

常考刚初始化时的链表

起始指针是空指针(the PS contains a null pointer);空闲链表指针指向第一个空闲元素(the PF points to the first element on the free list);所有节点都在空闲链表上(all the nodes are on the free list)。

常考删除节点:还给空闲链表
前一个节点的指针改指向被删节点的下一个
→
被删节点的指针指向空闲链表的起始
→
空闲链表的起始指针改指向被删节点

删第一个节点时,改的是起始指针。数据没有被搬动,只是改了几个指针。
