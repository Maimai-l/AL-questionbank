3.1.1内存:RAM 与 ROM

CPU 直接访问的内存分两种:RAM 可读可写、断电就丢,放正在运行的程序;ROM 只读、断电不丢,放开机指令。

主存储器primary memory是 CPU 能直接访问的存储器(accessed directly from the CPU)。随机存取存储器RAM可以读也可以写(can be written to and read from),存放正在使用的数据、程序和部分操作系统(data, files, programs, part of the OS currently in use),它是易失的volatile的,断电后内容消失(memory contents are lost on powering off)。只读存储器ROM只能读、不能改(can only be read from),断电后内容还在(non-volatile),常用来存开机时要用的指令,也就是基本输入输出系统BIOS(start-up / boot-up instructions)。

必考RAM 和 ROM 的区别

RAMROM
读写可读可写(can be read from and written to)只能读(can only be read from)
断电内容消失,临时的(volatile, temporary)内容保留,永久的(non-volatile, permanent)
存什么正在运行的数据和指令(currently running data / instructions)开机指令、固件(boot-up instructions / firmware)

题目问"区别"时,每一点都要同时写出 RAM 和 ROM 两边;题目里已经给出缩写的全称,再把全称抄一遍不得分。

了解RAM 越大,电脑为什么越快

RAM 越大,能放下的正在运行的数据和指令越多(more currently running data and instructions can be stored),就不用先去速度慢得多的存储设备里取数据(without having to fetch the data from secondary storage first),等待的时间更短(less latency / delay waiting for instructions / data)。

RAM 满了以后,处理器要不停地访问慢速存储设备,用新数据覆盖 RAM 里的旧数据,电脑就越来越慢;加大 RAM 能让这样的操作少很多。

3.1.1DRAM、SRAM 和高速缓存

DRAM 用电容存位、要不停刷新,便宜、容量大,做主存;SRAM 用触发器存位、不用刷新,更快但更贵,做高速缓存。

动态随机存储器DRAM由晶体管和电容组成(transistors and capacitors),电容里的电荷表示 0 或 1,电荷会漏掉,所以要不停地刷新(needs to be constantly refreshed)。它每个存储单位的成本更低(lower cost per unit / less expensive to manufacture),容量更大,但访问更慢(slower access time)。静态随机存储器SRAM用晶体管排成的触发器存位(transistors arranged as flip-flops / latches),不用刷新(does not need to be refreshed),访问更快(faster access time),但制造更贵(more expensive to manufacture)。

高速缓存cache memory是靠近处理器的高速存储器(fast-access memory close to the CPU),存放处理器很可能再用到的数据和指令(stores data / instructions the processor will need again)。程序常常反复用到同样的数据和指令,所以缓存有效;缓存要的是速度,所以用 SRAM。

常考DRAM 和 SRAM 的区别

DRAMSRAM
结构晶体管加电容(transistors and capacitors)晶体管排成触发器(transistors arranged as flip-flops / latches)
刷新要不停刷新(requires constant refresh cycles)不用刷新(does not need to be refreshed)
速度访问更慢(lower access speed)访问更快(faster access time)
成本每单位更便宜(lower cost per unit)制造更贵(more expensive to manufacture)
用在哪主存(main memory)CPU 的高速缓存(cache)

3.1.1ROM 的几种:PROM、EPROM、EEPROM

PROM 只能写一次;EPROM 用紫外线擦、要拆下来;EEPROM 用电压擦、装在设备里就能改写,固件常放在它里面。

可编程只读存储器PROM内容只能写一次(can be programmed once)。可擦可编程只读存储器用紫外线擦除内容(contents are erased using ultraviolet (UV) light),改写前必须从设备上取下来(must be physically removed to be reprogrammed)。电可擦只读存储器用电压脉冲擦除(erased using a voltage pulse),可以反复改写,不必从设备上取下(changed multiple times without physically removing the memory)。闪存是 EEPROM 的一种,用在 U 盘、存储卡等设备里(flash memory: a type of EEPROM)。

固件firmware是存在 ROM 或闪存里、控制设备基本运行的程序指令(program instructions stored in ROM or flash memory that control the device's basic operation)。

常考固件为什么用 EEPROM 存

可以多次读、写、擦allows frequent / multiple read / write / erase operations
→
固件容易更新the firmware can be changed easily
→
不必先把整块内容全部擦掉,也不必拆下芯片without fully erasing the contents / without removing the chip

反过来,不用 EEPROM 的设备固件很难由用户更新(difficult to change / update the firmware by the user)。

了解EPROM 和 EEPROM 的区别

EPROMEEPROM
怎么擦紫外线(erased using UV light)电压(erased using voltage)
要不要拆要从设备上取下(needs to be removed from device)原地擦写(can be erased in situ)
擦多少数据全擦(erases all the data)可只擦一部分(can erase parts of the data)

3.1.1嵌入式系统

嵌入式系统是装在更大设备里、只负责一件事的微处理器;好处是小、便宜、省电,缺点是不好升级、不好修。

嵌入式系统embedded system是装在更大系统里的微处理器microprocessor或微控制器(microprocessor / microcontroller within a larger system),只完成一项特定任务(performs one specific task)。它至少要有处理器、存储器和输入输出能力(must contain a processor, memory and an I/O capability)。

常考嵌入式系统的特征和缺点

特征缺点
装在更大的设备里(built into / integrated into a larger system)用户很难更新固件、很难升级(difficult to change / update the firmware by the user; difficult to upgrade)
只做一件事,功能有限(dedicated to a single task / limited number of functions)不容易改去做别的事(cannot be easily adapted for another task)
有处理器、存储器、输入输出(processor, memory and an I/O capability)查故障、升级要专业人员;坏了常整个扔掉(troubleshooting is a specialist task; devices are thrown away rather than repaired)

题目问"为什么是嵌入式系统",就写:装在设备里面、只做一件事、功能不容易被用户改。

了解嵌入式系统的其他优点

体积小,容易装进设备(small in size);制造成本较低(relatively low cost);耗电很少(consume very little power);对输入变化反应很快,能实时工作(operate in real time)。

3.1.1辅助存储器与硬盘

辅助存储器存程序和文件,断电不丢,比内存大得多也慢得多;硬盘靠读写头读写盘片上的磁性。

辅助存储器secondary storage是 CPU 不能直接访问的存储器(not directly accessed by the CPU),数据永久保存(non-volatile; permanently stores data and programs),所有应用程序、操作系统和文件都存在里面;它还可以用来扩展可用的 RAM(used to extend the RAM / memory available)。它分磁性、固态、光学三类(magnetic, solid state and optical)。

硬盘HDD属于磁性存储:盘片表面能被磁化(each surface of the platter is capable of being magnetised),数据以磁性图案记在盘面上(the data is encoded as a magnetic pattern)。盘面分成同心的磁道和扇区(divided into concentric tracks and sectors),每个盘面上方有一个装在臂上的读写头(a read/write head mounted on an arm)。

常考硬盘怎么工作

一个或多个盘片,表面可被磁化one or more platters that can be magnetised
→
盘片装在主轴上高速旋转mounted on a spindle and rotate at high speed
→
读写头在臂上移过盘面read/write head is moved across the surface on an arm
→
读数据时磁场变化产生电流变化changes in the magnetic field produce a change in the electric current
了解硬盘为什么会越用越慢:延迟与碎片

延迟是目标数据所在的扇区转到读写头下面要等的时间(latency: the time for a block of data on a track to rotate around to the read/write head)。

文件反复编辑、删除后,同一个文件占用的扇区不再相邻,这叫碎片(fragmented: stored in non-consecutive sectors),访问越来越慢;碎片整理软件可以把扇区重新整理好(defragmentation software)。

3.1.1固态硬盘与光盘

SSD 没有活动部件,靠电子在芯片里移动存数据,更快更可靠;光盘用激光读写螺旋磁道上的凹点和平面。

固态硬盘SSD没有活动部件(no moving parts),靠控制电子在 NAND 芯片里的移动来存数据(controlling the movement of electrons within NAND chips),是非易失、可重写的存储。光盘optical disc用激光读写数据(laser light is used to read data from, and write data onto, the surface),CD、DVD、蓝光盘都是光盘。

价格较贵每个存储单位更便宜(costs less per storage unit)
寿命写入次数有限(SSD endurance)可能寿命更长(likely to have a longer life span)

3.1.2打印机与缓冲区

计算机快、打印机慢:数据先放进缓冲区,计算机就能去做别的事;缓冲区空了,打印机用中断向计算机要更多数据。

缓冲区buffer是临时存放数据的存储区,等设备准备好再把数据送过去(a buffer temporarily holds data until it is ready to be transmitted to the device)。它用来解决处理器和外设速度不一致的问题(to manage the mismatch in speed between the processor and the peripheral)。硬盘、光盘读写器、VR 头显用缓冲区也是同样的道理。

必考缓冲区怎么用(以打印为例)

→
数据从缓冲区按打印机的速度送到打印机transferred from the buffer to the printer (at printer speed)
→
缓冲区空了,向计算机发中断,请求更多数据when the buffer is empty an interrupt is sent to the laptop requesting more data

别忘了写好处:计算机不必等慢速的打印机,可以继续处理别的事(allowing the processor to continue processing instead of waiting for the relatively slower printer)。缓冲区满了,也会发中断请对方停止发送(an interrupt requesting to stop further data being sent)。

3.1.2话筒、扬声器与模数转换

话筒把声音变成模拟电流,要经 ADC 变成数字才能存;数字声音要经 DAC 变回电流,放大后推动扬声器。

话筒接收声音引起的空气振动,让膜片振动,线圈和磁铁相对运动,产生电信号(an electrical signal is produced),这个电流是模拟的(the electric current is analogue in nature)。模数转换器ADC把模拟数据转成计算机能处理的数字形式(converts analogue data, read from sensors for example, into a form understood by a computer)。数模转换器DAC把数字数据转成电流,可以驱动扬声器、电机、继电器(converts digital data into electric currents that can drive motors, actuators and relays)。DAC 的输出电流很小,要先经放大器才够推动扬声器(an amplifier creates a current large enough to drive a loudspeaker)。

了解话筒和扬声器里面是什么

动圈式话筒:线圈经过磁铁而产生电流(a coil moves past a magnet: dynamic microphone);另外还有电容式(changing the capacitance: condenser microphone)和晶体式(deforms the crystal: crystal microphone)。

扬声器:电流通过线圈使铁芯成为电磁铁,电流一变,铁芯相对永久磁铁振动,带动纸盆振动发出声音(the cone vibrates, producing sound)。

3.1.2屏幕与触摸屏

触摸屏既是输入也是输出设备;电阻式靠两层接触接通电路,电容式靠手指改变电场。

触摸屏touch screen用手指或触控笔选择、操作屏幕上的图像,既是输入设备又是输出设备(allows selection or manipulation of a screen image; acts as both input and output device)。屏幕上的触点位置,由微处理器算出坐标(a microprocessor identifies the coordinates of the touch)。电阻式触摸屏resistive touch screen有两层,用户一按,两层接触,电路接通(has two layers; when the user touches the screen, the layers touch and a circuit is completed)。电容式触摸屏capacitive touch screen有好几层,触摸最上层时电流发生变化(has several layers; when the top layer is touched there is a change in the electric current)。

屏幕由像素组成,每个像素由红、绿、蓝三个子像素组成,调节它们的亮度就能显示上百万种颜色(each pixel is made up of three sub-pixels: red, green and blue)。

OLED 屏自己发光,不需要背光,所以可以做得很薄(OLED generates its own light so no back lighting is required);LCD 屏则要背光。

3.1.2传感器与执行器

传感器读取温度、光、压力等物理量,送给处理器;执行器接收处理器的信号,去做动作。

传感器sensor是读取或测量周围物理量的输入设备(input device that reads physical data from its surroundings),真实世界的数据是模拟的,要经 ADC 转成数字才能让计算机处理。执行器actuator是机电装置,如继电器、螺线管(电磁阀)、电机(an electromechanical device such as a relay, solenoid or motor);它根据处理器的信号产生动作,把电能变成机械力(generates a signal / causes an action / converts electrical energy into a mechanical force)。

必考选传感器

3.1.2监控系统与控制系统

监控系统只检测、报警;控制系统还用执行器改变环境,输出又影响下一次输入,这就是反馈。

控制系统control system用传感器、反馈和执行器,在数值超出规定范围时自动改变环境(act autonomously to change the environment if the values are out of a prescribed range)。监控系统monitoring system只用传感器检查数值并发出警告,不采取行动(do not take any action)。反馈feedback指系统的输出会影响下一次输入(the output affects the next input):执行器改变了环境,传感器下一次读到的数据就变了。

常考监控系统和控制系统的区别

监控系统控制系统
行动不采取行动,只警告(do not take any action)自动改变环境(act autonomously to change the environment)
执行器没有(do not have any actuators)有(use actuators)
反馈没有(do not make use of feedback)有(make use of feedback)
输出对输入不影响下一次输入(output does not affect the subsequent input)影响下一次输入(output affects the next input)

判断题"是监控还是控制并说明理由":选择本身不给分,理由才给分,写执行器、反馈、输出会不会改变下一次输入。

3.1总线与接口

地址总线送"在哪里",数据总线送"是什么";总线越宽一次传得越多;USB 和 HDMI 用来连接外设。

地址总线address bus传送要读写的内存位置或设备的地址(the address of the data to be written to the device is carried on the address bus)。数据总线data bus传送数据本身(all data to be written to the device is carried on the data bus)。通用串行总线USB是连接外设的接口,传输速度快,是通用的标准(fast data transfer speeds; a universal standard)。高清多媒体接口HDMI用一根线同时传送视频和音频,不需要两根线(allows video and audio to be transferred on the same cable; no need for two cables),传送的是未压缩的数字信号(uncompressed digital signals)。

了解总线宽度的影响

更宽的结果
数据总线一次能传更多数据(more data can be transferred between components at a time);取数据时的延迟更少(less delay / latency)
地址总线能用更大的内存地址(larger memory addresses can be used);能直接访问更多内存位置(more memory locations accessed directly)

插入设备时电压发生变化a voltage change occurs when the drive is plugged in
→
计算机检测到电压变化the computer detects this voltage change
→
操作系统在设备表里找到这个设备的代码the OS finds the code of the device in the list of devices
→
加载对应的设备驱动loads the appropriate device driver

逻辑门logic gate是靠"开/关"逻辑工作的电子电路(electronic circuits which rely on on/off logic),输入和输出都是二进制(take binary inputs and produce a binary output)。非门NOT是唯一只有一个输入的门,输入不是 1 时输出 1(the output, X, is 1 if the input A is NOT 1)。与门AND两个输入都是 1 时输出 1(the output, X, is 1 if input A is 1 and input B is 1)。或门OR任一输入是 1 时输出 1(the output, X, is 1 if input A is 1 or input B is 1)。与非门NAND是"非 AND":有一个输入不是 1,输出就是 1(the output, X, is 1 if input A is NOT 1 or input B is NOT 1)。或非门NOR是"非 OR":两个输入都不是 1,输出才是 1(the output, X, is 1 if input A is NOT 1 and input B is NOT 1)。异或门XOR两个输入不同时输出 1(the output, X, is 1 if (input A is 1 AND input B is NOT 1) OR (input A is NOT 1 AND input B is 1))。

必考门的写法

门逻辑式(logic notation)布尔代数(Boolean algebra)
NOTX = NOT AX = A
ANDX = A AND BX = A . B
ORX = A OR BX = A + B
NANDX = A NAND BX = A . B
NORX = A NOR BX = A + B
XORX = A XOR BX = (A . B) + (A . B)

点 . 表示 AND,加号 + 表示 OR,字母上面的横线表示 NOT。

3.2.5用 NAND 搭其他门与化简

只用 NAND 门就能搭出 NOT、AND、OR,所以任何逻辑电路都能只用 NAND 搭出来;化简电路能省成本。

NAND 是常用的"积木"(building block):可以把一些 NAND 门连在一起搭出 AND 门、OR 门和 NOT 门,进而搭出任何逻辑门和任何逻辑电路(any logic gate, and therefore any logic circuit, can be built from NAND gates)。

了解为什么要化简电路

元件少了,生产成本更低(the cost of production can be less),可靠性更高(improve reliability),出故障时更容易查(easier to trace faults);电路板空间紧张时也需要化简,例如太空探测用的电路板(room is at a premium)。

AS 考试不要求做多于两个输入的门。
