7.1道德、法律与文化

不道德是违反行为准则,违法是违反法律,两者不是一回事;计算机道德规范管三件事:知识产权、隐私、对社会的影响。

道德规范ethics是约束个人或组织行为的道德原则,例如行为准则(moral principles governing an individual's or organisation's behaviour, such as a code of conduct)。知识产权intellectual property rights是个人对自己创作或想法的所有权规则,禁止未经许可复制,例如复制软件(prohibiting copying without the owner's permission)。隐私privacy是个人信息和数据保密、不被擅自访问或分享的权利(the right to keep personal information and data secret),黑客入侵就侵犯了隐私。第三方面是计算机对社会的影响(effect of computers on society),例如失业。

抄袭plagiarism是拿别人的作品当作自己的(taking another person's work and claiming it as one's own)。道德morality是分辨对错的认识,常来自个人信仰,因人、因文化而异(the difference between right and wrong);文化culture是一个群体共有的态度、价值观和习惯(attitudes, values and practices shared by a group of people)。

常考不道德与违法的区别

不道德 unethical违法 illegal
违反的是行为准则(breaking a code of conduct)法律(breaking the law)
例子员工把公司的想法透露给竞争对手未经版权人许可复制软件再出售
关系不道德不等于违法,违法也不等于不道德;同一件事若涉及国家安全或受版权保护的软件,就同时违法
了解法律、道德、道德规范、文化四个词
词关注什么常用于
legal是否合法,会不会受法律惩处(relating to, or permissible by, law)法律
morality对与错,因人而异个人选择
ethics对与错,写成准则职业和组织
culture一个群体共有的价值观如游戏里不能放某些文化觉得冒犯的内容
了解抄袭:引用要注明出处

引用别人的想法没问题,但必须注明,让原作者为人所知(some acknowledgement is made so that the originator is known):文末列参考文献,或在页下加脚注。有软件可以扫描文本,到网页上搜索抄袭的内容。

7.1职业道德机构

职业道德机构给从业者一份写好的行为准则,还提供帮助和培训;加入它,就是向客户证明自己守规矩。

职业道德机构professional ethical body为计算机从业者制定行为准则(has ethical guidelines to follow),并向会员提供帮助和支持(provides help and support)和培训(runs training courses)。BCS 在英国成立,现在是国际组织;IEEE 在美国成立,要提高人们对道德问题的认识,促进电子行业从业者的道德行为。

常考对公众和同事应该做什么

对象程序员应该
公众维护公众的健康、安全和福利(maintain the health, safety and welfare of the public);声明要诚实、实事求是(be honest / realistic in making claims about the software),这样公众才信任;保护公众数据的安全(maintain the security of the public's data)
同事公平对待,不歧视(treat colleagues fairly and avoid acts of discrimination);接受和提出批评(accept / offer critique);注明同事的贡献(credit the contributions of colleagues);帮助、培训同事(help / train colleagues)

了解加入职业道德机构的好处

好处评分细则原话
有准则可依The professional ethical body has ethical guidelines to follow, so clients know the standards being applied and the programmer does not have to decide what is ethical.
客户信任Clients know the programmer is reputable; there may be an entry requirement / exam, giving recognition of the programmer's skills / knowledge.
帮助支持Provides help and support, for example legal advice.
培训Runs training courses to keep skills up to date.

7.2版权与盗版

软件和音乐、书一样受版权保护;未经许可复制就是盗版,厂商用产品密钥、许可协议和 DRM 来防。

版权copyright让持有人对知识产权有合法所有权(gives the holder the legal right of ownership of intellectual property),别人不经许可不能复制、分发或改编。盗版piracy是使用或制作软件的非法拷贝(the use or making of illegal copies of software)。产品密钥product key是安装或激活软件时要输入的安全码,防止非法拷贝和使用(protects against illegal copies or use)。数字版权管理digital rights management(DRM)是控制对受版权保护的数字内容的访问和使用的技术(used to control the access to copyrighted material),例如音乐可以串流但不能下载拷贝,电子书只能在平板上读。

常考给程序加版权有什么好处

好处评分细则原话
保护知识产权Protects the programmer's intellectual property rights.
防止修改Prevents illegal changes to the program / protects the source code.
防止复制Prevents illegal copies of the program being made.
可以收费A fee can be charged for the program.
确认作者To identify themselves as the owner / author; to gain formal recognition of ownership.
可以追责To allow for legal consequences if anyone steals / copies it.
限制竞争To restrict competition.
了解买了软件以后,哪些事是违法的

复制软件再出售或送人;在网络上或多台电脑上使用而没有多用户许可证(multi-use licence);把版权软件的代码用到自己的软件里再出售;未经允许出租软件;未经同意把版权软件的名字用到别的软件上。英国的 FAST(Federation Against Software Theft)负责起诉侵犯版权的组织和个人。

7.2软件许可证类型

看两件事就能分类:要不要付钱,能不能看源码;许可证规定用户怎样使用、复制和修改软件。

软件许可证software licence是规定用户可以怎样使用、复制、修改和分发软件的法律协议(a (legal) agreement that defines the rights and terms of usage for the software)。商业软件commercial software受版权保护,付费购买,用户看不到源码(a fee is charged; users have no access to source code)。共享软件shareware先给用户试用期或有限功能(a trial period / limited functionality),之后可能要付费才能继续用。免费软件freeware可以免费下载使用,但仍受版权保护,不能改源码(copyright protected; source code cannot be modified)。

常考比较各类许可证

类型特征评分细则原话
商业收费,看不到源码,没有免费试用A fee is charged for the software. The source code cannot be accessed. Users do not get a free trial.
共享先试用,试用版常缺部分功能Users can try the software before buying it. Users may not be able to access all features during the trial.
自由 / 开源通常免费,能看并改源码Software is usually free of charge. Users can access the source code and alter the program to their needs.

常考共享软件的好处

对象好处
开发者Users are able to trial the program and may offer constructive feedback. More people might try the program because the trial is free of charge. Allows bugs to be found and corrected on a wide range of computer system configurations. Users that find the trial useful will buy the program, so the programmer gets income.
用户The user can test / trial the program before purchasing to see whether it meets needs. There is no initial cost.
了解商业软件的好处与限制

好处:所有者能收到费用(the owner / developer can earn a fee);通常提供完整的支持和维护,如更新和修补错误(support and maintenance is usually provided e.g. updates, bug fixes);软件一般测试充分,错误少(well tested so few bugs)。限制:用户不能合法地修改或分享程序(users cannot legally alter or share the program),安装次数等使用也有限制。一份正版许可证只供一台设备,多个用户要买多用户许可证。

7.2自由软件与开源

自由软件和开源软件都给用户四项自由,都能拿到源码;两个组织只是关注的角度不同。

自由软件free software允许用户运行、研究、修改、复制和再分发,包括修改后的版本(the source code comes with the program; can be changed and distributed with the changes)。开源软件open source software提供源码,用户可以自由复制、分发、研究和修改(software can be freely copied, distributed or adapted)。自由软件基金会Free Software Foundation是非营利组织,强调用户有运行、复制、修改和改编软件的自由。开源促进会Open Source Initiative主张同样的自由,但更关注实际好处,如用户之间协作开发软件(more collaborative software development)。

常考公开源码的好处与风险

评分细则原话
好处To allow users to customise the code. To allow errors to be reported / identified / fixed by users. To allow additional features to be added to the code. Allows the source code to be examined, so that a business can adapt / modify the program to meet their needs.
风险The source code would be accessible, therefore it could be changed, which might lead to the program outputting an incorrect response, with serious consequences.
了解用户仍要遵守的规则

自由软件和开源软件不受版权限制,用户不用先征求许可,但不能:把另一个软件的源码加进来,除非它也是自由或开源软件;用源码做出复制受版权保护软件的软件;改得侵犯别的软件的版权;做出会被第三方认为冒犯的软件。

7.3人工智能

人工智能是让机器去做原本需要人的智力才能做的事;它既有好处也有风险,答影响的题要两面都写。

人工智能artificial intelligence(AI)是完成某项任务的机器或应用,这项任务由人来做时需要一定程度的智力(a task that requires some degree of intelligence when carried out by a human)。AI 复制需要决策和解决问题能力的人类任务(decision-making and problem-solving)。AI 不只是机器人,还包括无人驾驶汽车、假肢、拆弹和焊接用的无人机、气候预测、精度极高的眼科手术。

常考AI 的影响

方面好处坏处
就业以往技术进步最终使工作净增加,新工作往往更有趣预测到 2030 年全球约 6 亿个工作岗位消失
环境在大量数据中找出规律,更快预测气候变化;更准确地发现污染源
司法面部识别几乎取代指纹决策中可能带有偏见(bias creeps into AI decision making);难以质疑 AI 的判决
广告针对个人投放广告为每个用户建立个人画像,数据可能被滥用
教育Students given additional support may do better. AI-assisted learning at their own pace.Students may miss out on developing reasoning and problem-solving skills. The AI answer might not be correct leading to mis-information. Emphasises the digital divide.

1机器人不得伤害人类,也不得见人受害而不救
2机器人必须服从人的命令
3在不违反前两条的前提下,机器人要保护自己
