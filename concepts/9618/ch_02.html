2.1局域网和广域网

局域网覆盖一栋楼这样的小范围,广域网把许多局域网连起来覆盖很大的范围;网络里传的数据被切成一个个数据包。

局域网local area network (LAN)覆盖一栋楼这样的小范围(covers a small geographical area),通常归一家机构所有,用自己的线路和设备(normally privately owned / dedicated infrastructure),可以有线也可以无线(can use wired or wireless communication)。广域网wide area network (WAN)由许多局域网连成,覆盖很大的地理范围(covers a large geographical area),要借用公共的线路(external / public infrastructure is used)。

网络里传的数据被切成数据包packet,每个包带着发送方的地址、接收方的地址和一段数据(the address of the sender, the address of the recipient and the data)。

了解比较局域网与广域网

比什么局域网 LAN广域网 WAN
范围小(small geographical area)大(large geographical area)
线路多为机构自己的(transmission media usually company owned)外部、公共的(external / not company owned)
硬件多为专用(dedicated hardware)可以非专用(non-dedicated hardware)
速度与安全传输快,通常更安全(high data transfer rate; usually more secure)传输较慢(low data transfer rate)
了解联网有什么好处和坏处

好处:打印机等设备可以共享(devices such as printers can be shared),用户共享文件,数据可以集中备份(files can be backed up centrally),网络管理员能设置访问权限。

坏处:布线和服务器的初始投入大,大网络难管理;文件服务器出故障会影响整个网络,恶意软件也会在网络里扩散(malware and hacking can affect entire networks)。

2.1客户端服务器与对等网络

客户端服务器有一台专门的服务器集中存数据、管权限;对等网络没有中心,每台电脑既提供服务也使用服务。

客户端服务器模型client-server model里,服务器集中存放数据、决定谁能访问什么(a dedicated server stores data and manages access);客户端只向服务器发出请求,再显示返回的结果(clients send requests to the server and display the returned results)。对等网络peer-to-peer network没有中心服务器(no central server),每个节点保存自己的数据,并和其他节点直接共享(each node has its own data and can share its files with all the other nodes),节点既是提供者又是使用者(peers are both suppliers and consumers)。

瘦客户端thin client自己几乎不存数据、不做处理,全靠服务器和网络(data is not stored on the client computer; reliant on access to the server; requires few local resources)。

常考比较两种网络模型

比什么客户端服务器对等网络
数据放哪集中在专用服务器(stored on dedicated servers)每个节点各存各的(each node has its own data)
安全较好:中央安全数据库,要用户名和密码(central security databases; user IDs and passwords)较差:没有中央安全系统,没有真正的身份验证(no central security system)
规模容易扩大(much easier to scale up);请求同时太多会成为瓶颈适合节点很少的小网络(no more than 10 nodes)
了解厚客户端和瘦客户端

厚客户端(thick client)自己有存储和处理能力,断网也能做一部分工作(can work offline or online; still able to do some processing),普通电脑就是例子。好处是更稳、本地有更多控制;坏处是安全靠客户端自己,每台都要单独更新软件。

瘦客户端靠服务器干活,服务器或网络一断就用不了,但设备便宜,软件和数据集中管理、集中防护。

2.1网络拓扑

总线型所有设备共用一根线,星型所有设备连到中心设备,网状的设备之间有多条路径。

总线型拓扑bus topology里所有设备接在一根中心电缆上(all devices connect to a central cable),同一时刻只能有一个设备发送(only one transmission can be on the line at once)。星型拓扑star topology里所有设备都连到中心设备,数据都经它转发(all devices connect to one central device)。网状拓扑mesh topology里设备之间互相连接,包有多条路径可走(multiple paths for the packets to travel along),设备还能充当中继,把包往目的地传(the computers can act as relays, passing packets on towards the final destination)。

常考比较三种拓扑

拓扑好处问题
总线型用线少;一个节点坏了,其余节点照常工作(even if one node fails, the remainder of the network continues to function)节点多时效率低,同时只能一个发送(inefficient with a large number of nodes);线断则网络不可用(if the bus / cable goes down the whole network is unusable);数据广播给所有节点,不保密(broadcast to all nodes: privacy / security issues)
星型一条线坏只影响一个节点(more resilient to faults);碰撞少,性能高(fewer collisions);容易加节点(easier to add new nodes)中心设备坏了,整个网络瘫痪;安装成本高
网状一条线断了还有别的路(if one line goes down there are more routes available);不靠一条主线,更安全(improved security);碰撞少(fewer collisions)布线多,建设和维护复杂

常考总线和星型怎么传数据

总线:

两个节点接在同一根线上both nodes are connected to a bus / cable
→
数据在线上广播data is broadcast on the cable
→
只有目的节点接收only accepted by the intended recipient

星型:

发送设备把包发给中心设备the sending device sends the packets to the switch
→
检查每个包的目的地址the switch checks the destination address on each packet
→
只转发给目的设备sends them only to the intended receiver
了解集线器和交换机作中心设备有什么不同

中心设备若是集线器(hub),所有包会发给每个节点,节点比对地址,符合才接收,和总线的做法类似;若是交换机,包只送到地址匹配的节点,所以更安全。

网状分两种:路由式给节点配上路由逻辑,沿最短路径转发,路径坏了可以改道;泛洪式把数据发给所有节点,不用路由,会增加不必要的负载。混合网络(hybrid network)是几种拓扑的组合,适合大网络,但安装维护更复杂。

2.1云计算与云存储

云存储把数据放在别人管理的远程服务器上,联网随时能取;方便、容量大,但依赖网络和第三方。

云计算cloud computing是通过网络使用放在远程服务器上的服务、文件或软件(accessing a service / files / software on a remote server)。云存储cloud storage是云计算中存数据的一种:数据存在异地服务器上(data is stored on off-site servers),由托管公司拥有和管理(owned and managed by a hosting company);同一份数据存在多台服务器上,方便维护,也保证随时能取(data redundancy)。

公有云public cloud由第三方提供商通过公共互联网提供,谁有设备和账号都能用(offered by a 3rd party provider over the public Internet)。私有云private cloud在公司防火墙之后的专用环境里,用户和提供方是一体的(a dedicated environment behind a company firewall)。

常考云存储的好处与问题

方面好处问题
访问有网就能从任何设备随时访问没有可靠的网络就取不到文件(cannot access files without a reliable internet connection)
容量少量空间可以免费(free of charge for a limited amount);容量容易扩大(quickly and easily increased)免费空间有限,不够要付费(may be limited so have to purchase more space)
数据相当于异地备份,方便灾后恢复(remote back-up of data)备份和安全由第三方负责,自己无法控制(do not have control over the backup or security)

2.1传输介质:有线与无线

光纤传光脉冲,距离最远、最快、最不受干扰,但最贵;无线方便移动,但更慢、更易被截获。

光纤fibre-optic cable用光脉冲而不是电信号传数据(transmits data as pulses of light),带宽高、干扰小、可以传得很远。无线网络用无线电波、微波等电磁波传输(transmits electromagnetic waves on different frequencies),设备不必接线,可以移动。

常考比较光纤与铜缆

比什么光纤铜缆
信号光(light)电信号(electrical signals)
带宽更高(higher bandwidth / transmission rates)较低
干扰更小(smaller risk of interference)较大
距离需要中继器之前能传更远(used over longer distances before repeaters are needed)较近
安全与损坏更难窃听(much more difficult to hack into),但更易损坏(more prone to damage)更易窃听,较耐用

常考比较有线与无线

方式好处代价
有线更稳定,速度更快,没有信号死角;性能好,干扰少,传私密数据更安全(better performance; less interference; transmit private data securely)设备不能移动;线多会绊人
无线设备可以在范围内自由移动,容易扩展(devices can be used in different rooms / portable);可以带多台自己的设备(bring multiple devices)更易受干扰,数据更易被截获,要加密;比有线慢
了解蓝牙、Wi-Fi、蜂窝网络和卫星

蓝牙(Bluetooth)在 2.45 GHz 附近的 79 个信道里随机挑一个,被占用就换一个,叫跳频(spread spectrum frequency hopping),适合 30 米以内、速度要求不高的传输。Wi-Fi 更快、范围更大(到无线接入点最远约 100 米)、更安全。

手机用蜂窝网络:地区分成许多小区,每个小区有一座带天线的塔,手机与塔之间用低功率无线电传数据,多台设备能同时与同一座塔通信(land is split into cells; each cell has a tower with an antenna)。

卫星的好处是不固定在一个地点,偏远地区也能连(allows access in remote / rural areas);问题是延迟高(high latency)、受恶劣天气影响、要有直接视线(direct line of sight needed)。

2.1网络设备

交换机在局域网内把包只送到目的设备,路由器在不同网络之间转发包,中继器把信号恢复后送得更远。

路由器router在不同网络之间接收和转发数据包(receives and sends data between two networks),靠路由表routing table决定往哪送(to store / update / maintain a routing table)。交换机switch把局域网里的设备连在一起,只把包转发给目的设备(receives transmissions and forwards them to their destination),靠每台设备的MAC 地址MAC address辨认它们。MAC 地址是网卡的唯一硬件地址(identifies a device uniquely; set at the manufacturing stage)。

中继器repeater把衰减的信号恢复后继续往远处送(restores the digital signal so it can be transmitted over greater distances)。网桥bridge连接两个协议相同的局域网(connects two LANs / segments with the same protocol)。无线接入点wireless access point (WAP)让无线设备接入有线网络(allows wireless-enabled devices to connect to a wired network)。无线网卡wireless network interface card (WNIC)让设备连上无线网络,并给设备提供 MAC 地址(provides a MAC address to the device to identify it on the wireless network)。

必考路由器做什么

收到数据包receives packets from the internet / external network
→
看每个包的目的地址analyses the destination IP address of each packet
→
查路由表,选最有效的路finds the most efficient route using the routing table
→
把包转发向目的地forwards the packet towards its destination

路由器还会给局域网里的设备分配地址(allocates private IP addresses),起防火墙的作用(implements a firewall),必要时改变包的格式,以便在下一个网络传输(changes the packet format for transmission over the next network)。

必考其他设备各做什么

设备作用
交换机 switch把设备互相连起来;收到传输后转发给目的设备(to connect individual devices to each other; to receive transmissions and forward them to their destination)
网桥 bridge连接两个协议相同的网络(to connect two LANs / segments with the same protocol)
中继器 repeater恢复数字信号,让它传得更远(restores the digital signal so it can be transmitted over greater distances)
无线接入点 WAP用无线电让设备连到有线网络(allows connection of devices using radio signals / Wi-Fi)
无线网卡 WNIC让设备连上无线网络,提供 MAC 地址(allows a device to connect to a wireless network)
了解集线器、调制解调器和网络地址转换

集线器(hub)把收到的包发给网络里的每台设备,不安全,还浪费带宽;交换机只发给目的设备,所以更安全、更有效。

调制解调器(modem)把数字数据转换成模拟数据以便在模拟线路上传输,收到时再转回数字数据。

网络地址转换(NAT: allows multiple devices in a private LAN to share a single public IP address)由路由器完成,局域网里的多台设备共用一个公网地址上网。

2.1以太网与碰撞

共用一条线的设备可能同时发送而碰撞;CSMA/CD 的办法是先听、线空才发、撞了就停并随机等一会再发。

载波侦听多路访问/冲突检测CSMA/CD是以太网用的协议(Carrier Sense Multiple Access / Collision Detection)。以太网把数据装进帧里发送(Ethernet transmits data as frames),帧里有发送方和接收方的地址。会碰撞是因为多台电脑接在同一传输介质上(more than one computer connected to the same transmission medium),两个节点可能同时开始发送(two workstations can start to transmit at the same time)。

必考描述 CSMA/CD

先监听信道listens to the communication channel
→
线路空闲才发送data is only sent when the channel is free
→
检测到碰撞,停止发送并发出干扰信号transmission is aborted / a jamming signal is sent
→
各自等一个随机时间再重发each waits a random time before trying again

碰撞次数越多,随机等待的时间就加得越长(the random time is increased if there are multiple collisions)。答题时要说出这几步,并说明为什么会碰撞。

2.1位流

位流是边下载边播放的连续数据,靠缓冲区把不稳定的下载变成平稳的播放。

位流bit streaming是通过网络连续发送的一串数字位(a contiguous sequence of digital bits sent over a network)。缓冲区先把服务器发来的数据存起来,等接收设备来处理(the buffer stores data from the server until the receiving device can process it);服务器到缓冲区的速率必须大于缓冲区到播放器的速率,播放才不会中断。

了解视频会议里的位流

发送前先压缩data is compressed before transmitting
→
音视频连续发出transmitted continuously as a series of bits
→
上传到媒体服务器uploaded to a media server
→
服务器把数据送进缓冲区the media server sends the data to a buffer
→
接收设备从缓冲区取位流the receiving device receives the bit stream from the buffer
了解随选位流和实时位流
方式怎么来能不能暂停
随选服务器上已有的文件先编码,用户点击链接后连续下载(on demand)能暂停、倒退、快进
实时摄像头和麦克风现场采集,编码后上传服务器,再发给用户(real time)不能,因为内容是直播

2.2互联网与万维网

互联网是网络的网络,万维网是跑在互联网上、用网址访问的网页集合。

互联网(internet)是网络的网络(a massive network of networks),用 TCP/IP 协议通信。万维网World Wide Web是存放在网站上的网页和其他文档的集合(a collection of web pages and other documents stored on websites),用互联网从服务器取得信息(uses the internet to access information from servers)。

统一资源定位符uniform resource locator (URL)写明网页的位置,格式是协议、网站地址、路径、文件名(protocol://website address/path/filename);协议通常是 http 或 https,网站地址包括域名主机、域名和域名类型。网页浏览器web browser用网址取得网页,并把收到的 HTML 解释后显示出来(interprets web pages sent to a user's computer)。

了解连上互联网要什么,以及网络电话

连上互联网需要:设备、电话线或手机网络、路由器(或路由器加调制解调器)、网络服务提供商(internet service provider, ISP)和网页浏览器。

方式怎么传
PSTN通话期间一直占用一条线路,是电路交换(circuit switching requires a dedicated line)
VoIP没有专用线路,只在传数据时才有连接(packet switching);声音切成数据包,沿最快的路发送,到达后重新组装(reassembled at the receiving end)

2.2IP 地址

IP 地址给联网设备编号:IPv4 是 32 位、四组;IPv6 是 128 位、八组十六进制;私有地址只在局域网内用,公网地址能被互联网访问。

IP 地址IP address是网络给每台设备的唯一地址,用来标识设备、把数据包送到它那里(uses IPv4 or IPv6 to give addresses to devices)。IPv4 地址IPv4是四组 8 位数、用句点隔开(four groups of 8-bit numbers separated by full stops; 32 bits);IPv6 地址IPv6是八组 4 位十六进制数、用冒号隔开,连续的全零组可以用 :: 代替(eight groups of 4 hexadecimal numbers separated by colons; 128 bits)。

公网 IP 地址public IP address让设备能被互联网直接访问(assigned to a device to allow direct access on the internet)。私有 IP 地址private IP address只在局域网内通信用(used for internal LAN communication only),由路由器分配(assigned by the router within the LAN)。静态 IP 地址static IP address固定不变,动态 IP 地址dynamic IP address每次重新入网时可能改变。

常考区分几类 IP 地址

类型说法
公网分配给设备,让它能在互联网上直接被访问(assigned to a device to allow direct access on the internet);路由器有公网地址,才能被外部网络看到(so that the router is visible to the internet / external network)
私有只用于局域网内部通信(used for internal LAN communication only);让路由器在局域网内被设备识别(identified to computers within the LAN)
静态固定不变,设备重新加入网络也一样(fixed / doesn't change each time a device re-joins a LAN)
动态可能刷新、改变(may be refreshed / changed each time a device re-joins a LAN)

了解比较 IPv4 与 IPv6

比什么IPv4IPv6
位数32 位128 位
组数4 组8 组
隔开句点(full stops)冒号(colons)
数字十进制(denary),每组 0 到 255十六进制(hexadecimal),每组 0 到 FFFF
了解怎么判断地址合法,以及零压缩

判断 256.0.0.A:不是 IPv4,因为每组最大只能是 255,而这里有 256(the maximum denary value should be 255);也不是 IPv6,因为它用句点而不是冒号隔开(uses a full stop to separate sections and not colon);所以是无效地址。

IPv6 的零压缩:连续的全零组可以用 :: 代替,但整个地址只能用一次,否则分不清每处压缩了几组。

900B3E4AAE4100000000AFF7DD44F1FF
压缩成900B3E4AAE41::AFF7DD44F1FF

私有地址预留了三段:10.0.0.0 到 10.255.255.255,172.16.0.0 到 172.31.255.255,192.168.0.0 到 192.168.255.255。

2.2子网划分

子网划分把一个网络切成几个小网络;IP 地址分成网络号和主机号,同一子网的设备网络号相同、主机号各不相同。

子网划分subnetting是把一个网络分成两个或更多个小网络(splits a larger network into smaller / more manageable parts)。IP 地址由网络号与主机号network ID and host ID两部分组成(an IP address is made up of a network ID and a host ID):同一子网的设备网络号相同(each device in a subnetwork has the same network ID),各个子网的网络号不同(each subnetwork has a different network ID);主机号在子网里唯一标识一台设备(the host ID uniquely identifies the device within the subnetwork)。

了解子网划分的好处

好处原因
减少拥堵同一子网内设备之间的数据留在子网里,不用传远(data stays within the subnet; reduces congestion)
更安全设备不会收到不该收的数据;一台设备被攻破,不会暴露整个网络(devices do not receive unintended data)
好管理故障更容易隔离(faults can be isolated more efficiently);网络更容易扩展(easier to scale a network with subnets)
更简单隐藏了整个网络的复杂性(hides the complexity of the network)
了解教材里的大学例子与 CIDR

大学网络的网络号是 192.200.20,有八个系。把主机部分的前 3 位当作子网号(000 到 111,共 8 个子网),后 5 位当作主机号,每个子网的主机号从 00001 到 11110,全 0 和全 1 不能用。上图的 011 00011 属于子网号 3(011)的子网,即 Science 系。

CIDR 用后缀指出网络号占几位(classless inter-domain routing):/18 表示前 18 位是网络号,后 14 位是主机号。

2.2域名服务

人记的是网址,网络用的是 IP 地址;浏览器要先让 DNS 服务器把域名换成 IP 地址,才能连上网站服务器。

域名服务domain name service (DNS)负责找出域名对应的 IP 地址(finds the IP address of a Uniform Resource Locator);DNS 服务器里存着网址和 IP 地址的对应数据库(a database of URLs with the matching IP addresses)。有了它,用户不必记住 IP 地址。

了解浏览器怎样用网址取得网页

先查自己的缓存checks its cache for the URL
→
把网址拆成几个部分parses the URL and splits it into its component parts
→
向 DNS 服务器查域名对应的 IP 地址finds the IP address by querying a DNS server
→
与该 IP 地址的网站服务器建立连接并请求网页creates a connection with the web server; a request for the resource is sent
→
渲染并显示,把 IP 地址存入缓存renders and displays the result; the IP address is stored in the cache
