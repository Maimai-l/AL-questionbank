6.1数据隐私与访问权限

隐私管"谁能看到数据",安全管"别人拿不到、丢了能恢复";靠账户证明身份,再按访问级别决定能看什么。

数据隐私data privacy是存在计算机里的个人或机构信息,只能让被授权的人看到(data can only be accessed by or disclosed to authorised persons, not to unauthorised parties)。数据安全data security是防止未授权访问数据(prevent unauthorised access to data)的办法,也包括数据丢失或损坏后把它找回来(recover data if it is lost or corrupted)。

用户账户(user account)先做身份认证authentication,证明用户确实是他声称的人(proving somebody is who they claim to be);再由访问权限access rights按访问级别(access levels)保证只有授权用户才能打开某些数据(only authorised users can gain access to certain data)。

了解数据保护法的八条原则

各国的数据保护法(data protection laws)不同,但都围绕同样八条原则,多数针对组织而不是个人。

数据要合法、公平地处理(fairly and lawfully processed);只能用于声明的目的(processed for the stated purpose);要足够、相关、不过量(adequate, relevant and not excessive);要准确(accurate);保存不超过必要的时间(not kept longer than necessary)。

还要按数据主体的权利处理(in accordance with the data subject's rights);要妥善保管(kept secure);没有足够保护的国家,不能把数据传过去(not transferred to a country without adequate protection)。

6.1密码与生物识别

密码要难猜:同时有大写字母、数字和其他符号,不用生日、宠物名;生物识别是拿人体特征当密码。

密码password让只有输入正确密码的用户才能使用资源(only users with the correct password can access the resources // prevents unauthorised access)。强密码(strong password)混用不同类型的字符,长度不少于规定,而且和本人无关,比如不是生日(a mixture of different types of characters, at least a set number of characters, not something connected to the individual such as a date of birth);还要经常更换(regularly change passwords)。

生物识别biometrics利用每个人独有的特征来认人(unique human characteristics to identify a user),例如指纹(fingerprint)、视网膜(retina scan)、人脸和声音。再多要一道验证,比如生物识别或验证器应用,就是多因素认证(multi-factor authentication: a second form of verification is required for logging in)。

了解指纹与视网膜:怎么比对

指纹:把扫描图像和数据库里存好的指纹比对,比的是脊和谷的图案(patterns of ridges and valleys),准确率约 1/500。

视网膜:用红外线扫描眼底血管的独特图案(infra-red scan of the pattern of blood vessels),要保持不动 10 至 15 秒,准确率约 1/1000 万,目前没有人能复制这种图案。

6.1防火墙与反恶意软件

防火墙守在计算机和外部网络之间,只放行符合规则的数据;反恶意软件在计算机里扫描文件,发现恶意程序就隔离或删除。

防火墙firewall可以是软件也可以是硬件(software or hardware),监测进出的网络数据(monitors incoming and outgoing traffic),和用户设定的条件比较,例如白名单、黑名单或允许、禁止的 IP 地址(compares it to criteria set by the user such as a whitelist / blacklist / allowed or blocked IP addresses),不符合条件的就拦下(blocks those that do not match the criteria)。

反恶意软件anti-malware(也叫杀毒软件(anti-virus software))扫描文件和下载内容,和已知病毒的数据库比较(compares against a stored database of known viruses),发现就隔离、删除或提醒用户(quarantines / deletes / alerts the user);病毒库要定期更新(needs to be updated regularly)。反间谍软件(anti-spyware)专门检测并清除间谍软件。

必考用什么措施防什么威胁

威胁常用措施
黑客入侵防火墙、强密码或生物识别密码、用户权限(firewall / strong or biometric passwords / user permissions)
病毒、恶意软件杀毒或反恶意软件、防火墙(anti-virus // anti-malware // firewall)
间谍软件防火墙、安装并运行反间谍软件(firewall / install and run anti-spyware)
钓鱼、域名欺骗不打开链接、不下载附件,运行反恶意软件(do not open links or download attachments // anti-malware)
了解防火墙做什么、做不到什么

防火墙的任务:检查内外网之间的数据(examining the traffic);不符合条件就拦截并警告(blocking the traffic and giving a warning);记录所有进出的数据以便日后查看(logging all incoming and outgoing traffic);把不良网站的 IP 地址列入名单禁止访问。

它做不到:阻止内网用户用自己的调制解调器绕过它,管住员工的疏忽或不当行为,也不能阻止单机用户自己把它关掉。

了解杀毒软件怎么发现病毒

运行前先检查文件(check files before they are run or loaded),和已知病毒的数据库比较;再做启发式检查(heuristic checking: check for behaviour that could indicate a virus),这样数据库里还没有的新病毒也有机会发现。

可疑文件先放进隔离区(quarantine),由软件自动删除,或由用户决定。好文件被误判为病毒叫误报(false positive),是杀毒软件的缺点之一。还要定期做全盘扫描,因为有些病毒会潜伏不动。

6.1加密

加密把明文打乱成密文,没有正确的解密密钥就看不懂;它防的是数据被读懂,拦不住别人删文件。

加密encryption用加密密钥把数据打乱成密文(an encryption key is used to scramble data into cipher text),没有正确的解密密钥它就毫无意义(meaningless without the correct decryption key)。即使数据被截获,也读不懂(if intercepted the data cannot be understood without the decryption key)。

密文cipher text是明文(plain text)用加密密钥加密后得到的、不能读的数据(data is encoded / scrambled using a key to create cipher text)。

了解用公钥加密、私钥解密

发送方用收件人的公钥(public key)加密文件,生成密文;密文只能用收件人的私钥(private key)解密。

明文收件人的公钥加密 →密文收件人的私钥解密 →明文

加密不能阻止黑客删除文件,只能让他们没法使用读到的数据。

6.1安全威胁:黑客、病毒与间谍软件

黑客入侵是未经许可闯进系统;恶意软件是装进系统的坏程序,病毒会自我复制,间谍软件偷偷记录并外传。

黑客入侵hacking是未经所有者许可就访问计算机系统(illegal access to a computer system without the owner's permission),常怀恶意(with malicious intent),比如删除、修改文件或窃取银行账户等个人数据。经公司允许、用来测试系统安全的叫道德黑客(ethical hacking),是合法的。

恶意软件malware是为了破坏或未经授权进入计算机系统而设计的软件(malicious software that seeks to damage or gain unauthorised access to a computer system),例如修改或删除文件(malicious code that can alter / delete files)。计算机病毒virus是能自我复制的恶意程序(replicates / copies itself),会修改、删除或破坏计算机里的文件和数据(alters / deletes / corrupts files and data);它要依附在运行中的宿主程序上才能运行。

间谍软件spyware在用户不知情时装进计算机(downloaded without the user's knowledge),偷偷记录按键和操作(secretly records the user's actions / keystrokes),再把记录发给第三方(sends logs of the actions to a third party)。

必考辨认威胁:病毒和间谍软件的区别

比较病毒间谍软件
对数据破坏数据(can damage computer data)只记录、读取(only records / accesses data)
复制会自我复制(replicates itself)不复制(does not replicate itself)
数据外传不向外发数据把记录发出去(sends recorded data out)
了解蠕虫、逻辑炸弹、特洛伊木马、僵尸程序

蠕虫(worm):独立的病毒,自我复制并通过网络找安全性弱的计算机传播。

逻辑炸弹(logic bomb):藏在程序里的代码,条件满足(如到了某个日期)才启动,去删文件或把数据发给黑客。

特洛伊木马(trojan horse):伪装成正规软件,取代全部或部分正规软件,再做破坏。

僵尸程序(bot):不一定有害,比如自动搜索网页;但可能接管计算机去发动攻击。

6.1网络钓鱼与域名欺骗

钓鱼要用户自己动手点链接;域名欺骗不用用户动手,恶意代码自动把人带到假网站。

网络钓鱼phishing是看起来正规的电子邮件(legitimate-looking emails),冒充官方机构(the email pretends to be from an official body),劝收件人点链接去非官方网站,泄露银行信息等个人数据(persuading individuals to disclose private information, such as bank details)。

域名欺骗pharming是装在计算机上的恶意代码(malicious code installed on a computer),把用户重定向到假网站(redirects user to a fake website),从而取得个人数据(to obtain personal data)。

6.1数据恢复:备份

数据丢了靠备份找回:定期备份到另一种介质,并放在另一个地方。

备份backup是把数据复制到别处(backup / archive computer systems)。误操作、硬件故障和软件故障造成的数据丢失,都靠它恢复。可以自动备份,也可以每天结束时手动备份,存到云存储或移动硬盘这样的另一种介质上,并放在另一个地点,防止火灾或失窃时一起丢掉;最好指定专人负责。

了解病毒感染时,备份不一定能救

备份的数据里可能带着病毒(the backed up data may contain strands of the virus),恢复后会让"清理过"的计算机再次感染,所以病毒感染后不能只靠备份。

6.2数据完整性与数据验证

数据完整性是数据准确、完整、一致;验证只查输入"合理、在范围内",不查它到底对不对。

数据完整性data integrity是数据准确、完整、一致(the accuracy, completeness and consistency of data)。数据输入和传输时出错、恶意攻击、硬件故障造成的意外丢失,都会破坏它。

数据验证validation由计算机软件检查输入的数据是否合理、在设定的范围内(checks that data is reasonable / sensible / within bounds),但不检查输入的是不是准确的数据(it does not check that accurate data has been entered)。常见的有:非空检查presence check查字段有没有留空(a field is not left empty);范围检查range check查数据在上下限之间(between a lower and an upper limit);长度检查length check查字符数对不对(the correct quantity of characters);类型检查type check查数据类型对不对(e.g. alphanumeric / an integer value);格式检查format check查是不是约定的格式(the agreed format)。

常考给字段选验证检查

检查查什么不通过的例子
非空字段不能是空的护照号码一栏空着
范围在下限和上限之间年龄输入 −120
长度要求的字符个数11 位的电话号码只输入 9 位
类型数字栏里不能有非数字价格栏输入 sk.34
格式符合约定格式要求 dd/mm/yyyy,却输入 12-12-20
了解另外四种验证检查

存在检查(existence check: compares the data entered to a list of possible values; if it is not one of them, it is rejected):例如骑手等级只能是 Beginner、Intermediate 或 Advanced;汽车牌照 A123 BCD 查不到,就不通过。

限值检查(limit check):只查一个界限,上限或下限二选一,如年龄不能是负数。

一致性检查(consistency check):两个字段要对得上,如称呼填 Mr,性别却选 female。

唯一性检查(uniqueness check):值不能重复,如用户名 MAXIMUS222 已被注册。

6.2输入时的数据校验

校验查的是"和原件一样吗";手工输入数据时,靠双重输入和目视核对。

数据校验verification检查输入或传输的数据和原件一样(checks that data entered or transferred is the same as the original)。手工输入时有两种做法:双重输入double entry把数据输入两次,由计算机比较是否相同(enter the data twice and the computer compares them),教材里是由两个不同的人输入;目视核对visual check是把输入的数据和原件手工对照(manually compared to the original data to make sure that they are the same),比如打印出来和原件比。

6.2校验位

校验位是加在数字后面的一位,由前面各位算出来;重算一遍对不上,就是输错了。

校验位check digit是附加在数字后面的一位(an additional digit appended to a number),由其余各位算出,用来检查输入的数据有没有出错(to check that the entered data is error free)。条形码、ISBN 和车辆识别号都带校验位。

了解用 modulo-11 算校验位

从左到右,每位数字依次乘权重 7、6、5、4、3、2、1,乘积相加,总和除以 11 取余数,再用 11 减余数,得数就是校验位;得数是 10 时写成 X。

106÷ 11 → 9 余711 − 7 →4

检查时重算校验位。若误输成 4 1 5 7 6 1 0 4(第 4、5 位对调):28 + 6 + 25 + 28 + 18 + 2 + 0 = 107,107 ÷ 11 = 9 余 8,11 − 8 = 3,和输入的 4 不同,所以报错。

了解校验位能发现哪些错误

错一位数字(an incorrect digit: 8190 instead of 8180);两位对调(a transposition error: 8108 instead of 8180);漏掉或多出数字(digits omitted or added: 818 or 81180);读音混淆(phonetic errors: 13 thirteen instead of 30 thirty)。

6.2校验和与自动重传

发送方把数据算出一个校验和,和数据一起发出;接收方重算一遍,两个值不同就是传输出错。

校验和checksum是由数据算出、随数据一起发送的值(a calculation is made from the data and the result transmitted with the data)。接收方重复同样的计算,和收到的值比较(the receiver repeats the calculation and compares the result with the value received);两个值不同就有错误(if the two are different, there is an error),要求重发。另一种传输校验是自动重传请求automatic repeat request(ARQ)。

了解算 1 字节的校验和

校验和 = 总和 − (总和 ÷ 256 取整) × 256总和 ≤ 255 时,校验和就是总和;总和 1185:1185 ÷ 256 = 4.629,取整 4;4 × 256 = 1024;1185 − 1024 = 161

了解自动重传请求怎么工作

接收方发现错误,就要求重发这个数据包(asks for the data packet to be re-sent);没发现错误,就回送肯定的确认(positive acknowledgement)。

发送方在收到重发请求,或超时(timeout: the time allowed to elapse before an acknowledgement is received)仍没收到确认时,重发数据。整个过程重复到收到正确的数据,或到达超时上限为止。手机网络常用它保证数据完整。

6.2奇偶校验

每个字节加一个奇偶位,让 1 的个数符合事先约定的偶数或奇数;收到的字节个数对不上,就是出错。

奇偶位parity bit是加在每个字节上的一位,让 1 的个数是奇数或偶数,和约定的一致(a parity bit is added to each byte to make the number of 1s match the parity, odd or even)。奇偶校验parity check就是靠它检查传输:收发双方先约定奇偶(agree on whether to use odd or even parity),若用偶校验却收到 1 的个数为奇数的字节,就有错误(a byte with an odd number of 1 bits is received when even parity is used, there is an error)。

了解奇偶校验判错与它的局限

先数收到的字节里 1 的个数,和约定的奇偶比较:对得上就没发现错误,对不上就是出错。奇偶位的取法:偶校验时,数据有奇数个 1,奇偶位取 1,否则取 0;奇校验反过来。

局限:只知道出错了,不知道哪一位错。若同时错两位,1 的个数的奇偶不变,就查不出来。

了解两位同时出错,为什么查不出

发送的字节 0 1 0 1 1 1 0 0 是偶校验。若第 3 位和第 8 位同时变成 1,收到 0 1 1 1 1 1 0 1:共 6 个 1,仍是偶数,不会报错,所以还要配合校验和等其他方法。

6.2奇偶块校验

横向每个字节查一次,纵向每一列也查一次;出错的行和出错的列交叉的那一位,就是错位。

奇偶块校验parity block check把若干字节排成一块,横向查每个字节,纵向数每一列(每个位的位置)里 1 的个数(the number of 1s in each column / bit position is counted);给每列配一位使这一列也符合奇偶,这些位组成奇偶字节一起发送(these parity bits are transmitted with the data as a parity byte)。收到后重新检查,就能确定错误位的位置(the position of an incorrect bit can be determined)。
