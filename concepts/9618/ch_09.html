9.1.1抽象

抽象就是只留下解决问题必需的信息,把无关的细节去掉。

抽象abstraction是抽取解决问题必需的信息、忽略无关的信息(filter out information / data that is not necessary for the task),也就是只保留任务需要的数据(keep only information / data that is necessary for the task),得到一个只为某个目的服务的简化模型。地图、日历、时刻表都是抽象的例子:公路图只画道路、路号和城镇。

计算思维computational thinking是研究一个问题,设计出计算机能执行的有效解法(formulate an effective solution that can be provided using a computer);用到的方法有抽象、分解、算法和模式识别(abstraction, decomposition, algorithms and pattern recognition)。

9.1.2分解与模式识别

分解把大问题拆成小问题,一直拆到每一块都容易写;相似的小块可以共用同一段代码。

分解decomposition是把复杂的问题拆成更小的子问题(breaking down a problem into sub problems),每个子问题再拆,直到容易理解和解决。结果是程序由一系列模块、过程或函数组成(a program designed as a series of modules / procedures / functions)。模式识别pattern recognition是找出问题中相似的部分,它们可以用同一个解法(parts of a problem that are similar and could use the same solution),于是写出可重复使用的代码(reusable code)。

了解设计模块题:每个模块一个名字,一件事

题目说"描述三个模块"(Describe three program modules):每个模块写一个函数名式的名称,再用一句话说它做什么,例如 FindSeats() 用来查找有空位的座位(allows the user to search for available seats)。

类型特点
过程 procedure执行一组语句,不返回值,用 CALL 调用
函数 function要返回一个值时用函数(the type of program module that should be used to return a value: function)
了解分解出来的模块有什么用

每个最终的小块写成一个独立模块,单独写、单独测试(written and tested as a separate procedure or function)。已经写好并测试过的模块可以直接重用,节省开发时间(reuse program modules already written and tested)。

9.2.1算法与两种文字写法

算法是完成一项任务的有序步骤;可以写成结构化英语、伪代码,也可以画成流程图。

算法algorithm是为完成一项任务或解决一个问题而按顺序执行的一组步骤(an ordered set of steps to be followed in the completion of a task)。结构化英语structured English用约定好的一小批简单英语词表示命令和运算(an agreed subset of straightforward English words for commands and mathematical operations),步骤可以编号;没有固定规则,只要不含糊、容易看懂(unambiguous and easily understandable)。

伪代码pseudocode用关键字、有意义的标识符名和数学运算符写出算法的详细步骤(keywords, identifiers with meaningful names, and mathematical operators)。它不必符合某一种编程语言的语法(does not need to follow the syntax of a specific programming language),但要详细到能据此写出程序。本书和考试都按剑桥伪代码指南:等宽字体,缩进 4 格,THEN、ELSE 和 CASE 的分支只缩进 2 格。算法里用到的每个变量,列进标识符表identifier table:一列名字,一列用途(each identifier with a description of its purpose)。

9.2.2赋值与输入输出

伪代码一行一步:输入用 INPUT,输出用 OUTPUT,赋值用 ←,把右边算出的结果存进左边的变量。

输入语句读入一个值并存进变量(INPUT StudentName),输出语句可以同时输出信息和变量的值(OUTPUT "Student name is ", StudentName)。赋值语句把一个值或一次计算的结果存进变量(assign a value to a variable),字符串用 & 连接(string concatenation)。标识符名要有意义(meaningful identifier names),只含字母和数字,以字母开头,不分大小写。

了解整除、取余和取整
17 DIV 5=317 MOD 5=2INT(7.9)=7

DIV 取商的整数部分,MOD 取余数(17 = 5 × 3 + 2);INT(x) 返回 x 的整数部分。常用 INT(Value) = Value 判断输入的是不是整数。

9.2.2选择:IF 与 CASE

IF 按条件走其中一条路,选项很多时用 CASE;IF 以 ENDIF 结尾,CASE 以 ENDCASE 结尾。

选择selection让程序按条件决定执行哪些语句,用 IF 或 CASE。条件由比较运算符和 AND、OR、NOT 组成,结果只有真或假(the outcome is always either true or false)。注意边界:Mark < 40 与 Mark <= 40 在 Mark = 40 时结果不同。

了解用 IF 还是 CASE

结构适合结尾
IF判断一个条件,或比较范围(如 Mark < 60)ENDIF;可带 ELSE
CASE一个变量有几个具体取值,每个取值对应一件事ENDCASE;可带 OTHERWISE 处理其余情况
了解嵌套 IF:按分数评等级

ELSE 里再放一个 IF,就是嵌套;每个 IF 都要有自己的 ENDIF,靠缩进看出层次:

IF Mark < 40
  THEN
    Grade ← "Fail"
  ELSE
    IF Mark < 60
      THEN
        Grade ← "Pass"
      ELSE
        IF Mark < 80
          THEN
            Grade ← "Merit"
          ELSE
            Grade ← "Distinction"
        ENDIF
    ENDIF
ENDIF

9.2.2循环:FOR、WHILE、REPEAT

次数固定用 FOR;不知道循环几次就用 WHILE 或 REPEAT,区别是条件在前还是在后。

迭代iteration就是循环,重复执行一组语句(an iterative construct // a loop)。FOR 的重复次数固定(count-controlled loop),STEP 是可选的增量,必须是整数。WHILE 在条件为真时继续循环,每次进入前先判断;REPEAT 在 UNTIL 的条件变为真时才结束,条件放在末尾,所以循环体至少执行一次。

常考选哪种循环,并说明理由

循环条件在哪最少执行理由怎么写
FOR计数,到终值为止按次数次数已知,如输入 100 个数(count-controlled loop)
WHILE进入前判断0 次次数未知,可能一次也不做
REPEAT末尾判断1 次次数未知,至少做一次,如读入数据直到某个值

评分细则的例子:输入一串数直到 0 为止,答"条件循环 (pre / post) conditional loop",理由是循环次数未知,在输入某个特定的值时结束(the number of iterations is not known // loop ends following a specific input)。

必考计数与求和:初始化、更新、输出

Total ← 0                            // initialise before the loop
FOR Index ← 1 TO 100
    INPUT Num
    IF Num >= 30 AND Num <= 70
      THEN
        Total ← Total + Num
    ENDIF
NEXT Index
OUTPUT Total                         // output after the loop
给分点评分细则
循环前初始化Initialise Total to zero (counting 同理:Count ← 0)
循环内输入Input a number, repeat 100 times
循环内判断并累加Check the number is in range; if true, add to Total
循环后输出Output Total after the loop

计数把 Total ← Total + Num 换成 Count ← Count + 1;"30 到 70 含两端"写成 >= 30 AND <= 70(也可以写 > 29 AND < 71)。

9.2.2手工追踪:追踪表

追踪表就是手工执行算法:每执行一行,把变量的新值写进表里,最后得到输出。

追踪表trace table每一列是一个变量或输出,每一行记录一次变化(complete the trace table)。从上到下按程序的顺序执行,不要跳,不要凭感觉写结果。

9.2.3从结构化英语写伪代码

先从描述里找出变量、输入输出、选择、循环和处理,列好标识符表,再按原来的顺序一句一句译成伪代码。

结构化英语没有固定规则,用词只要不含糊、容易看懂(unambiguous and easily understandable);伪代码更精确,遵循一套约定的规则(pseudocode is more precise and usually follows an agreed set of rules)。每个结构化英语语句译成一条或几条伪代码,顺序不变。

9.2.4流程图

流程图用固定形状的框和带箭头的线画出算法;菱形是判断,两个出口都要标 Yes 或 No。

流程图flowchart用一套标准符号和流线表示算法(a diagrammatic representation of an algorithm using standard symbols joined by flow lines),表示每一步和执行顺序,最适合看出算法的结构。读图时顺着箭头走,遇到菱形按当前值选 Yes 或 No。

    INPUT Num

    ENDIF

真题例:先设 Count ← 1、Flag ← FALSE,Flag 为假且 Count ≤ 5 时反复调用 ReBoot()、Count 加 1、用 Check() 的返回值给 Flag 赋值,循环结束后若 Flag 仍为假就调用 Alert(27):

Count ← 1
Flag ← FALSE
WHILE Flag = FALSE AND Count <= 5
    CALL ReBoot()
    Count ← Count + 1
    Flag ← Check()
ENDWHILE
IF Flag = FALSE
  THEN
    CALL Alert(27)
ENDIF

给分点:Count 和 Flag 都初始化;循环里两个条件都写上;Count 加 1 和给 Flag 赋值都在循环里;最后的判断和 Alert(27) 在循环外(final test of Flag AND call to Alert(27) not in a loop)。

9.2.5逐步细化

逐步细化就是把每一步再拆成更小的步,一直拆到每一步都能写成一条语句。

逐步细化stepwise refinement是把大问题的每一部分再分成一连串更小的步骤,如此继续(subdividing each part of a larger problem into a series of smaller parts, and so on, as required),直到每一步都能写成高级语言中的一条语句。它建立在分解的基础上,细化后的步骤可以直接写成伪代码。

了解用逐步细化写出步骤
