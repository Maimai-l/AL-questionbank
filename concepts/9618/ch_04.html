4.1处理器的部件

程序和数据都放在内存里,处理器取出来按顺序执行:控制单元发号施令,ALU 负责计算,系统时钟打节拍。

冯·诺依曼模型Von Neumann model有三个特点:处理器能直接访问内存(a processor able to access the memory directly);内存里既存数据也存程序(memories that could store programs as well as data);程序由指令组成,按顺序执行(instructions executed in sequential order)。

处理器有四个主要部件。算术逻辑单元ALU做算术运算和逻辑比较(performs mathematical operations and logical comparisons);控制单元control unit读出指令并译码,沿控制总线向其他部件发信号(sends signals to other components on the control bus),协调各部件的工作(coordinate events based on the pulses of the system clock);系统时钟system clock产生计时信号,让各部件同步(creating and transmitting timing signals on the control bus);内存immediate access store, IAS存放处理器要用的全部程序和数据,是主存 RAM 的另一个名字(another name for primary (RAM) memory),读写比后备存储快得多。

了解ALU 怎么做乘除

乘法和除法由一连串的加、减和左右移位完成(a sequence of addition, subtraction and left/right shifting operations)。例如把 0011 0111 向左移两位,得到 1101 1100,相当于乘 4:

0011 0111 (55)左移 2 位 →1101 1100 (220)= 55 × 4

一台计算机可以有不止一个 ALU:一个做定点运算,另一个做浮点运算。

4.1寄存器

寄存器是处理器里最快的小存储单元:通用寄存器放临时数据,专用寄存器各管一件事,记录程序执行到哪一步。

通用寄存器general purpose register可以被大多数指令使用,存放任意用途的临时数据(can be used by most instructions; hold the temporary data while performing operations)。累加器accumulator就是通用寄存器,暂存 ALU 运算的数据和结果(temporarily stores the data and results of arithmetic and logic operations)。专用寄存器special purpose register有固定的功能,保存程序执行的状态(specialised for a specific use; hold the state of the program's execution)。

取指时用到四个专用寄存器。程序计数器program counter, PC存放下一条要取的指令的地址(holds the address of the next instruction to be loaded),这个地址送入内存地址寄存器(sent to the Memory Address Register)。内存地址寄存器memory address register, MAR存放正在读或写的内存单元的地址(stores the address of the memory location where data will be read from/written to)。内存数据寄存器memory data register, MDR存放从 MAR 地址读出的数据,或将要写入这个地址的数据(holds data read from the memory address in the MAR; holds data to be stored in the memory address in the MAR)。当前指令寄存器current instruction register, CIR存放正在译码、执行的指令(stores the current instruction being decoded and executed)。

变址寄存器index register, IX里的数要和操作数相加,得到数据的地址(stores a number that will be added to the operand, to form the address of the data)。状态寄存器status register, SR存放标志位,标志由算术逻辑运算的结果和中断设置(stores flags which are set by events // from the results of arithmetic and logic operations and interrupt flags)。

必考比较通用寄存器与专用寄存器

类型特点

专用只有特定用途,只有某些指令能用,存程序的状态(specialised for a specific use; certain instructions; the status of a program)
了解状态寄存器里的标志位

状态寄存器的每一位是一个标志(flag)。常见四个:进位标志 C 加法产生进位时为 1(carry flag: a CARRY following an addition);负标志 N 结果为负时为 1(negative flag);溢出标志 V 溢出时为 1(overflow flag);零标志 Z 结果为 0 时为 1(zero flag)。

11901110111 5600111000 结果10101111
N V C Z1100

两个正数相加,结果的最高位却是 1:结果是负数(N = 1),也发生了溢出(V = 1),没有进位(C = 0),结果不是零(Z = 0)。

4.1总线

三条总线并行传送数据:地址总线只往一个方向送地址,数据总线双向送数据,控制总线送控制信号。

系统总线是并行传输的通道,每根线传一位(each wire in the bus transmits one bit of data)。地址总线address bus传送读写数据的地址,在 CPU 和内存之间是单向的(carries the address where data is being written to or read from; unidirectional);数据总线data bus是双向的(bidirectional),传送的可以是地址、指令或数值(carries data to components);控制总线control bus也是双向的,传送控制单元发出的控制信号和时钟的计时信号(send / receive control signals along the control bus)。

常考说出三条总线的作用

总线方向传送什么
地址总线单向地址(carries the address)
数据总线双向数据(carries data)
控制总线双向控制信号(control signals)

了解总线宽度

n 位地址总线能直接寻址 2ⁿ 个内存单元16 位:2¹⁶ = 65 536 个;32 位:2³² = 4 294 967 296 个

地址总线越宽,能同时直接寻址的单元越多;数据总线越宽,一次能传送的字越长(the wider the bus, the larger the word length that can be transported)。

4.1提高处理器性能

提高时钟速度、加大缓存、增加内核,都能让处理器每秒处理更多指令,但每一种都有限制,不是越多越好。

时钟速度clock speed是每秒的时钟脉冲数(clock pulses per second)。每个脉冲执行一个取指执行周期(one F-E cycle is run on each clock pulse),所以时钟速度越高,每秒执行的指令越多(the faster the clock speed the more instructions can be run per second)。3.5 GHz 就是每秒 35 亿个时钟周期(3.5 billion clock cycles a second)。

高速缓存cache memory存放常用的指令和数据(stores frequently used instructions and data),是靠近 CPU 的快速存储器(fast access memory close to the CPU)。处理器读内存时,先查缓存,没有再读主存(it first checks cache and then moves on to main memory)。缓存用 SRAM,主存用 DRAM(SRAM is used in cache; DRAM is used in main memory)。内核core由一个 ALU、一个控制单元和寄存器组成(one core is made up of an ALU, a CU and the registers);常见双核和四核。

必考提高性能的方法与限制

方法好处与限制
提高时钟速度好处:每秒执行的指令更多(more instructions can be run per second)。限制:超出设计的速度,指令来不及完成,会不同步、死机,CPU 还会过热(overheating of the CPU; unsynchronised operations)。
加大缓存好处:常用的指令和数据读得更快(more instructions / data can be processed each second)。限制:数据不在缓存里时,还要去读主存。
增加内核好处:不必一味提高时钟速度(increase the number of cores)。限制:内核间要通信,多出开销;软件未必为多核设计(additional overheads; software may not be designed for multiple cores)。
加宽总线好处:地址总线宽,可寻址更多单元;数据总线宽,一次传更多。

4.1端口

外部设备通过端口连接计算机:USB 是通用的串行接口,HDMI 传数字的声音和图像,VGA 是老的模拟视频接口。

USB是异步串行传输方式(asynchronous serial data transmission)。设备插上后,计算机自动识别它,并加载合适的设备驱动程序(the device is automatically recognised, and the appropriate device driver is loaded);接口只有一种插法,不会插错(the connectors can only fit one way)。

HDMI把音频和视频一起输出到支持 HDMI 的设备(output both audio and visual; a single cable),是数字接口,带宽高(a digital interface; high bandwidth),比 VGA 干扰少(less prone to error/crosstalk/external interference),还用 HDCP 防盗版(high-bandwidth digital copy protection)。VGA是旧的模拟技术(analogue),支持 640 × 480 像素,逐步被 HDMI 取代。

了解比较 HDMI 与 VGA

答题抓三点:HDMI 是数字接口,VGA 是模拟接口(digital interface vs analogue interface);HDMI 传输速率更快(HDMI has faster transfer rates than VGA);HDMI 支持更高的分辨率,并能同时传音频和视频(supports the high resolution; video and audio transfer)。

4.1取指执行周期

处理器不停地重复:取指、译码、执行;取指走 PC → MAR → MDR → CIR 这条路,PC 每次加 1。

取指执行周期fetch-execute cycle是处理器反复进行的过程:从内存取出指令,译码,再执行(fetches an instruction from memory, decodes it and then executes it)。取指时,按 PC 里的地址取出指令,放进 CIR,PC 加 1,准备下一条(the next instruction is fetched from the address in the PC and stored in the CIR; the PC is incremented)。执行时,译码后的指令变成一组控制信号,送给各部件(the decoded instruction is passed as a set of control signals to the appropriate components)。

这些步骤可以用寄存器转移记号register transfer notation, RTN写出来:方括号表示取里面的内容,箭头表示复制到哪里。

必考用 RTN 描述取指

RTN意思
MAR ← [PC]PC 的内容复制到 MAR(contents of PC copied into MAR)
PC ← [PC] + 1PC 加 1(the Program Counter is incremented)
MDR ← [[MAR]]MAR 所指地址里的数据复制到 MDR(data at the address in MAR copied to MDR)
CIR ← [MDR]MDR 的内容复制到 CIR(contents of MDR copied into CIR)

第三行用双层方括号:复制的不是 MAR 本身的内容,而是 MAR 所指的那个地址里存的数据。之后控制单元对 CIR 里指令的操作码译码(the Control Unit decodes the instruction's opcode)。

4.1中断

中断是要求处理器马上处理的信号;处理器在周期开始或结束时检查,优先级更高就保存现场、去运行中断服务程序,运行完再回到原来的任务。

中断interrupt是设备或软件发给处理器的信号,要求处理器暂时停下手头的工作去处理(a signal sent from a device or from software to the processor)。来源有:计时信号、输入输出(如磁盘准备好接收数据)、硬件故障(如打印机卡纸)、用户操作(如按键)和不能忽略的软件错误(如除以零)(timing signal; input/output; hardware fault; user interaction; software error)。

发生中断时,对应的位记在中断寄存器interrupt register里(an interrupt flag is raised in the interrupt register; stores details of any interrupts that have occurred)。处理器要找出中断的类型和优先级(identify the interrupt type and establish the level of interrupt priority),再调用中断服务程序interrupt service routine, ISR(也叫 interrupt handler)来处理(the relevant ISR / interrupt handler is called to process the interrupt)。

优先级不比当前任务高,处理器就先不处理,继续原任务(carries on with what it was doing)。ISR 结束后,还要再检查有没有更高优先级的中断(when ISR finished, check for further interrupts of higher priority)。

了解ISR 是怎么被启动的

处理器先保存当前任务的状态:PC 和其他寄存器的内容都存起来(the contents of the program counter and other registers are saved)。然后把 ISR 的起始地址装入 PC,ISR 就开始执行(the ISR is executed by loading the start address into the program counter)。中断处理完后,取回保存的寄存器内容,任务从中断前的地方继续。

有了中断,计算机才能同时做几件事,比如一边下载文件,一边播放音乐。

4.2汇编语言与汇编

汇编语言用助记符代替二进制,每条指令是操作码加操作数;汇编器把它翻译成机器码,要扫描两遍才能填好标签的地址。

机器码machine code是 CPU 唯一能直接执行的语言(the only programming language that a CPU can use)。汇编语言assembly language和机器码关系密切,用助记符代替二进制(uses mnemonics instead of binary)。两者的指令结构相同:操作码opcode指明要执行的操作(identifies the operation to be carried out),操作数operand指明操作码要用的数据(identifies the data to be used by the opcode)。

汇编器assembler把每条汇编指令翻译成一条机器码指令(translates each assembly language instruction into a machine code instruction),并检查语法,确认用的操作码都在指令集里。符号表symbol table记录每个标签和它对应的内存地址(labels with their addresses)。

了解两遍汇编:为什么要扫描两遍

两遍汇编器要把源程序扫描两遍,才能把标签换成内存地址(scan the source program twice, so they can replace labels with memory addresses)。原因是有的标签先被引用,后才知道地址(some labels may be referred to before their address is known)。

第一遍:逐行读,忽略注释read one line at a time; ignore comments
→
给每行分配地址,检查操作码在指令集里allocate a memory address; check the opcode is in the instruction set
→
新标签和地址放进符号表add any new labels to the symbol table
→
第二遍:用符号表生成目标码,保存或执行generate object code from the symbol table; save or execute the program

例:程序装在地址 100 开始的位置,JPN Found 用到了后面才出现的标签 Found,这叫向前引用(forward reference)。

单遍汇编器把机器码直接放进内存执行;两遍汇编器生成目标程序,可以保存起来,以后再由装载程序装入执行(single pass: straight into memory; two pass: object program stored, then loaded by a loader)。

了解写符号表

从程序的起始地址往下,每条指令占一个地址;带标签的那一行,把标签和这一行的地址记进表里。向前引用的标签(如 Found),要等扫到它所在的那一行才知道地址。

4.2汇编指令

指令分取数存数、运算、比较跳转几类;运算在累加器里做,结果也放回累加器。

算术指令对累加器里的数做运算,答案总是存回累加器,覆盖原来的数据(answers to calculations are always stored in the accumulator)。比较指令总是拿累加器去比较(the contents of the accumulator are always compared)。条件指令conditional instruction(JPE、JPN)要跟在比较指令后面,按比较结果决定跳不跳(following a compare instruction, jump to the specified address if the comparison is True / False);JMP 是无条件指令,直接跳转。跳转就是把 PC 改成指定的地址,下一条执行的指令就是那个地址里的指令(change the PC to the address specified)。

4.2寻址方式

寻址方式决定怎么用操作数:立即寻址是数本身,直接寻址是数的地址,间接寻址是存着地址的地址,变址寻址要再加上 IX。

直接寻址direct addressing:操作数是数据所在的内存地址(the operand holds the memory address of the data),也叫绝对寻址,两者相同。立即寻址immediate addressing:操作数就是要用的数(the operand is the data)。间接寻址indirect addressing:操作数是一个地址,这个地址里存的又是数据的地址(the operand holds a memory address that stores the memory address of the data)。变址寻址indexed addressing:把变址寄存器的内容加到操作数上,得到数据的地址(the address of the data is formed by adding the contents of the Index Register (IX) to the operand)。

必考判断寻址方式,算出 ACC 里是什么

方式操作数是指令
立即数据本身LDM #n
直接数据的地址LDD
间接存着数据地址的地址LDI
变址加上 IX 后才是数据的地址LDX

例:地址 200 里是 300,地址 300 里是 50。

LDM #200→ ACC =200LDD 200→ ACC =300LDI 200→ ACC =50
了解相对寻址与符号寻址

相对寻址relative addressing:用的地址是当前地址加上操作数(the memory address used is the current memory address added to the operand)。例如 JMR #5 跳到当前指令之后第 5 个单元。

符号寻址symbolic addressing:只用于汇编语言,用标签代替地址(a label is used instead of a value)。程序里加了指令,用绝对地址的每一处引用都得改,用标签就不用,所以更容易修改程序。

4.3移位

移位把寄存器里的位整体左移或右移;逻辑移位补 0,算术移位保留符号位,循环移位不丢位。

逻辑移位logical shift:移出的位丢掉,空出来的位补 0(a logical shift moves all bits to the right and inserts zeros in the appropriate leftmost bits)。算术移位arithmetic shift:保持数的符号,把符号位复制到空出来的最高位(an arithmetic shift moves all bits to the right but copies the sign bit into the Most Significant Bit (MSB))。循环移位cyclic shift:不丢任何位,从一端移出的位从另一端移回来(no bits are lost during a shift)。每种移位都分左移和右移(left shift; right shift)。

必考写出移位的结果

指令作用
LSL #nACC 里的位逻辑左移 n 位,右端补 0(shifted logically n places to the left; zeros are introduced on the right-hand end)
LSR #nACC 里的位逻辑右移 n 位,左端补 0(shifted logically n places to the right; zeros are introduced on the left-hand end)

移位总是对 ACC 进行(shifts are always performed on the ACC)。例:ACC 里是 0001 1001。

4.3位操作

寄存器里的每一位都可以当一个标志:配上掩码,用 AND 检测,用 OR 置 1,用 XOR 清除。

位操作bit manipulation可以改变或检查某一位的状态(allows a change/evaluation of the state/value of a bit)。用于控制时,改变设备的状态;用于监测时,查明设备的状态(when controlling, change the state of a device; when monitoring, establish the state of a device)。指令的操作数用作掩码mask,选出要检测、置位或清除的位(the operand is used as the mask to set or clear bits)。运算结果总是存在 ACC 里(the results of logical bit manipulation are always stored in the ACC)。

三种按位运算:AND只有两个输入位都是 1,结果才是 1,用来检查某一位是否为 1(bitwise AND of the contents of ACC with the operand);OR只要有一个输入位是 1,结果就是 1,用来把某一位置 1(OR is used to set the bit);XOR两个输入位不同时结果才是 1,用来清除已置位的位(the output is 1 when one of the inputs is 1 and the other input is 0, otherwise the output is 0)。

必考检测、置位、清除某一位

目的做法原因
检测AND 掩码,再 CMP 掩码其他位都被清成 0,只剩要查的那一位(AND is used to check if the bit has been set)
置位OR 掩码掩码为 1 的位一定变成 1(OR is used to set the bit)
清除XOR 掩码翻转掩码为 1 的位,该位原来是 1 才会变成 0(XOR is used to clear a bit that has been set)

掩码的写法:选中的位写 1,其余写 0。教材里测试 sensor 3 的掩码是 #B100。

常考用汇编检测并清除 sensor 3

8 个传感器各用一位,记在同一个内存单元 sensors 里,处理完一个就清除它的位:

LDD sensors装入 ACC
AND #B100掩码只选 bit 3
CMP #B100检查 bit 3 是否为 1
LDD sensors处理完后,重新装入
XOR #B100清除 bit 3:sensor 3 已处理
