11.1常量与变量

变量的值运行中可以改,常量声明时赋值、之后不能改;每个名字使用前都要先声明。

变量variable是有名字的值,程序运行中可以改变(a named value that can change during the execution of a program);常量constant也有名字,运行中不能改变(a named value that cannot change during the execution of a program),而且声明时就要赋值(constants are always assigned a value when declared)。

标识符identifier是给变量、常量、过程或函数起的名字(the name given to a variable, constant, procedure or function)。所有变量和常量都要先声明再用(declared before use);变量最好声明后立刻赋初值,起始值才确定(assign a value so the starting value is certain)。

DECLARE <identifier> : <data type>
DECLARE height, width : REAL
DECLARE hypotenuse, area : REAL

每个变量都声明,并写出数据类型Declare loop variable and counter as integers

计数器、累加器先赋初值counter initialised

表格里描述为"固定值"的(如最大高度 25)写成常量,描述为"存放输入或计算结果"的写成变量。同类型的几个变量可以写在一条 DECLARE 里。

11.1库例程与字符串函数

库例程是现成的、测试过的子程序,拿来就用;字符串用 LENGTH、LEFT、RIGHT、MID 切,整数用 DIV、MOD 拆。

库例程library routine是编程语言开发环境里自带的现成例程(available in the development system of a programming language),已经测试过、可以直接放进程序(tested and ready-to-use; can be incorporated into a program)。输入输出这类几乎每个程序都要的功能,标准库里都有。

字符串函数返回字符串的长度或一部分(string manipulation functions)。DIV 返回除法的整数部分,MOD 返回余数(DIV returns the integer part of a division; MOD returns the remainder)。课本写成函数 DIV(10,3),真题里常写成 ThisInt MOD 10 = 7 这种中缀形式,两种都是同一个意思。

必考用字符串函数

函数(s = "Secret")作用
LENGTH(s) → 6字符串长度,返回整数(the length of the string)
LEFT(s, 2) → "Se"最左边 2 个字符(leftmost x characters)
RIGHT(s, 3) → "ret"最右边 3 个字符(rightmost x characters)
MID(s, 2, 3) → "ecr"从第 2 个字符起取 3 个,共 3 个参数(y characters starting at position x)

典型题:检查输入的密码长度和首尾字母。先比长度,再比首字母和尾字母:

CONSTANT storedPassword ← "Secret"
DECLARE inputPassword : STRING
OUTPUT "Please enter your password "
INPUT inputPassword
IF LENGTH(inputPassword) = LENGTH(storedPassword)
  THEN
    IF LEFT(inputPassword, 1) = LEFT(storedPassword, 1)
       AND RIGHT(inputPassword, 1) = RIGHT(storedPassword, 1)
      THEN
        OUTPUT "Password entered has correct first and last letters"
      ELSE
        OUTPUT "Password entered is incorrect"
    ENDIF
  ELSE
    OUTPUT "Password entered is incorrect"
ENDIF
输入检查输出
"Sad"长度 3 ≠ 6,不再往下查incorrect
"Cheese"长度相同;首 C≠S,尾 e≠tincorrect
"secret"长度相同;首 s≠S,尾 t=tincorrect
"Secret"长度相同;首 S=S,尾 t=tcorrect

LCASE 把一个字符转成小写,参数必须是单个字符,不能是整个字符串(Parameter must be a char // cannot be a string)。要逐个字符处理时,用 MID 取出一个字符再转换:

11.2选择:IF 与 CASE

条件决定走哪条路:两三种情况用 IF,选项多时用 CASE,最后用 OTHERWISE 兜住剩下的所有情况。

选择结构selection由条件决定执行哪些语句(a condition determines which statements are executed),用 IF 或 CASE 写(a selection construct // an IF statement)。只有两三种情况时用 IF,必要时嵌套;情况很多时用 CASE 更清楚。CASE 的每个分支可以按条件(如 < 10)、按范围(如 1:10)或按确切的值(如 10)来选(a condition, a range of values, or the exact value),最后的 OTHERWISE 处理前面都没有匹配的情况(a final catch all)。

常考写 CASE 语句

DECLARE choice : INTEGER
OUTPUT "Please enter your choice "
INPUT choice
CASE OF choice
  1 : OUTPUT "Routine 1"
  2 : OUTPUT "Routine 2"
  3 : OUTPUT "Routine 3"
  4 TO 6 : OUTPUT "Routine not written"
  10 : OUTPUT "Exit"
  OTHERWISE : OUTPUT "Incorrect choice"
ENDCASE
输入 choice输出走哪个分支
2Routine 2确切的值 2
5Routine not written范围 4 TO 6
10Exit确切的值 10
7Incorrect choice没有匹配,走 OTHERWISE

评分细则里 The OTHERWISE statement 和 Selection structure based on range 各单独给分,别漏写 OTHERWISE 和 ENDCASE。

常考不用 CASE 怎么写:先给默认值再逐个 IF

把 CASE 改写成 IF 时,用一次初始赋值代替 OTHERWISE(OTHERWISE, or initial assignment of default value)。下面和 CASE OF MySwitch 的 1→'a'、2→'y'、3→'7'、其余→'*' 完全等价:

ThisChar ← '*'
IF MySwitch = 1
  THEN
    ThisChar ← 'a'
ENDIF
IF MySwitch = 2
  THEN
    ThisChar ← 'y'
ENDIF
IF MySwitch = 3
  THEN
    ThisChar ← '7'
ENDIF

11.2三种循环

次数已知用 FOR(计数循环);先判断后执行用 WHILE(前置条件);先执行后判断用 REPEAT(后置条件)。

计数循环count-controlled loop写成 FOR … NEXT,重复预先确定的次数(repeats a block of statements a predetermined number of times)。前置条件循环pre-condition loop写成 WHILE … DO … ENDWHILE,每轮之前先测条件,所以循环体可能一次也不执行(tests its condition before each iteration; the body may never execute)。后置条件循环post-condition loop写成 REPEAT … UNTIL,每轮之后才测条件,所以循环体至少执行一次(tests its condition after each iteration; the body always executes at least once)。

注意条件的方向:WHILE 的条件为真就继续,REPEAT 的 UNTIL 条件为真就退出。

了解选哪种循环

情形选原因
次数已知FOR … NEXT计数器不用自己管理(the number of iterations is known; the loop counter does not have to be managed by the programmer)
可能一次都不用做WHILE先测条件,不满足就跳过(the body may never execute)
至少要做一次,如输入校验REPEAT … UNTIL循环体至少执行一次,不用在循环前再写一遍 INPUT(always executed at least once; no need for a second input statement)

11.2循环的写法

同一个任务三种循环都能写;考试按模板写,别忘了声明变量、赋初值、更新计数器。

三段代码输出的都是 15。FOR 的计数器由循环自己加 1,不用写更新语句(no step defined);WHILE 和 REPEAT 要自己给计数器赋初值、在循环体里加 1,漏了就会死循环。

必考写循环

真题:输出 100 到 200 之间个位是 7 的数,最后输出一共有几个(107、117、……、197,共 10 个)。

DECLARE ThisInt, Count : INTEGER
Count ← 0
FOR ThisInt ← 100 TO 200
    IF ThisInt MOD 10 = 7
      THEN
        OUTPUT ThisInt
        Count ← Count + 1
    ENDIF
NEXT ThisInt
OUTPUT Count
给分点英文原话
声明循环变量和计数器,计数器赋初值Declare loop variable and counter as integers, counter initialised
循环从 100 到 200,不写步长Loop 100 to 200, no step defined
在循环里测试每个值Test value in a loop
在循环里输出符合的数并计数Output selected value and incrementing a counter in a loop
循环结束后输出计数Output the counter, following a reasonable attempt, after the loop

THEN 也可以和条件写在同一行;写法其他部分按上面的模板。

了解追踪 WHILE 版:变量一步步怎么变
步骤CountTotalCount <= 5
循环前10真
第 1 轮后21真
第 2 轮后33真
第 3 轮后46真
第 4 轮后510真
第 5 轮后615假,退出,输出 15
了解输入校验:REPEAT 与 WHILE 对比

检查输入的数在 0 到 10 之间(含 0 和 10)。REPEAT 的 UNTIL 写"合格,可以退出"的条件;WHILE 写"不合格,要重来"的条件:

REPEAT
    OUTPUT "Enter value "
    INPUT Value
UNTIL Value >= 0 AND Value <= 10
OUTPUT "Enter value "
INPUT Value
WHILE Value < 0 OR Value > 10 DO
    OUTPUT "Enter value "
    INPUT Value
ENDWHILE

REPEAT 版循环体至少执行一次,不用重复写输入语句,所以校验输入更适合用 REPEAT。

11.3过程

过程把一组语句起个名字,定义一次、随处 CALL;参数让同一个过程每次做得不一样。

子程序subroutine是有名字、自成一体的一组语句,完成一项任务,可以在程序的不同地方调用很多次(can be called many times from different places in a program);过程和函数都是子程序。过程procedure定义一次,需要时调用(defined once and called when required),不必返回值(does not have to return a value)。调用过程是一条独立的语句 CALL(a single stand-alone statement)。

过程头header是定义的第一条语句,写明名字和参数(the name, any parameters and, for a function, the return type)。形式参数parameter是定义里接收传入值的变量(receives a value passed in when the subroutine is called);实参argument是调用时真正传进去的值(the actual value passed when it is called)。实参的个数、顺序和类型要和过程头里的形参一一对应(same order; each argument of the same type as its parameter)。

必考写过程

PROCEDURE <identifier>(<parameter1> : <datatype>, <parameter2> : <datatype>)
    <statements>
ENDPROCEDURE

CALL <identifier>(<value1>, <value2>)
给分点英文原话
过程头带参数,以 ENDPROCEDURE 结尾Procedure heading (with parameter) and ending
只在过程里用的变量在过程里声明Declare local variable for Index as loop counter
用正确的实参调用Call Display() with filename as parameter

11.3参数怎么传:按值与按引用

按值传的是副本,过程里怎么改,原变量都不变;按引用传的是变量本身,过程里一改,原变量跟着变。

按值传递by value传入的是值的副本,过程不能改变原变量(a copy of the value is passed; the value of the variable cannot be changed by the procedure)。按引用传递by reference传入的是变量的地址,过程可以改变原变量的值(the address of the variable is passed; the subroutine can change the original value)。伪代码里在形参前写 BYVAL 或 BYREF。

了解按值还是按引用

PROCEDURE celsius(BYREF temperature : REAL)
    temperature ← (temperature - 32) / 1.8
ENDPROCEDURE

myTemp ← 212
CALL celsius(myTemp)
OUTPUT myTemp    // 100;若写成 BYVAL,这里仍是 212
情形用英文原话
过程要把算出的结果交回给调用者BYREFuse of BYREF for the three extracted values
过程只读取参数,不该改动原变量BYVALparameter / Num has been passed by reference // should have been passed by value

11.3函数

函数和过程一样定义一次、多处使用,但函数一定返回一个值(RETURN),调用时放在表达式里。

函数function是从程序别处调用的一组语句,一定会返回一个值(always returns a value),调用出现在表达式的右边(a function call forms part of an expression)。函数头要写出名字、形参和返回值的类型(its name, any parameters passed to it, and the type of the return value),用 RETURN 指定返回的值,以 ENDFUNCTION 结束。

必考写函数

FUNCTION <identifier>(<parameter1> : <datatype>) RETURNS <data type>
    <statements>
    RETURN <value>
ENDFUNCTION
给分点英文原话
函数头:名字、形参、返回类型Function heading, including parameters and return type
以 ENDFUNCTION 结尾Function heading and ending
用 RETURN 返回正确的值Return Index (correctly in all cases)

常考过程和函数的区别

过程函数
返回值不必返回值(does not have to return a value)一定返回一个值(always returns a value)
调用单独一条语句(a single stand-alone statement),如 CALL stars(7)放在表达式里(part of an expression),如 myTemp ← celsius(212)
了解多个 RETURN:不同路径各返回一次

一个函数里可以有多个 RETURN,对应不同的执行路径,但要小心,保证每条路径都有返回值(more than one RETURN if there are different paths through its statements):

FUNCTION Larger(A : INTEGER, B : INTEGER) RETURNS INTEGER
    IF A > B
      THEN
        RETURN A
      ELSE
        RETURN B
    ENDIF
ENDFUNCTION

Larger(7, 12) 返回 12,Larger(9, 3) 返回 9。
