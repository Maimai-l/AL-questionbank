# 入学考选择题:TMUA、TSA 与 BMAT

本文档说明题目切分规则的设计依据,覆盖 55 份卷子共 1888 题。规则本身位于
`scripts/qb/pipeline/admissions_rebuild/split_admissions.py`,修改规则前应
先阅读本文。

## 三类卷子的版面差异

| | TMUA | TSA | BMAT |
|---|---|---|---|
| 年份范围 | 2016–2023 及 specimen,每届 P1 与 P2 | 2008–2023 | 2003–2023 |
| 每卷题数 | 20 | 50 | 35,2020 年起 32 |
| 版面 | 一页一题,2016 年与 specimen 为一页两题 | 一页 1 至 2 题 | 一页 1 至 2 题 |
| 选项 | A–H,以数学表达式居多 | A–E | A–H,早期夹杂无选项的短答题 |
| 答案键 | 每年一份,两卷并排于同一张表 | 每年一份 | 每年一份,含自由文本答案 |
| 附加材料 | 每题均有官方逐题详解 | 2020 年有官方讲解 | 无 |

TMUA 因一页一题,可借助页与题的位置关系补全题号;TSA 与 BMAT 不具备这一
条件。

## 切分锚点为何选择选项连排

最直观的做法是按印刷题号切分,但这条路不可行。OCR 经常丢失两位数题号的
前导位,第 11 题被读作 "1",第 13 题被读作 "3"。以此为锚点,一份卷子可能
错一半。

真正稳定的特征是选项连排:每道选择题都以 A、B、C 等字母升序、连续、不重复
的若干行结尾。据此确定三条规则:

- 从上一个选项连排结束到下一个选项连排结束,构成一道题;
- 题号由位置给出,即第几个连排即第几题,印刷题号仅用于交叉印证;
- 连排至少包含 3 个字母,且必须从 A 起始。

### 连排检测需要容忍的插入内容

实际卷面中,连排内部会插入多种内容,检测时不能一遇异常就中断:

| 插入内容 | 示例 | 处理方式 |
|---|---|---|
| 空行 | OCR 在选项之间留空 | 跳过 |
| 插图 | 图形选项,每个字母下方一张图 | 跳过,由 `IMGTAG` 识别 |
| 居中 div | `<div>A</div>` 形式的字母标注 | 先归一化为 `A (图形选项)` |
| 图注 | "View from East" | 长度不足 40 字且上一项为图形选项时跳过 |
| 转录注释 | `<!-- 选项自页面图像转录 -->` | 跳过 |
| 错位单行 | OCR 将题干问句输出在选项之间 | 下一行恰为期待字母时跳过 |

### 选项字母缺失的补全

OCR 时常吞掉某个选项的字母而保留其正文。`repair_option_gaps()` 区分三种
情形:

- 中间缺失:出现字母 X 与 X+2,二者之间恰好一行散文,该行即 X+1;
- 开头缺失:B、C 等均在而 A 缺失,B 之前一行若其上一行是以问号结尾的问句,
  该行即 A;
- 结尾缺失:最后一个字母之后有一行散文,其后为新题号或页尾,该行即最后
  一个选项。

三条规则均要求周围结构恰好符合模式。宁可不补也不能误补——补错会将题干中
的一句话变成选项,反而导致校验失败。

### 选项的两种非常规位置

其一是被打包进数学块,形如 `$$ \textbf{A}\quad ... \textbf{B} ... $$`。
`mathblock_options()` 从 `\textbf{X}` 中抽取升序字母。

其二是以表格呈现,形如 `| A | 1:1 |` 的两列表。`tables_to_lines()` 的判据
是行首单元格是否为单个字母:是则摊平为 `A 1:1` 文本行,否则作为数据表格
保留。这一区分是必要的,否则题干中的数据表会被误伤。

### 图形选项必须连同插图一并切出

字母表在前、插图在后是常见排版。若在选项行处切分,整组配图会被归入下一题,
形成"本题声明见图却无图,下一题多出五张他人的图"的错误。因此当检测到连排
中包含图形选项标记时,应继续向后吸收紧随的图片行与空 div,直至遇见真正的
正文或新题号。

### 选项折行合并必须克制

长选项会折行,折行部分需并入选项。但这条规则一旦放宽,就会将下一题开头的
整段论证并入上一题。判据是:上一个选项行不以句末标点(`.?!:;`)结尾,且
下一行不以大写字母、数字或引号开头,才视为折行。

该规则曾经过宽,导致 138 道 CT 题丢失论证段落。CT 题失去论证段完全无法作答,
而单独查看题目却显得正常。收紧后降至 5 处,且均为共享材料题——材料位于前
一页,题目本身只有一句问句,属于正常情形。

### 题号对齐:切出题数不足时的处理

切出的题数少于答案键条数时,不能简单按顺序编号,因为缺口之后的题目会整体
错位。`align_numbers()` 用动态规划将 m 个片段对应到 1 至 N,评分规则如下:

- 片段携带的印刷题号与候选题号完全相同,计 +3 分;
- 印刷题号是候选题号的个位,即丢失了前导位,计 +2 分;
- 片段不含印刷题号,计 0 分,视为中性;
- 印刷题号与候选题号矛盾,计 −3 分。

取全局最优路径。如此缺口会落在证据最弱的位置,而非一律落在末尾。

## 答案键解析

答案键是 OCR 输出的 HTML 表格,必须按行解析,不能扁平扫描单元格,原因有三:

- TMUA 在一张表中并排放置两份卷子,形成 Q、K、Q、K 四列,扁平扫描会将 P1
  的题号配上 P2 的答案;
- 早期 BMAT 的答案键含 Comments 与 Max marks 附加列;
- BMAT 的答案不一定是字母,`£10500`、`30 to 49`、`s: 38, b: 36` 均为合法
  答案。因此"答案单元格"的判据是内容简短、非空且不属于表头词,而非"单个
  字母"。

解析完成后断言:题号连续覆盖 1 至 N 无缺口,且 N 落在该考试的合理区间内
(TSA 为 50,BMAT 为 30 至 40,TMUA 每卷为 20)。

## 主题标注

### TMUA:官方 spec 的 MM/M 码

以 `TMUA_Content_Specification_April2025.pdf` 本身作为训练语料:每个主题
一份文档,内容为标题重复三遍加权,加上该主题下的全部条目;n-gram 取至 3;
IDF 在主题之间计算;题目按命中词的权重打分。分词与 CAIE 标注共用
`pipeline/tags/topic_model.py`,以保持两条线口径一致。

语料中必须包含 M1 至 M7 背景知识组。缺少这些条目时,数论题、多边形题与
统计题无处归属,会被强行分配到最接近的 MM 主题,实测导致 MM8 异常膨胀至
52 题。M4(GCSE 代数)在展示时并入 MM1,因为对使用者而言属于同一练习类别。

低置信题目(最高分与次高分相差不足 15%)交由模型复核,改判结果写入
`retag_tmua.json`。P2 另有推理子标签 Arg、Prf、Err,按 spec 原词表匹配。

### TSA 与 BMAT:官方 PS/CT 七型

采用 TARA 官方 Question Guide 的分类。CT 题的题干高度程式化,例如
"best expresses the main conclusion"、"if true, most weakens",因此使用
题干正则即可达到较高的分型准确率:

| 代码 | 题型 | 典型句式 |
|---|---|---|
| CT-main | 主结论 | best expresses the main conclusion |
| CT-draw | 推出结论 | can be drawn as a conclusion / can be inferred |
| CT-assm | 找假设 | underlying assumption / takes for granted |
| CT-evid | 证据影响 | if true, most weakens / strengthens |
| CT-flaw | 找谬误 | best statement of the flaw |
| CT-match | 类比推理 | most closely parallels the reasoning |
| CT-prin | 应用原则 | illustrates the principle |
| PS | 问题求解 | 其余全部 |

匹配时只检查题干,不检查选项。选项中同样会出现这些词,一并匹配会将 PS 题
误判为 CT。

校验依据是官方结构:TSA 每卷恰好 25 题 PS 加 25 题 CT,BMAT 自 2020 年起为
16 加 16。配比不符即说明存在误判,应顺着差额定位。人工改判写入
`retag_tara.json`。数据图表推断题(题干含 "inferred from the graph/tables")
按 TSA 惯例归入 PS。

## 逐题配图

由 `render_adm_imgs.py` 生成,文件名即题号 ID,便于在本地建立索引。

裁切依据是 PDF 文本层中的印刷题号,即左边距上的粗体数字。TSA 与 BMAT 使用
Arial-Bold,x 坐标约为 51;TMUA 使用 CM 粗体。从本题题号裁至下一题题号,
一页两题自然切成两张。

有三种情形必须处理:

- 题号位于更靠后的页面。切分记录的 `pages` 是段落文字的来源页,常把上一题
  残行所在的页也计入。因此应在本题所有页面中查找题号,并向前额外查找两页。
- 共享材料。形如 "Questions 19–22 refer to the following information" 的
  材料页需整页拼接在题目之前,否则单独查看一题缺乏上下文。
- 裁切过度。计算出的高度小于 120pt 说明上界定位有误,应退回整页。宁可多给。

拼接多块图像时,带 clip 的 pixmap 自带页面坐标原点,必须调用 `set_origin`;
且 `Pixmap.copy(src, rect)` 的 rect 按源坐标计算。这两点弄反会得到空白图像。
尾部整片留白会自动裁除。

## 早期 BMAT 的短答题

2003 至 2011 年的 BMAT 夹杂无选项的短答题,答案为数字或自由文本。此类题目
没有选项连排,只能从过长片段中依据印刷题号切出,由 `recover_short_answers`
处理。该恢复流程仅在该卷题数不足时启用,且只接受与位置吻合的题号,否则会
将题干中的编号列表(1. 2. 3.)误认为新题。入库时 `qtype` 记为 `short`,
共 33 道。
