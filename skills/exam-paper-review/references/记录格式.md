# 刷卷记录格式

完整样例见 `记录样例.md`（9231 FP1，13 套卷，含练习材料、笔记索引、题库存量）。

一门卷子一份 Markdown 文件，文件名 `<科目代码>_<卷种>_刷卷记录.md`，例如 `9231_FP1_刷卷记录.md`。手工维护，不用脚本生成。

## 每次更新只做一件事

在第 6 节最上方加一个小节，写元数据行、自评原话、逐题表、判分从宽、备注。其余各节的所有数字都从各套的逐题表算出，更新时重算，不另行手记次数。重算后核对三处：各板块得分之和等于总分之和；机制失分之和等于标签失分之和；两者都等于累计失分。

## 节次

| 节 | 内容 |
|---|---|
| 抬头 | 考试名称与考季、更新日期 |
| 1 状态 | 已刷套数、累计得分、平均分、平均高出等级线、最高与最低单套、最大领先、累计失分及其中已定位到机制的部分 |
| 2 卷子总表 | 一套一行：卷、卷号、场次、日期、得分、等级线、高出、用时、介质、涂改、自评摘录 |
| 3 知识板块 | 两张表。累计表：行是板块，按得分率升序，列为累计得分、得分率、失分、失分占比、主要机制。分卷表：行是板块，列是卷，按时间从左到右，格内写得分与满分 |
| 4 错误机制 | 行是机制，按累计失分降序，列为机制、标签、次数、失分、出现位置。下附失分性质表（七类标签的累计失分） |
| 5 当前重点 | 最多三条，每条写依据和下一步。整节重写，不追加 |
| 6 逐套明细 | 新的在上，每套格式相同 |
| 7 练习材料 | 一份一行：编号、名称、规格、介质、完成、得分。用户自己做的只记结果，不逐题记 |
| 8 必背方法与笔记 | 索引表加用户原话。正文另存文件 |
| 9 题库存量 | 场次 × 变体矩阵，格内写占用它的卷或练习材料编号；下附等级线矩阵 |
| 10 检查清单 | 按机制累计失分排列，每条对应一个机制 |

记录方法（标签定义、涂改等级、缺失值写法）另存 `记录方法.md`，不放进记录本身。

## 逐套明细的固定格式

```markdown
### P13 · 9231/13 · O/N 2021

73/75，A 线 42，+31；用时未记录；纸质，涂改未记录；判分日期 2026-09-17

> 自评原话。

| 题 | 板块 | 得分 | 丢分 | 标签 | 机制 | 说明 |
|---|---|---|---|---|---|---|
| 1 | 多项式根 | 6/6 | — | — | — | — |
| 3(b) | 归纳法 | 7/8 | −1 | 概念 | M9 | 错在哪一步、正确做法 |

判分从宽：无

备注：只属于这套卷的分析。
```

- 列固定为：题、板块、得分、丢分、标签、机制、说明。
- 满分的题也要列，否则板块统计缺分母。
- 同一题多处失分时拆成多行，得分列重复写该题总得分。
- 一处失分只归入一个机制。引用新机制时先在第 4 节加一行。
- 不判分的卷用同一模板，得分列写“—”，逐题表只填板块、满分和题目构成，不计入任何统计。
- 逐题数据未留存的卷同样列出小节，写明“逐题数据未留存”和已知的聚合信息。

## 七类失分性质标签

| 标签 | 定义 |
|---|---|
| 算术/转写 | 工作行正确，计算或抄到答案行时出错 |
| 目标条件 | 计算正确，但求错对象或没有用上题目条件 |
| 术语 | 数学正确，但名称或描述不符合要求 |
| 记号 | 书写形式不符合要求（坐标形式、区间端点开闭、哑变量） |
| 概念 | 不知道方法，或方法本身错误 |
| 图标注 | 图形正确，但缺渐近线方程、交点坐标等标注 |
| 答案不完整 | 小问没答完，或缺最终结论 |

## 涂改等级

0 干净一次成型；1 局部小改；2 一段推导划掉重写；3 整条解题路线推翻重来。按小问分值加权得到整卷涂改指数。iPad 书写不计算。

## 编号规范

| 对象 | 编号 | 说明 |
|---|---|---|
| 真题卷 | P01、P02… | 按判分顺序，不按年份 |
| 机制 | M01、M02… | 按出现顺序，编号不复用 |
| 笔记与必背方法 | N01、N02… | 按写下的顺序 |
| 专题练习（真题选题） | TP-01… | |
| 操练册（自编同类题） | DR-01… | |
| 靶向练习卷（自编成套） | TG-01… | |

文件名：`<科目代码>_<卷种>_<编号>_<简短标题>_题目.pdf` 与 `…_答案.pdf`，笔记为 `N01_<标题>.md`。

## 需要避免的写法

- 不写“本节”“本册”“本卷”这类元叙述，也不在正文里解释某张表怎么来的。
- 不在累计节里追加“本轮变化”这类段落，它们会堆积并互相矛盾。只属于某一套的分析写在该套的备注里。
- 数据缺失写“未记录”，不补填推测值。
- 中文用全角标点，数学统一用同一种写法。
