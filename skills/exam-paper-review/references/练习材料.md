# 用 Typst 出练习卷

工具：Typst（`pip install typst --break-system-packages`，Python 中 `import typst` 调用）配合 Typst Universe 的 `examy` 包，编译时自动下载，版本以 Universe 上最新版为准。不要手写 LaTeX 宏实现作答空间。

样例与脚本在 `assets/` 下。样例本身就是模板：

| 文件 | 用途 |
|---|---|
| `练习卷样例.typ` | 部分分式那份的源文件；出新卷时复制一份，改配置块和题目数据 |
| `build.py` | 编译出题目册与答案册两个 PDF |
| `check.py` | 逐题测量作答空间，检查题干与作答区是否被分页拆开 |
| `练习卷样例_题目.pdf`、`练习卷样例_评分方案.pdf` | 样例编译出的成品，出卷前先看一遍版式 |

字体：正文与公式用 STIX Two（Times 风格，接近 CIE 原卷），中文用思源黑体（Noto Sans CJK SC），数学用 STIX Two Math。STIX Two 不在容器内，从 Google Fonts 仓库取 `stixtwomath` 与 `stixtwotext` 的 ttf，放在一个目录里，编译时用 `font_paths` 指向它。

## 源文件结构

- **配置块**：卷号、中英文标题、建议用时、字体。
- **方法要点**：这个专题要固定下来的公式与方法，写完整的句子，不要缩成看不懂的简写。封面只放标题和它。
- **题目数据**：一个数组，每题写题干、分值、作答空间、评分点和说明。题目册、答案册和封面右上角的题数与满分都由它生成，不会前后不一致。
- `作答空间` 三种：`("lines", n)` 虚线书写行、`("blank", 长度)` 空白作图区、`("fill",)` 占满本页剩余。

## 版式要求

- 页面底部只有页码，不放页脚、卷名、分隔线。
- 题数、满分、用时放在标题右侧，与标题同一行。
- 题号加粗，小问写作 (a)(b)，分值写成右对齐的 **[n]**。
- 题目正文用英文（考试是英文命题），封面、方法要点、评分说明用中文。
- 评分方案仿 mark scheme 的四列表格：题号、答案、分值、说明。每行一个得分点，M1/A1/B1 与该行步骤对齐。

## 已知陷阱

- **书写行与作图区必须是不可跨页的实体块**。否则页尾空间不足时，题干留在本页、作答区被推到下一页。
- **examy 的题目内部不能按答案开关决定是否分页**，Typst 会报错。分页开关要读编译输入变量，在数据层判断。
- 答案册里隐藏书写行、作图区和分页，题目后直接接答案。

## 交付前验证

1. 编译无错误。
2. `pdftotext` 检查题目册不含答案文字、答案册含答案文字。
3. 运行 `check.py`，逐题输出题干下方的作答空间高度，确认没有被分页拆开、没有远小于设定值的题。
4. 所有答案用 sympy 验证（不定积分求导回代，定积分数值比对，几何题用代码计算）。
5. 渲染每页图片目视检查。

## 参考图（matplotlib 导出 SVG 或 PDF，Typst 中用 `image` 插入）

- 每个函数固定一种颜色，同一曲线的不同分支不自动换色。
- 极点处分段并屏蔽过大值；渐近线用灰色虚线并标注方程。
- 用 `bbox_inches='tight'` 避免标注被裁；标注互不重叠、不压在曲线上。

## 真题选题

- 用 `scripts/qbank.py find --syllabus 9231 --topic 3 --text 关键词` 从题库检索真题，题库已按大纲主题码标注，不必自己下载建索引。题库范围外的年份再用 `get_paper.py` 下载。
- 逐题判断难度和考查程度后再选，优先覆盖用户从未接触过的 syllabus 子项。
- 排除用户已做过的卷子中的题目，并在记录的题库存量里标出被练习材料占用的卷。
- 题目文本用 `qbank.py show 题号` 取出后核对原卷（`get_paper.py` 下载），保留原卷号与题号。
